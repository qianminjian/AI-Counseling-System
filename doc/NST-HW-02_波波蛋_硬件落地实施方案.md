# 无屏交互终端 ·「波波蛋 / 圆润小精灵」硬件落地实施方案

> 编号：NST-HW-02（落地实施方案）| 创建：2026-08-08 | 关联：NST-FRM-01（方案 A 波波蛋）、NST-HW-01（§2.2 试点采购清单）、NST-MFG-01（3D 打印）、NST-ENG-01（工程基线）
> 定位：以 **NST-FRM-01 方案 A（波波蛋）** 为产品形态、以 **NST-HW-01 §2.2 试点采购清单（整体化，单台）** 为物料边界，把"立创实战派 ESP32-S3"整体化方案**落实为新手可直接采购、编程、组装、打印的一份可执行方案**。
> 结论先行：核心板已是整体化板（含主控+双麦+Codec+功放+喇叭+屏+IMU），你只需外挂 **震动马达 + WS2812 LED 环**；编程先用**小智固件 Web 刷机**（零代码跑通对话），再按需走 ESP-IDF 二次开发；组装按"板竖放→喇叭底朝下→马达贴壁→灯环底圈→出线"顺序；外壳按 NST-MFG-01 用 A1 mini/P2S 打印。本方案把清单、工具、代码、步骤一次给全。

## 三、重点 2 · 硬件编程详细方案

### 3.1 两条路径（先选路，别一上来就搭环境）

| 路径 | 适合 | 工作量 | 能跑通什么 |
|---|---|---|---|
| **A·小智固件 Web 刷机（零代码）** | 新手先验证产品形态 | 30 分钟 | 语音对话、表情屏、Soft-AP 配网；震动/LED 靠小智"设备端 MCP"脚本控制 |
| **B·ESP-IDF 二次开发** | 要定制唤醒词/后端/震动 LED 深度联动 | 1–3 天搭环境 + 编码 | 在 A 基础上改固件、加驱动任务、接自有后端 |

**强烈建议**：先用 **路径 A** 把"会说话的波波蛋"跑起来（验证形态+交互），再视需要走 **路径 B**。不要一开始就编译源码——小智源码编一次要 10+ 分钟且坑多。

### 3.2 路径 A：小智固件 Web 刷机（零代码，先跑通）

**工具**：Chrome/Edge 浏览器、USB-C 数据线（**必须带数据，不只是充电线**）、电脑。

**步骤**：
1. 下载固件：到 `https://github.com/78/xiaozhi-esp32/releases` 取 **`vX.X.X_lichuang-dev.zip`**（立创实战派专属，文件名带 `lichuang-dev`）。解压得到 `.bin`。
2. 打开 Web 烧录页（二选一）：
   - 官方：`https://espressif.github.io/esp-launchpad/`
   - 国内镜像：`https://fw.gtai-tech.com/`
3. 开发板用 USB-C 连电脑 → 网页点 **Connect** → 选串口（CH340，需先装 CH340 驱动：`https://www.wch.cn/downloads/CH341SER_EXE.html`）。
4. 选刚下载的 `.bin`，烧录地址填 **`0x0`** → 点 **Program**。
5. 烧完点 **Reset Device**（或按板载复位键）。
6. 首次启动进配网模式 → 手机连设备开的 **Soft-AP 热点**（名称类似 `Xiaozhi-XXXX`）→ 浏览器开配网页输家里 WiFi → 绑定 `xiaozhi.me` 账号（免费用 Qwen 实时模型）。
7. 对波波蛋说唤醒词（默认"你好小智"）→ 对话，屏幕显示表情。✅ 形态验证完成。

> 此路径**完全满足 NST-SPC-01 的 Soft-AP 配网要求**，且零代码。震动/LED 在路径 A 下用"设备端 MCP"控制（小智支持 MCP 控制 GPIO/电机/灯），改配置即可，无需写 C。

### 3.3 路径 B：ESP-IDF 开发环境（二次开发）

**工具**：VSCode（或 Cursor）、ESP-IDF 插件（**SDK ≥ 5.4**）、Python 3.10+、Git。

**步骤**：
1. VSCode 装 `Espressif IDF` 插件，按向导装 ESP-IDF **v5.4**（Linux 编译更快，Windows 需先装 CH340 驱动）。
2. 取源码（用稳定版，勿用 master）：
   ```bash
   git clone --branch v2.0.3 --depth 1 https://github.com/78/xiaozhi-esp32.git
   cd xiaozhi-esp32 && idf.py set-target esp32s3
   ```
3. `idf.py menuconfig` → `Xiaozhi Assistant` → **Board Type 选「立创实战派 ESP32-S3 开发板」**；`Serial flash config` → **Flash size 16 MB**。保存退出。
4. 编译烧录：`idf.py build flash monitor`。首次编译 10–20 分钟。
5. 串口监视：`idf.py monitor`（退出 `Ctrl+]`）。

**要在源码里加震动/LED**（见 §3.5），改 `main/boards/lichuang-*` 板级文件或新增 MCP 设备控制。

### 3.4 引脚分配与接线定义（立创实战派扩展口）

立创实战派有**两个扩展口**（5P GH 端子，官网 wiki 可查）：
- **I2C 接口**：与板载 IMU/触摸/音频共用总线，**只能做 I2C，不要复用** → 本方案不用它接外设。
- **多功能接口**：引出 **GPIO10、GPIO11**，可复用为 PWM/串口/I2C/CAN，并带 **3.3V / 5V / GND** → **震动马达与 LED 环接这里**。

| 外设 | 接扩展口引脚 | 信号类型 | 备注 |
|---|---|---|---|
| 震动马达 | GPIO10（PWM）| 数字输出 → 三极管驱动 | 不能直接接马达，过 S8050 |
| WS2812 灯环 | GPIO11（单总线）| 数字输出（3.3V→串 330Ω）| DIN 串 330Ω 接近 5V 阈值，短距可靠 |
| 共地 | GND（扩展口）| — | 灯环/马达电源地与 ESP32 必须共地 |
| 取电 | 5V（扩展口）| — | 灯环 VCC、马达+（经驱动）取自此处 |

> ⚠️ GPIO10/11 非 strapping 脚，安全。不要碰 GPIO0/3/45/46（下载/启动相关）。板载用户键已占用，别复用。

**震动马达驱动电路（必修，否则烧 IO）**：
```
ESP32 GPIO10 ──1kΩ──► S8050 基极 B
                         │
                    S8050 发射极 E ──► GND（与 ESP32 共地）
                         │
                    S8050 集电极 C ──► 马达负极(−)
                         │
                  马达正极(+) ──► 5V（扩展口）
                         │
              1N4148 反向并联马达：阴极接 5V，阳极接 C
```
PWM 占空比控制"震动强度"（10%–100%）。用 L9110H 模块则按模块丝印接 IN1/IN2=GPIO10、VCC=5V、OUT=马达。

**WS2812 灯环接线**：
```
灯环 VCC ──► 5V（扩展口）
灯环 GND ──► GND（扩展口，共地）
灯环 DIN ──► 330Ω ──► GPIO11
```

### 3.5 外设驱动代码框架（ESP-IDF，固件通视角：非阻塞、查返回值、静态分配）

**(a) 震动马达（PWM via LEDC，任务化、非阻塞）**
```c
#include "driver/ledc.h"
#define MOTOR_GPIO   GPIO_NUM_10
#define MOTOR_CH     LEDC_CHANNEL_0

static void motor_init(void) {
    ledc_timer_config_t t = {
        .speed_mode = LEDC_LOW_SPEED_MODE,
        .timer_num  = LEDC_TIMER_0,
        .duty_resolution = LEDC_TIMER_10_BIT,  // 0-1023
        .freq_hz    = 5000,                     // 5kHz  audible-free
        .clk_cfg    = LEDC_AUTO_CLK,
    };
    ESP_ERROR_CHECK(ledc_timer_config(&t));
    ledc_channel_config_t c = {
        .gpio_num   = MOTOR_GPIO,
        .speed_mode = LEDC_LOW_SPEED_MODE,
        .channel    = MOTOR_CH,
        .timer_sel  = LEDC_TIMER_0,
        .duty       = 0,
    };
    ESP_ERROR_CHECK(ledc_channel_config(&c));
}
// 触发震动：duty 0-1023；非阻塞，由调用方控制时长
static void motor_pulse(uint32_t duty, uint32_t ms) {
    ledc_set_duty(LEDC_LOW_SPEED_MODE, MOTOR_CH, duty);
    ledc_update_duty(LEDC_LOW_SPEED_MODE, MOTOR_CH);
    vTaskDelay(pdMS_TO_TICKS(ms));
    ledc_set_duty(LEDC_LOW_SPEED_MODE, MOTOR_CH, 0);
    ledc_update_duty(LEDC_LOW_SPEED_MODE, MOTOR_CH);
}
```

**(b) WS2812 灯环（RMT + led_strip 组件，非阻塞状态色）**
```c
#include "led_strip.h"
#define LED_GPIO  GPIO_NUM_11
#define LED_NUM   8
static led_strip_handle_t strip;

static void led_init(void) {
    led_strip_config_t cfg = {
        .strip_gpio = LED_GPIO, .max_leds = LED_NUM,
        .led_pixel_format = LED_PIXEL_FORMAT_GRB,
        .led_model = LED_MODEL_WS2812,
    };
    led_strip_rmt_config_t rmt = { .resolution_hz = 10 * 1000 * 1000 };
    ESP_ERROR_CHECK(led_strip_new_rmt_device(&cfg, &rmt, &strip));
}
// 状态色：配网=蓝, 倾听=青, 说话=绿, 休眠=灭
static void led_set(uint8_t r, uint8_t g, uint8_t b) {
    for (int i = 0; i < LED_NUM; i++)
        ESP_ERROR_CHECK(strip->set_pixel(strip, i, r, g, b));
    ESP_ERROR_CHECK(strip->refresh(strip, 50));
}
```
> 用 ESP-IDF 官方 `led_strip` 组件（RMT 后端），别用忙等 bit-bang；在 `idf_component.yml` 加 `espressif/led_strip`。

**(c) 与后端对接**：小智已内置 ASR+LLM+TTS 流式架构，震动/LED 通过**设备端 MCP** 暴露为"设备动作"（音量/灯光/电机/GPIO），后端或本地脚本调用即可，无需从零写 WebSocket。若要接自有后端，走小智的 WebSocket/MQTT+UDP 通道，改 `menuconfig` 里的服务器地址。

### 3.6 Soft-AP 配网（满足 NST-SPC-01）

- **路径 A**：小智自带 Soft-AP + 手机 captive portal 配网，**已满足**，零开发。
- **路径 B 进阶（加密 L1，防嗅探）**：ESP-IDF `network_provisioning` 组件，X25519+AES-CTR + PoP 持有证明（微信 BLE 扫码配网扩展包 `WeXin-BLE-Provison-for-xiaozhi-esp32` 基于此，商用成熟）。试点期用路径 A 即可，二期再上 L1。

### 3.7 固件任务架构（生产级，固件通要求）

```
app_main()
 ├─ nvs_flash_init()             // WiFi 凭证持久化
 ├─ wifi/soft-ap init            // 配网（§3.6）
 ├─ motor_init() / led_init()    // 外设（§3.5）
 ├─ xTaskCreate(audio_task)      // 小智音频链路（采集/播放，非阻塞）
 ├─ xTaskCreate(motor_task)      // 收事件队列→PWM 震动
 ├─ xTaskCreate(led_task)        // 收状态→灯环变色
 └─ xTaskCreate(provision_task)  // 长按用户键→进配网

通信：audio_task → xQueueSend(status_q) → led_task / motor_task
约束：
 • 所有外设 init 查 ESP_ERROR_CHECK，失败即停（不裸奔）
 • 任务栈用 uxTaskGetStackHighWaterMark() 验收（≥30% 余量）
 • 禁动态分配（init 后不用 malloc）；ISR 仅置事件位，活全丢给任务
 • 马达/灯刷新非阻塞，绝不 vTaskDelay 卡死音频
```
> 调试：崩溃看 `idf.py coredump-info`；栈溢出用 `uxTaskGetStackHighWaterMark`；日志 `ESP_LOGI`。

## 四、重点 3 · 组装方法与注意点

### 4.1 装配顺序（波波蛋，板竖放屏幕朝前当"脸"）

1. **打印外壳**（见 §五）：上下两壳 + 底圈 + 头顶触摸盖，先打半高验证件试装。
2. **预埋螺母**：用烙铁/热熔枪把 M2.5 热熔螺母压入上下壳螺丝柱（柱外径≥5mm，预孔 Φ2.0）。
3. **固定核心板**：板竖放，屏幕朝前"脸"位；用 3M 薄双面胶 + 螺丝固定于壳内板仓（内腔 ≥74×46×19mm，四周留 0.5mm 间隙）。
4. **喇叭朝下**：1811 喇叭在板底，正对壳底出音孔/音腔（壳底留空腔，避免贴死闷音）。
5. **贴震动马达**：马达贴壳壁（非贴板，否则共振噪），薄双面胶固定；焊好 S8050+1N4148 电路，线走扩展口 GPIO10/5V/GND。
6. **装 LED 环**：底圈槽位嵌入 WS2812 环（DIN 串 330Ω 接 GPIO11），热熔胶点固。
7. **理线出 Type-C**：USB-C 从壳底孔引出；线用扎带/热熔固定，防拉扯。
8. **合壳**：上壳（蛋顶）+ 下壳（蛋身）卡扣 + 磁吸 + M2.5 螺丝锁紧；头顶触摸盖轻压。
9. **通电验证**：插电 → 复位 → 进配网 → 对话 → 摸头顶/摇一摇看交互（见 NST-TSK-01 T-C0）。

### 4.2 焊接注意（新手高频翻车点）

- **共地第一**：马达/灯环的 GND 必须与 ESP32 GND 同一点，否则信号乱、灯闪。
- **马达必加续流二极管**：断电瞬间反峰会击穿三极管/IO，1N4148 反向并联（阴极接 5V）。
- **ESD 防静电**：摸板前摸金属放电；焊时烙铁接地；IMU/Codec 敏感。
- **别短接**：扩展口 5V 与 GND 别用镊子短接；焊完万用表蜂鸣查短路再上电。
- **GPIO 不直接驱马达**：见 §3.4，过三极管/L9110H。
- **焊点干净**：助焊膏后清洗，避免明天氧化接触不良。

### 4.3 结构注意

- **音腔**：喇叭下方留 ≥8mm 空腔 + 底/后出音孔（Ø2–3mm 阵列），否则声音闷。
- **配重**：蛋形重心高易倒，底圈加少量热熔胶/配重块降低重心。
- **卡扣+磁吸**：频繁拆处（底圈）用热熔螺母+螺丝，不用纯 PLA 卡扣（怕振松）；上下壳用磁吸+卡扣快拆。
- **触摸灵敏度**：头顶触摸区（板载用户键/电容触摸）对准壳顶薄壁（≤2mm），太厚摸不到。
- **IMU 朝向**：板竖放时 QMI8658 轴系对应"摇/翻"，固件里映射好（小智已处理）。

### 4.4 安全

- 5V/3.3V 隔离清晰，适配器选品牌（纹波小，音频不啸叫）。
- 喇叭功放 PA_EN 由板载 PCA9557(0x19) 控制，小智已驱动；二次开发别漏初始化 IO 扩展，否则无声。
- 长时间通电放在儿童房：外壳用 PLA+（低温无毒），避免 ABS（有味）；封闭腔打印机（P2S）才能打 ASA。

### 5.2 建模要求（波波蛋，内腔必须吃下硬件）

| 要素 | 要求 | 理由 |
|---|---|---|
| 内腔净尺寸 | ≥ **74(高)×46(宽)×19(深)mm** | 核心板 69×41×14 + 四周 0.5mm 间隙 + 壁厚 |
| 壁厚 | ≥ 2mm | 强度，防跌落裂 |
| 板仓 | 竖放卡槽 + 2×M2.5 螺丝柱 | 固定核心板屏幕朝前 |
| 出音孔 | 底/后 Ø2–3mm 阵列（≥6 孔）| 喇叭音腔出声 |
| Type-C 孔 | 底孔 9×4mm，单边间隙 0.3mm | 出线不卡 |
| LED 环槽 | 底圈 Ø 略大于灯环（≥Ø32mm 槽，深 3mm）| 嵌 WS2812 环 |
| 马达仓 | 侧壁小凹槽 12×12×4mm | 贴壁固定马达 |
| 头顶触摸盖 | 薄壁 ≤2mm，对应用户键 | 摸头唤醒 |
| 分件 | 上壳(蛋顶)+下壳(蛋身)+底圈+头顶盖 | 卡扣+磁吸+螺丝 |
| 圆角 | 内直角 R0.5–1mm | 防碎 |
| STL 导出 | 偏差 0.01mm、二进制、单位 mm | 防曲面变棱 |

### 5.4 打印步骤（先验证后整壳，防废壳）

1. 打 **校准件/benchy** 确认机器正常（1–2h）。
2. 打 **半高验证件**（只打下半壳到板仓高度）→ 装板试配 → 调内腔/孔位。
3. 验证 OK 再打 **整下壳 + 上壳 + 底圈 + 头顶盖**（每件 2–4h）。
4. 去支撑、砂纸打磨接缝、可上色/贴纸做 IP 外观。
