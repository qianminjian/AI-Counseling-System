## 1. 总体架构（分层）

系统采用分层架构，从前端到基础设施共 7 层，层间通过标准化接口通信。

| 层次 | 职责 | 技术方案（现行） |
|------|------|------|
| 前端层 | Web / H5 / 平板多端适配 | React 19 + TypeScript + Vite 8（三应用独立 npm 管理） |
| 负载均衡/网关层 | 流量分发、静态资源、反向代理 | **Nginx**（定稿：单体架构下不引入独立 API 网关） |
| 应用服务层 | 业务逻辑处理 | **Spring Boot 3 模块化单体（Maven 多模块）** |
| AI 编排层 | LLM 对话、RAG、情绪识别、风险管线 | **Spring AI（ChatClient）+ Service 层显式安全管线 + CTX-Agent 4 段式上下文简报** |
| AI 边车层 | 语音能力（ASR/SER/TTS） | **voice-service / tts-service（Python 独立容器，解耦加载）** |
| 端侧 AI 层 | 唤醒词 + 声纹识别（隐私优先） | **Transformers.js + Whisper-tiny/wespeaker ONNX（同源 WASM 自托管）** |
| 数据层 | 关系型/缓存/向量/文件存储 | PostgreSQL 16 + pgvector / Redis 7 / OSS |
| 基础设施层 | 计算、存储、网络 | Docker Compose（试点）/ Kubernetes（规模化） |

**架构实态**：系统是「Java 单体 + 2 个 Python AI 边车服务」（合理漂移：Python AI 生态不可替代，如 FunASR/CosyVoice/emotion2vec）。

### 2.1 技术栈（按实现实态）


## 4. AI 编排架构（世界 A 事实架构）

> **架构定稿**：线上对话唯一生效架构为**世界 A**——`ConversationServiceImpl` + `PromptOrchestrationService`（单 prompt 主线，SSE 流式）。原 7-Agent 星型编排（世界 B）已于 2026-07-29 整体删除（DEC-CBT 决策），其设计思路作为历史蓝图不再代表任何计划实现。

### 4.1 对话处理链（最终形态，🟩 含 CTX-Agent 上下文简报）

```
请求 → Service 安全前置（风险检测 + PII 脱敏 + 语义风险分类）
→ RED 硬短路（高危：跳过 LLM，返回 CrisisResources）
→ CTX-Agent 上下文简报（commit c9121a8，零 LLM 调用）
   ├─ §1 身份简报（昵称/年级/性别/对话次数/进入心情）
   ├─ §2 情绪旅程（进入心情 + 最近 5 轮语音情绪轨迹 + 趋势判断 + 状态机 + 缓解计数）
   ├─ §3 会话上下文（滚动摘要 + 主题线索 TopicHint + 长期记忆按主题相关性重排序）
   └─ §4 学生画像（provenance/confidence 过滤后的 StrategyProfile 输入）
→ Prompt 策略编排（SYS-001 + 年龄分层语言模板 + 性别风格 + 画像 + nudge + CTX 注入 System Prompt Layer 3）
→ LLM 流式生成（SSE，ResilientChatModel 主备降级 + LlmStreamEnhancer 超时/重试）
→ 输出审查（OutputContentFilter 关键词硬过滤 + OutputReviewService 语义审查）
→ 记忆/画像回注（会话摘要 + 7 维画像增量提炼 + 长期记忆向量化）
```

**CTX-Agent 设计要点**（落地于 `ConversationContextAgent.java`，详见 09 §八·五）：
- **零 LLM 调用**：纯规则拼接，每次推理 <10ms；
- **4 段结构**：身份/情绪/会话/画像，每段都有明确职责边界，避免重复注入；
- **情绪门控联动**：情绪旅程的最近轨迹驱动 EmotionStateMachine 漂移切换，间接影响 PromptOrchestrationService 的 `allowCbt` 决策；
- **占位符昵称防护**：检测"同学/某人/小朋友/学生"等占位符 → 提示 AI 询问真名，避免"哈喽同学"的泛化称谓；
- **当前交互能力感知**：TTS 静音/唤醒关闭等状态只前端知晓，未注入 LLM（已知盲点，待前端接入）。

> 定稿理由：显式调用的安全顺序在代码中可读可测（安全合规 > 一致性），儿童安全场景不宜把硬短路埋进框架回调链；Spring AI Advisor API 仍在演进。Advisor 链仅作目标态参考，不再作为待办。

### 4.2 LLM 编排层

| 模块 | 技术方案 | 说明 |
|------|------|------|
| 模型调用 | Spring AI `ChatClient` | 统一抽象层，LLM 供应商无关（决策 #7） |
| 供应商适配 | `ResilientChatModel` 主备降级 | 主 DeepSeek V4（关闭思考模式）→ 备 qwen-plus，主模型异常立即切换 |
| 流式增强 | `LlmStreamEnhancer` | 首 token 超时 12s（prod）/整体流超时 45s/瞬时失败重试 1 次（2s 退避）/超时降级安全话术；Supplier 模式确保重试时创建全新 LLM 调用 |
| Prompt 管理 | `PromptTemplate` 资源 + `prompt_versions` 版本管理 | 支持 A/B 测试分组、快速回滚 |
| 编排 | `PromptOrchestrationService` 单 prompt 编排 | 情绪门控/年龄分层/合规裁决/阶段指令注入 |

### 4.3 安全管线（Service 层显式调用）

| 环节 | 组件 | 职责 |
|------|------|------|
| 输入风险检测 | `RiskDetectorService` + `SemanticRiskClassifier` | 硬规则（10 类高危信号）+ 语义融合（`fuseRiskSignals`：文本 max 语音情绪 max 趋势） |
| PII 脱敏 | `PiiDesensitizer` | 手机号/身份证号等自动遮蔽后再传 AI |
| RED 硬短路 | 危机交互硬短路（SAFE-203） | 高危返回 CrisisResources（求助热线），跳过 LLM |
| 输出过滤 | `OutputContentFilter`（Layer1） | 关键词硬过滤 |
| 输出审查 | `OutputReviewService`（Layer2 异步） | 语义安全审查：不诊断/不治疗承诺/不药物建议/不强化负面 |

### 4.4 语音能力（Python 边车服务 + 端侧 WASM 同源自托管）

**Python 边车（云端 / 私有化推理）**：

| 服务 | 能力 | 引擎 |
|------|------|------|
| `voice-service` | ASR 双引擎 + 语音情感（SER）解耦并行 | ASR 主力 funasr SenseVoiceSmall（本地自部署，适合信创/私有化）/ 备用 dashscope Paraformer-V2（云端，低资源占用）由 `ASR_ENGINE` 环境变量切换；SER = emotion2vec_plus_large（~1.5GB）由 `SER_ENABLED` 独立控制；`ThreadPoolExecutor(max_workers=2)` + `executor.shutdown(wait=False, cancel_futures=True)` 并行执行避免串行 3-4s 等待 |
| `tts-service` | 语音合成三级降级 + 7 音色 + 8 方言 + 情感 Instruct | CosyVoice cosyvoice-v3-flash（云端 WebSocket 流式，首包 <800ms）→ edge-tts → 浏览器 speechSynthesis；v4 方言架构：原生方言（粤语 longjiayi_v3/longanyue_v3、闽南 longanmin_v3）自动生效 + 6 种 Instruct 方言（东北/四川/河南/山东/湖南/陕西）需 qiqiu 音色 |

**端侧 WASM 同源自托管（隐私优先 + 离线可用）**：

| 能力 | 模型 | 路径 | 引擎 |
|------|------|------|------|
| 唤醒词识别 | whisper-tiny (~20MB) | `/mindsafe/models/whisper-tiny/` | Transformers.js 动态 chunk |
| 声纹识别 | wespeaker (256-dim embedding) | `/mindsafe/models/wespeaker/` | Transformers.js ORT WASM |

- **同源加载**：nginx 在 `/mindsafe/models/` 路径提供模型文件；`WAKE_MODEL_REMOTE_HOST='SAME_ORIGIN'` / `VP_MODEL_REMOTE_HOST='SAME_ORIGIN'`；
- **预加载策略**：①登录页预加载声纹模型 + 情绪选择页预加载唤醒模型（commit d5d02bb + ef169e0 + 4f74ede）；②对话内首次触摸麦克风按钮后预热（替代挂载即预热，commit a6a2422），充分利用 TTS 播放窗口提前下载；
- **WASM/SIMD/SAB 兼容性**（commit a81dbf4 + a184b4b + 5a95baf + 67fb0c8 + bb6e537 + aa1102c + 5d0deb3）：① nginx 添加 COOP/COEP 头启用 SharedArrayBuffer；②禁用 asyncify 变体 + 入口 SW 清理；③`numThreads=1` ORT 单线程模式；④禁用 ORT 高级图优化（修复 `TransposeDQWeightsForMatMulNBits` 崩溃，commit 392a098）；⑤不支持 SIMD/SAB 时静默降级（不显示错误横幅+隐藏声音按钮）；
- **加载失败降级**：模型 404 → 隐藏唤醒开关/声音按钮；按住说话主路径不受影响。

### 4.5 情绪识别

- **文本情绪**：`EmotionStateMachine` / `EntryMoodStrategyResolver` + `PromptOrchestrationService` 情绪门控（7 类情绪 + 强度 + 置信度随消息上送）。
- **语音情绪**：voice-service SER 输出 voiceEmotion 随消息上送 → `fuseRiskSignals` 融合 + 连续消极趋势升级。
- **画像回注**：会话结束 → SQL 聚合 + LLM 增量提炼（7 维 JSONB 含 personality_traits）→ 下次对话 `buildProfilePrompt` 注入 System Prompt。

### 4.6 CBT 流程（世界 A 等价实现）

CBT 策略变体 + `CbtStageRouter` 启发式接线承担：阶段指令注入 system prompt + 年龄分层三态 + 容纳之窗门控 + state_path JSONB 按轮落库。流程主线：情境 → 感受 → 想法 → 行动（认知重构 + 微行动建议），无独立状态机。

## 5. 多租户架构（A 路线定稿：行级隔离）

### 5.1 租户模型：学校即租户

采用**学校（School）作为租户粒度**。业务边界清晰、数据敏感性高、配置差异大、支持私有化部署。

### 5.2 隔离策略（2026-07-28 定稿）

| 防线 | 实现 | 状态 |
|------|------|:---:|
| 行级过滤 | 所有实体统一带 `tenantId`；MyBatis-Plus `TenantLineInnerInterceptor`（`MindSafeTenantLineHandler`）自动注入 `AND tenant_id=?` | 🟩 |
| fail-fast 铁律 | 无租户上下文且未声明系统作用域（`runAsSystem`/`callAsSystem`）的业务表 DAO 调用直接抛 `IllegalStateException`；`tenants` 公共标识表恒忽略 | 🟩 |
| 系统作用域 | 合法跨租户链路（登录/注册/企微回调/定时任务）经 `TenantContextHolder.runAsSystem/callAsSystem` 显式声明；异步线程由 `TaskDecorator` 传播上下文 | 🟩 |
| Schema 级物理隔离 | 推迟至首个「要求强隔离」的付费学校签约前实施（expand-contract 迁移路径清晰）；BIZ-001 维持挂起 | ⬜（待需） |

> **隔离铁律**：TenantContext 未绑定时，任何进入持久层的查询必须快速失败抛异常，绝不允许「无租户条件」的查询穿透到数据库。
> **对外物料禁止使用"Schema 级/物理隔离"表述**，避免采购合同中形成虚假承诺。

### 5.3 认证与授权

- JWT 双 Token（Access + Refresh，含 iss/aud/jti，登出拉黑撤销）
- Token 绑定租户：解构 Token 时同步校验归属租户；跨校 API 调用返回 403 并记录安全审计
- RBAC：角色（student/teacher/head_teacher/admin/guardian）+ 数据权限（只能访问归属自己含下级的学生数据）
- SSO（钉钉/企微 OAuth）为预留能力，商用前随学校采购需求接入

### 5.4 学校级配置

| 配置类别 | 可配置项 |
|------|------|
| 品牌定制 | Logo、学校全称（≤20 字）、简称（≤10 字）、主题色 |

| 组件类别 | 技术选型 | 选型理由 |
|------|------|------|
| 前端框架 | React 19 + TypeScript + Vite 8 | 生态完善、类型安全 |

## 12. 性能与可靠性

### 12.1 错误处理与降级

| 失败场景 | 降级策略 |
|------|------|
| LLM 瞬时失败（网络抖动/限流/连接重置） | `retryWhen(Retry.backoff(1, 2s))` 自动重试 1 次；超时不重试 |
| 主模型异常 | `ResilientChatModel` 立即切换备用模型（qwen-plus），无等待 |
| 重试耗尽 + 备用失败 | 降级安全话术（"波波现在有点忙不过来…"） |
| TTS 三级降级 | CosyVoice → edge-tts → 浏览器 speechSynthesis |
| 风险检测失败 | 规则引擎（关键词）替代语义检测 |
| 情绪识别失败 | 返回中性情绪 |

### 12.2 超时控制

| 场景 | 超时 |
|------|------|
| 首 token | 12s（prod） |
| 整体流 | 45s |
| 学生端会话 | 单次 ≤20 分钟（对话限制）、每日 ≤30 分钟（未保法） |

### 12.3 缓存策略

| 缓存类型 | 内容 | TTL |
|---------|------|-----|
| 用户画像 | 基本信息、偏好 | 24 小时 |
| 情绪上下文 | 最近情绪分析结果 | 5 分钟 |
| 风险结果 | 相同内容检测结果 | 1 小时 |
