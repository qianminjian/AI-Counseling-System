# 二、学生心理画像（源：23、46）

> 最新方案口径：以 23 §9 深化实现（7 个 JSONB 维度、ProfileExtractorService 接线）与 46 落地记录（PROF-020~025、ProfileMergeGate 门控）为准。

## 2.1 设计目标

- **只存统计、不存原文**：画像中不保存聊天原文、不保存可还原对话的措辞，仅保存提炼后的统计特征与趋势（儿童隐私底线，与上卷第六章安全规范一致）。
- **自动迭代**：画像随对话持续自动更新，无需人工维护，形成"对话 → 提炼 → 画像 → 反哺对话"的闭环。
- **驱动个性化**：画像（而非年级猜的）决定回复风格、话题取材、CBT 推进节奏，是学生端"对谁说"的核心依据。
- **可删除**：学生/家长依据 PIPL 第 47 条（个人删除权）可随时清除画像数据，删除后从下一轮对话重新积累。

## 2.2 画像维度模型（6 维 × 18 子指标）

| 维度 | 子指标 | 内容 | 主要来源 |
|------|--------|------|---------|
| 情绪基线 | emotion_baseline | 情绪倾向、频率、强度、波动 | 情绪标签统计 |
| 沟通偏好 | communication_pref | 表达方式、是否愿意分享、回复长度 | 对话模式 |
| 韧性水平 | resilience | 应对困难的方式、恢复速度 | 情境分析 |
| 风险轨迹 | risk_trajectory | 风险情绪的历史与趋势 | 风险识别记录 |
| 社交图谱 | social_graph | 提到的人物关系（家人/朋友/老师）、亲近度 | 实体识别 |
| 成长轨迹 | growth_track | 兴趣、成就、变化、里程碑 | 长程观察 |

> 实施注记：画像实现中还会叠加第 7 维"需求信号"类字段（如微行动偏好）承载来自记忆回注的成长信号；字段以代码 `StudentProfile` 实体与 `student_profiles` 表为准（见 2.4）。

## 2.3 数据加工管线（P0 / P1 / P2 三阶段）

| 阶段 | 方式 | 内容 | 特点 |
|------|------|------|------|
| P0 规则聚合 | SQL/规则统计 | 情绪频次、词汇偏好、回复长度等结构化统计 | 确定性、零 LLM 成本、首日可用 |
| P1 LLM 提炼 | ProfileExtractorService | 从对话摘要中提炼性格倾向、韧性、兴趣（PROF-003/022/023） | 需质量门控与置信度标注 |
| P2 长期积累 | 跨会话归并 | 里程碑、成长轨迹、跨会话趋势 | 时间越长越准 |

- **分层写入**：P0 结果直接写入画像字段；P1/P2 结果经 2.6 合并门控（ProfileMergeGate）校验后才可写入。
- **记忆回注**：MemoryProfileBackfillService 将长期记忆中确认的里程碑/关键人物/负面主题/情绪事件回注画像对应维度（provenance=memory），见第四章 4.6。
- **画像读取聚合出口**：SessionEndAnalyticsService 在会话结束时聚合画像更新事件，供画像服务批量消费，避免会话中反复写库。

## 2.4 存储模型（student_profiles 表 + 7 个 JSONB）

> 以实现为准：画像数据存放于 `student_profiles` 表，七个维度 JSONB 字段承载（情绪基线、沟通偏好、韧性、风险轨迹、社交图谱、成长轨迹、需求信号），外键关联 `student_id`。字段内扩展见 2.5。

```sql
-- 结构示意（实现为准）
CREATE TABLE student_profiles (
    student_id      BIGINT PRIMARY KEY REFERENCES student(id),
    emotion_baseline     JSONB NOT NULL DEFAULT '{}',  -- 情绪基线
    communication_pref   JSONB NOT NULL DEFAULT '{}',  -- 沟通偏好
    resilience           JSONB NOT NULL DEFAULT '{}',  -- 韧性水平
    risk_trajectory      JSONB NOT NULL DEFAULT '{}',  -- 风险轨迹
    social_graph         JSONB NOT NULL DEFAULT '{}',  -- 社交图谱
    growth_track         JSONB NOT NULL DEFAULT '{}',  -- 成长轨迹
    need_signals         JSONB NOT NULL DEFAULT '{}',  -- 需求信号（含记忆回注）
    updated_at      TIMESTAMPTZ NOT NULL DEFAULT now()
);
```

## 2.5 字段级元数据（provenance / confidence / decay）

每个画像字段除取值外，携带三层元数据（PROF-020/021，JSONB 内扩展）：

| 元数据 | 取值 | 含义 |
|--------|------|------|
| provenance | `rule_agg` ｜ `llm_extract` ｜ `scale` ｜ `teacher_input` ｜ `memory` ｜ `voice_ser` | 数据来源，决定信任权重与审计路径 |
| confidence | 0~1 | 提炼置信度；低于 0.5 的信号不写入（PROF-025，ProfileSignals.MIN_CONFIDENCE） |
| decay | 半衰期天数 | 情绪类 60 天、偏好类 180 天；超期自动衰减，极低置信度字段归档不参与注入 |

- **来源可信度排序**：`teacher_input > scale > rule_agg > llm_extract > memory > voice_ser`（教师显式输入最可信，语音情绪单点推断最需保守）。
- **写入限制**：单次写入批次封顶 10 次更新（ProfileMetaStamper），防画像被单次对话污染。**审计登记（2026-08-12，audit-report-03 P2-1）**：代码 ProfileMetaStamper 未实现该封顶，当前单次写入无批次上限，设计意图保留待实现，状态改为「待实现」

## 2.6 画像合并门控（ProfileMergeGate 四规则）

所有 P1/P2/记忆回注信号写入前，经合并门控校验：

| 规则 | 机制 | 目的 |
|------|------|------|
| 置信加权合并 | 新值与旧值按置信度加权融合 | 低置信新值不足以推翻长期结论 |
| 冲突检测 | 同字段新旧值差异 > 0.4 时，高置信者胜出，冲突留痕 | 防止单次异常对话改写画像 |
| 半衰期衰减 | 情绪类 60 天 / 偏好类 180 天半衰期；极低置信字段直接归档 | 画像随时间自然过期，不做永久结论 |
| 污染防护 | 对画像更新做 EMA（平滑系数 0.4） | 抑制异常对话冲击，防止画像被单一情绪事件带偏 |

> 实现状态（O 专题 S2，2026-08-05）：半衰期衰减与污染防护的编码实现（ProfileMergeGate.applyDecay/isExpired）经零调用验证为死分支已删除，冲突阈值 0.4 与 EMA 平滑系数参数保留待数据回流（设计意图不变）。
> **审计登记（2026-08-12，audit-report-03 P1-8）**：ProfileMergeGate 规则 4 返回 "REPLACE" 实为 EMA 置信加权实现（L62-67），命名与本节 EMA 描述不一致；行为与设计意图一致，命名差异登记待后续统一。

## 2.7 画像质量四维评估

| 维度 | 定义 | 保障机制 |
|------|------|---------|
| 完整性 | 六维度覆盖度 | 缺字段时系统 Prompt 提示波波主动收集（如"你平时喜欢做什么？"） |
| 时效性 | 画像与近期行为一致 | 半衰期衰减 + 过期归档 |
| 置信度 | 字段可信程度 | 来源排序 + MIN_CONFIDENCE 门槛 |
| 一致性 | 与对话事实不矛盾 | 冲突检测 + 合并门控 |

## 2.8 Prompt 注入规则

| 情形 | 注入规则 |
|------|---------|
| 对话次数 < 3 | 只注入简化版画像（年级/昵称/情绪基线粗粒度），防误导 |
| 对话次数 ≥ 3 | 注入完整版画像（六维摘要 + 沟通偏好 + 风险轨迹趋势） |
| risk_trajectory 呈 rising | 注入时追加关怀提醒（守护模式），并与风险模块联动 |
| 敏感话题（sensitive_topics） | 注入为提问方向约束而非事实陈述（防复述隐私，上卷 6.2 隐私套取防护） |

## 2.9 画像 → StrategyProfile 映射（编排层消费）

画像经映射生成编排层（上卷第九章）的 StrategyProfile 决策参数：

| 画像字段 | 映射策略 | 消费方 |
|----------|---------|--------|
| preferred_style | → 回复风格（简洁/故事化/直白） | 编排回复风格 |
| communication_pref | → 主动程度（话多 → 少主动、话少 → 多主动） | 冷场决策（第七章 7.6） |
| coping_skills | → 微行动建议取材（画画/深呼吸/运动等） | 心理工具箱推荐（上卷第十章） |
| sensitive_topics | → 提问方向约束 | 编排提问生成 |
| risk_trend = rising | → 守护模式（开启关怀提醒、收敛刺激性话题） | 风险模块联动 |
| expression_depth | → 表达深度（L1/L2/L3） | 编排策略（上卷 9.x） |
| dominant_interests | → 话题取材池 | 编排开场/镜映 |
| mood_baseline | → 情绪镜映话术素材 | 编排 EMO 镜映（上卷 9.x） |

**策略优先级链（冲突时谁先谁后）**：

```
合规安全 > 情绪稳定 > 年龄适配 > 性格适配 > 画像个性化 > 兴趣取材
```

- 任何画像个性化都不得突破儿童安全与情绪稳定底线（上卷第四章 CBT 风险回退、第六章安全规范优先）；
- 年龄适配（第三章）高于性格适配：语言难度必须服从有效年龄，性格只调整语气。

## 2.10 效果回收与自校准

- **画像有效性追踪**：ProfileEffectivenessTracker（PROF-024）追踪"基于画像的回复"是否改善对话效果（学生回复率、情绪正向迁移）。
- **自校准规则**：某画像字段连续 3 次基于它的策略未带来改善 → 该字段置信度降低一档；降至门槛以下后停止参与注入，直至新证据出现。
- **避免循环依赖**：画像只影响策略选择，不参与效果标注本身（效果标注来自学生行为信号，如是否回复、情绪标签迁移）。

## 2.11 隐私与删除权

| 项 | 规则 |
|----|------|
| 最小化 | 只存统计特征，不存原文、不存可还原对话的措辞 |
| 删除权 | 学生/家长可一键清除画像（PIPL 第 47 条）；删除后下一轮对话重新积累 |
| 审计 | 画像写入事件留痕（provenance 全程可追溯） |
| 隔离 | 画像随租户/学校数据隔离（SaaS 多学校隔离架构） |
| 不告知 | 画像内容不对学生展示推导理由，避免"被看穿"感；如需展示仅展示统计化结论 |

# 三、画像与年龄适配（源：29）

> 最新方案口径：三层方案（年级解析层/策略适配层/动态降级层）**全部落地** 🟩，五个断裂点（年级解析、语言模板、性别适配、性格适配、动态降级）均已修复，以本卷描述为定稿。

## 3.1 设计目标

- **同一年级不同年龄**：小学入学年龄漂移（9 月后出生晚一年入学）导致同年级实际年龄差可到 2 岁，语言与认知适配必须基于**有效年龄**而非单纯年级。
- **性格 ≠ 年级**：两个同岁孩子（一个内向一个外向）需要不同的对话策略；性格维由画像（第二章）补充建模。
- **先适配再个性化**：年龄适配是地基，个性化（画像）是上层——优先级链见 2.9。

## 3.2 年级解析层（gradeCode）

| 项 | 规则 |
|----|------|
| 数据 | `Student.gradeCode`（G1~G6） |
| 解析 | 非法/缺失时按默认值处理 |
| 默认值 | grade=4（四年级），保证任何脏数据都能兜底且不出错 |
| 边界 | 年级边界校验（≤G6 小学上限），防止越界注入 |

## 3.3 语言模板三档（按有效年龄选档）

> 模板为定稿全文（已实现）：低龄档 ≤50 字/句，中档 ≤80 字，高档允许认知三角论证。

| 档位 | 适用 | 句长限制 | 语言特征 | 定稿模板示例 |
|------|------|---------|---------|-------------|
| 低龄（1-2 年级） | effectiveGrade ≤ 2 | ≤50 字 | 短句、具象词、无抽象概念 | "你可以和我说说，今天在学校有没有开心的事呀？" |
| 中龄（3-4 年级） | effectiveGrade 3-4 | ≤80 字 | 可含简单比喻，情绪温度计表达 | "把心情想成一个温度计，现在它在哪里呀？可以告诉波波吗？" |
| 高龄（5-6 年级） | effectiveGrade ≥ 5 | ≤120 字 | 可含认知三角（想法-感受-行为） | "有时候一个想法会让心情变化，比如'我肯定做不好'。你觉得呢？" |

## 3.4 性格建模四维（personality_traits）

| 维度 | 取值 | 来源 |
|------|------|------|
| introversion | 0~1 内向度 | 画像 LLM 提炼 + 行为统计 |
| sensitivity | 0~1 敏感度 | 画像 + 风险信号 |
| curiosity | 0~1 好奇心 | 画像兴趣维度 |
| dominant_interests | 枚举（画画/运动/游戏/动物…） | 画像成长轨迹 |

## 3.5 性格 → 策略映射（阈值 ≥ 0.7 触发）

| 特征 | 判定 | 策略 |
|------|------|------|
| 内向 | introversion ≥ 0.7 | 开场用低压力话题、给足思考留白（与第七章冷场模型联动） |
| 外向 | introversion ≤ 0.3 | 可用开放式游戏化提问、适当加快节奏 |
| 高敏感 | sensitivity ≥ 0.7 | 避免直接评价性语言、委婉反馈 |
| 高好奇 | curiosity ≥ 0.7 | 多用探索性问题、知识类话题 |
| 兴趣明确 | dominant_interests 非空 | 话题取材优先兴趣（编排层消费） |

> 阈值语义：低于 0.7 视为中性，不触发特殊策略（避免过度个性化）；所有性格策略不得改变安全底线与合规优先级（2.9 优先级链）。

## 3.6 性别 × 年龄九格矩阵

> 性别以学生自选/班级信息为准，不强制二元；矩阵仅作话题引导参考，不作能力假设。

| 性别 \ 档位 | 低龄（1-2 年级） | 中龄（3-4 年级） | 高龄（5-6 年级） |
|-------------|----------------|----------------|----------------|
| 男 | 游戏/动物/恐龙话题开场 | 运动/科技/冒险话题 | 兴趣小组/挑战类话题 |
| 女 | 玩偶/画画/家人话题 | 朋友关系/创作话题 | 同伴压力/自我认同话题 |
| 未选择 | 通用话题池（动物/节日/校园日常） | 通用话题池 + 双选项提问 | 通用话题池 + 引导式提问 |

## 3.7 动态降级层（computeEffectiveGrade）

当画像/对话信号显示孩子语言水平明显低于年级时，**只降不升**，动态降低有效年龄：

| 信号 | 降级幅度 |
|------|---------|
| 理解度 < 0.3（连续） | 降 2 级 |
| 理解度 < 0.15（极低） | 直达 1-2 级低龄档 |
| 风险场景 | **不降级**（风险话术必须清晰准确，不得用低龄模糊表达） |

- **computeEffectiveGrade 输入**：年级 + 画像语言能力信号 + 对话理解反馈；输出 effectiveGrade 供模板选档、CBT 推进深度、工具推荐等全局消费。
- **降级只降不升**：有效年龄下调后不自动回升（需教师/家长显式确认），避免来回切换破坏一致性（YAGNI 闭环）。
- **与 CBT 联动**：effectiveGrade 决定上卷第四章 CBT 的提问深度与工具复杂度；高龄档才能进入认知三角类 CBT 技术。

## 3.8 遗留盲点（已知，接受）

|------|------|------|

| 降级不回升 | 语言能力实际提升后无法自动升档 | YAGNI：显式人工确认机制保留，自动回升不实现 |

# 四、长期记忆增强（源：50）

> 最新方案口径：以 50 落地记录（LongTermMemoryService、MEM-101、五断链 M1-M5 修复）与画像回注契约为准；历史文档中 AI-008 的虚标描述已更正为 MEM-101。

## 4.1 设计目标

- **让波波记得**：跨会话记住孩子说过的关键信息（宠物名字、家人、兴趣爱好、重要经历），对话有连续性。
- **泛化存储**：记忆按"主题/实体/情绪事件"结构化存储，非原文复述（儿童隐私与安全规范，上卷第六章）。
- **不硬灌**：相关性不足时宁可不注入，不为了"用记忆"而打断对话自然度。
- **可遗忘**：孩子说"不想让波波记住"时必须遗忘（情感安全底线）。

## 4.2 三层记忆架构

| 层 | 载体 | 生命周期 | 用途 |
|----|------|---------|------|
| 短期（ChatMemory） | 会话内上下文 | 单会话 | 当前对话连续性 |
| 中期（主题记忆） | 会话摘要（SessionSummary） | 会话中每 4 轮滚动更新（SessionSummaryUpdater @Async，SUMMARY_INTERVAL=4）+ 会话结束归档 | 话题承接、主题聚类输入 |
| 长期（LongTermMemory） | 结构化记忆条目 | 跨会话（可淘汰） | 个性化回注与召回复用 |

## 4.3 LongTermMemoryService（提取/存储/召回）

| 环节 | 机制 |
|------|------|
| 提取 | 会话结束从摘要中提取可结构化记忆（实体/主题/情绪事件），经置信度门槛写入 |
| 存储 | 记忆条目含：类型、关键字段、时间戳、recall_count（被召回次数） |
| 召回 | 新会话开始时 top5 回注；按相关性排序，无关不注入 |
| 淘汰 | 总量上限 50 条；超出按 4.9 遗忘机制淘汰（LRU + 低价值优先） |

## 4.4 相关性召回升级（加权评分）

召回评分 = w1·相关性 + w2·importance + w3·时效 + w4·recurring：

| 因子 | 权重 | 语义 |
|------|------|------|
| 相关性 | w1 | 与当前话题向量相似度（复用 EmbeddingModel，不新增模型） |
| importance | w2 | 记忆条目重要度（情绪事件 > 事实信息） |
| 时效 | w3 | 近期记忆优先（EMA 衰减） |
| recurring | w4 | 反复出现的主题加权（recurring_theme 命中） |

- **无相关不硬灌**：所有因子合计低于阈值时不注入任何记忆，保持对话自然；
- **复用能力**：向量化复用现有 EmbeddingModel，零新增外部依赖。

## 4.5 MEM-CTX 注入与 continuity 评估

- **注入格式**：以 `MEM-CTX` 系统指令段注入（与 Prompt 模板库保持一致），内容为结构化摘要而非原文。
- **continuity 评估**：会话结束时评估"记忆注入是否带来连续性提升"（是否命中上轮话题、是否提及旧实体），评估结果反哺 4.7 聚类权重。

## 4.6 记忆 → 画像回注契约（provenance=memory）

长期记忆与画像（第二章）互哺，回注契约：

| 记忆类型 | 回注画像字段 | 说明 |
|----------|-------------|------|
| 里程碑（获奖/学会新技能） | growth_track | 成长轨迹更新 |
| 关键人物（家人/好友） | social_graph | 社交图谱补充 |
| 负面主题（反复出现的不安） | risk_trajectory | 风险轨迹趋势参考 |
| 情绪事件（重大情绪波动） | emotion_baseline | 情绪基线校准 |

- 回注统一标注 `provenance=memory`，经画像合并门控（2.6）校验后写入；
- 回注只写画像统计字段，不写原文（与 2.1 隐私底线一致）。

## 4.7 recurring_theme 聚类

- **机制**：对历史记忆做向量 + 关键词双重聚类，同一主题出现次数达阈值时聚合为 recurring_theme（如"总是提到数学考试"）。
- **消费**：① 进入 w4 召回加权；② 注入 Prompt 供波波自然提起（"你最近好像常说到数学考试"）；③ 高风险主题联动 4.8。

## 4.8 风险关联（教师关注信号）

- **负面加剧检测**：同一负面主题反复出现且强度递增时，生成**教师关注信号**（teacher_attention）——非实时报警，仅在下一次教师侧查看时呈现（避免过度干预，与风险模块分级一致）。
- 联动：risk_trajectory rising 时升级为守护模式（2.9），高等级风险仍走实时报警通道（上卷第五章）。

## 4.9 遗忘机制（四维）

| 维度 | 机制 |
|------|------|
| 时效 | EMA 衰减：久未命中的记忆分值下降 |
| 敏感度 | 高敏感内容（隐私相关）默认低驻留、可快速淘汰 |
| 学生意愿 | 孩子明说"不想让波波记住"→ 该条目立即删除，且不重新提取同类内容（意愿记录保留） |
| 数量 | 总量 50 条上限，超出淘汰低价值 |

## 4.10 落地记录与任务归口

| 任务 ID | 内容 | 状态 |
|---------|------|------|
| MEM-101 | LongTermMemoryService（提取/存储/top5 召回/50 条淘汰/recall_count） | 🟩 已生效 |
| 五断链 M1-M5 | 提取→存储→召回→注入→回注五环节断链修复 | 🟩 已修复 |
| 相关性召回升级 | w1~w4 加权 + 复用 EmbeddingModel | 🟩 已生效 |
| MEM-CTX 注入 | 注入格式 + continuity 评估 | 🟩 已生效 |
| MemoryProfileBackfillService | 记忆→画像回注（4.6 契约） | 🟩 已生效（见 2.12） |
| recurring_theme 聚类 | 向量+关键词聚类 | 🟩 已生效 |
| 风险关联 | 负面加剧→教师关注信号 | 🟩 已生效 |

# 五、语音情感分析（源：54、47）

> 最新方案口径：以 54 实现现状（ASR/SER 解耦、SER_ENABLED 独立控制）与 47 落地记录（VCL-001/002/003、BL-08 通道）为定稿；47 设计期的 voice_emotion_trend 独立表已按 KISS 不建，趋势数据由 risk_events 承载。

## 5.1 设计目标

- **听见情绪**：从孩子语音中识别情绪（生气、难过、害怕、开心等），作为对话策略输入。
- **与文本互补**：文本表达不了的声音特征（哭腔、颤抖、激动）由语音侧补齐；两者冲突时按共情规则处理（5.5）。
- **数据闭环**：识别结果回注画像、趋势进风险通道，形成"识别 → 融合 → 回注 → 校准"闭环。

## 5.2 架构：ASR / SER 解耦（双引擎）

| 能力 | 引擎 | 部署 | 控制 |
|------|------|------|------|
| ASR 语音转写 | DashScope Paraformer-V2 / SenseVoiceSmall（**定稿为 SenseVoiceSmall**） | 云端可选 + 本地 | 独立开关 |
| SER 情绪识别 | emotion2vec_plus_large | **本地 CPU 推理** | `SER_ENABLED` 独立控制 |

- **解耦原则**：ASR 与 SER 互相独立、并行执行——SER 失败不影响转写，反之亦然；SER 可单独关闭（隐私/性能降级）。
- **接口形态**：识别结果 `voiceEmotion` + `voiceEmotionConfidence` 随 `SendMessageRequest` 一并上送，后端消费（无独立音频上传链路）。
- **SER 输入**：使用孩子说话音频片段，ASR 与 SER 并行处理同一段音频，互不阻塞。

## 5.3 情绪分类映射（SER 9 类 → 规范集）

SER 原始 9 类情绪映射到 44 规范情绪集（VCL-001，`mapVoiceEmotion`）：

| SER 原始类别 | 映射 | 说明 |
|--------------|------|------|
| happy | → 开心 | 正向信号 |
| angry / disgusted | → 生气 | 高唤醒负面 |
| fearful / sad | → 难过/害怕 | 低唤醒负面 |
| surprised | → 结合文本判定 | 语音惊讶可能伴随积极或消极，交由文本融合 |
| neutral | → 中性 | 无倾向 |
| other / unknown | → 忽略 | 不注入，防止噪声污染画像 |

- 识别结果以 `SessionState.currentEmotion` 缓存供编排层消费（VCL-001）；
- 覆盖率：ai.voice 包测试覆盖率 99.2%。

## 5.4 多信号融合与风险联动

**融合规则（max 语义，保守取高）**：文本情绪与语音情绪同时存在时取强度更高者：

| 信号 | 强度 | 风险贡献 |
|------|------|---------|
| angry/disgusted | 高唤醒负面 | +1（黄） |
| fearful/sad | 低唤醒负面 | +2（橙） |
| 连续 3 轮 conf > 0.7 | 持续负面 | 升级 ORANGE |
| 连续 5 轮负面 | 长期负面 | 升级 RED |

- **趋势报警**：TrendAnomalySignaler（VCL-003）检测情绪持续恶化时，落 `risk_events`（`riskType=voice_trend:CONTINUOUS_WORSENING`），不建独立趋势表（KISS）；
- 风险通道完整复用上卷第五章分级体系，语音趋势作为附加信号源。

## 5.5 共情融合策略（文本 vs 语音不一致时）

| 情形 | 策略 |
|------|------|
| 文本与语音情绪一致 | 按该情绪执行镜映与策略（上卷 EMO 镜映） |
| 文本平静、语音难过（掩饰） | 温和探询**不拆穿**："听起来你好像有点累，愿意跟波波说说吗？" |
| 语音情绪无效/不可用 | 回退文本情绪，正常流程 |
| 任一通道风险信号高 | **始终取 max**（风险优先于共情，不因掩饰降低风险等级） |

## 5.6 多模态不一致检测

- **情绪掩饰倾向信号**：文本-语音情绪不一致（如文本说"没事"、语音难过）累计达到阈值时，记为掩饰倾向（masking tendency），供守护模式（2.9）与教师关注信号（4.8）参考。
- 检测只作弱信号，不直接触发报警（避免误判）。

## 5.7 两级趋势分析

| 层级 | 内容 | 载体 |
|------|------|------|
| 会话内曲线 | 单次会话情绪走向（上升/平稳/恶化） | VoiceEmotionTrendAnalyzer 纯函数（VCL-002） |
| 跨会话趋势 | 多会话情绪基线迁移 | 画像 emotion_baseline 更新（provenance=voice_ser）+ risk_events 趋势记录 |

- 会话内恶化 → 5.4 趋势报警；跨会话恶化 → 画像风险轨迹 rising → 守护模式。

## 5.8 标注回流与阈值自适应

- **弱标签三来源**：① 文本-语音一致的对话自动形成正样本；② 教师事后标注；③ 不一致难例（保留供人工复核）。
- **评估**：定期计算混淆矩阵，监控 SER 各类别误判率；
- **阈值自适应**：误判率高的类别提升置信度门槛（防止该类噪声注入画像），阈值变更留痕。

## 5.9 隐私与合规

| 项 | 规则 |
|----|------|
| 音频不落盘 | 音频仅用于实时识别，处理完即弃（审计中该项列为**核对项**，上线前逐行核对确认无缓存路径） |
| 本地优先 | SER 本地 CPU 推理，音频不出学校机房 |
| 独立开关 | SER_ENABLED 可单独关闭，关闭后仅文本情绪 |
| 回注标注 | 语音情绪回注画像统一 provenance=voice_ser（低信任权重，见 2.5） |

## 5.10 落地记录与任务归口

| 任务 ID | 内容 | 状态 |
|---------|------|------|
| VCL-001 | mapVoiceEmotion 9 类映射 + SessionState.currentEmotion 缓存 | 🟩 已生效 |
| VCL-002 | VoiceEmotionTrendAnalyzer 纯函数（会话内曲线） | 🟩 已生效 |
| VCL-003 | TrendAnomalySignaler → risk_events（source_type=attention / risk_level=YELLOW） | 🟩 已生效 |

# 六、TTS 与多音色（源：48、56、37）

> 最新方案口径：音色以 **56 的 7 音色矩阵为定稿**（升级替代 28 §4 的四音色方案）；情绪信号源与风险语音以降级策略以 37 为准；人设匹配以 48 的 VoicePersonaResolver 落地为基准。

## 6.1 设计目标

- **统一情绪信号源**：AI 回复只产出一个 `{text, emotion, riskLevel}` 结构，同时驱动 TTS 服务、波波表情、微动效三路消费，保证"说的内容、声音情绪、表情状态"三方一致（三方同源原则）。
- **音色匹配人设**：音色随学生年龄/性格/性别偏好自动匹配（冷启动规则），不要求孩子理解"音色参数"。
- **情感可表达**：语音情绪随内容情绪变化（开心活泼、难过温柔），且低龄档语速更慢、停顿更长。
- **风险不降级**：安全/危机场景锁定温柔安抚音色与最慢语速，任何情况语音不得惊慌急促（上卷红线）。

## 6.2 统一情绪信号源（ReplyEmotionResolver）

## 6.8 三级降级链（CosyVoice v3-flash → edge-tts → 前端兜底）

```
一级：CosyVoice（阿里云百炼 DashScope SDK WebSocket 流式，模型 cosyvoice-v3-flash，云端）
  ├─ Instruct（方言/情感）失败 → 无指令重试（保留音色品质）
  ├─ 不可用/超时（TTS_SYNTHESIZE_TIMEOUT=30s）/失败 →
二级：edge-tts（方言仅东北/陕西有对应音色；其余方言降为普通话）
  └─ 仍失败（含 30s 超时防挂死）→
三级：HTTP 503 → 前端自动降级浏览器 speechSynthesis（非静默）
```

- **超时防护（P1-DEP）**：DashScope SDK 阻塞 call() 在线程中执行，`asyncio.wait_for` 兜底 30s，SDK 线程挂死/网络黑洞不会永久挂起请求，超时自动降级或 503；edge-tts stream() 同样超时保护
- **监控（P1-10）**：Prometheus 文本指标 `tts_synthesize_requests_total{engine=cosyvoice|cosyvoice_fallback|edge_tts|error}`、`tts_synthesize_duration_seconds`、`tts_engine_available`，供监控栈 internal 网络抓取
- **CORS 安全收敛**：默认拒绝跨域，确需前端直连用 `TTS_CORS_ORIGINS` 显式白名单（禁止 *）
- **配置外置（CFG-004）**：模型/音色/方言/情感映射从 config.yaml 加载，环境变量覆盖（`DASHSCOPE_TTS_MODEL`）
- **离线备选**：不做端侧神经 TTS（包体过大），采用**预合成话术包**（30 句 × 4 音色 < 8MB），覆盖高频场景离线可用（未实现）；
- **音频缓存**：缓存键 = hash(text + persona + emotion + speed)，同参数不重复合成；
- edge-tts 降级出网合规按系统配置文档（22 §6.3）处理。

## 6.9 风险场景语音（VoiceDegradationPolicy，TTSFX-001）

| 风险等级 | 语音策略 |

| S3（无风险） | 正常情绪语音 |
| S2（低风险） | soothe/calm 情绪，语速下限 0.92 |

## 7.5 儿童语音 UX 10 原则 + 近同伴原则（55 上位原则）

| # | 原则 | 实现 |
|---|------|------|
| 1 | 包容性 | 主题/音色自选不强制 |
| 2 | 给予控制感 | 可暂停/重播/切换音色/静音 |
| 3 | 安全 | 无惊吓元素；风险场景语音极度温柔 |
| 4 | 灵活 | 纯文字/纯语音/混合模式 |
| 5 | 理解用户 | 情绪识别驱动语音风格 |
| 6 | 鼓励互动 | 语音结尾带引导性问句 |
| 7 | 允许探索 | 音色/主题自由尝试无惩罚 |
| 8 | 恰当表达 | 表扬努力而非天赋（"你很勇敢"而非"你真聪明"） |

## 7.6 语音唤醒（28 定稿）

### 7.6.1 唤醒词与授权（已定稿）

- **唤醒词定稿**：主唤醒词"你好波波" + 同音变体"哈喽波波"（归一化匹配：小写 + 去标点空白；`config/wakeWord.js` 的 WAKE_PATTERNS）；
- **授权定稿（B 分层告知）**：学生端用童语化简句（"波波会用耳朵听你叫它，只在你的设备上，不上传；离开对话就不听了"）；22 号文档保留技术性完整说明；
- **监听范围（隐私即设计）**：唤醒引擎只在**进入对话后**启动（会话创建 → ChatRoom 挂载），离开对话立即释放麦克风；登录前、情绪选择页一律不监听；登录页无被动监听（声音登录为按钮显式触发）。

### 7.6.2 唤醒状态机（🟩 commit 689d6dd 加固：即时反馈+状态锁+首轮过滤）

```
off → standby（开关+授权+引擎就绪）→ active（命中唤醒词）
active：自由对话，冷却 25s 无说话 → standby（TTS 温柔收尾"我先安静陪着你，想说话随时叫我哦"）
任意态 → off：关闭开关/离开对话/引擎出错（释放麦克风）
```

- **防自听回声**：TTS 朗读期间暂停识别，播完才重启聆听；
- **iOS 稳健性**：每回合独立 SpeechRecognition 实例（比常驻 continuous 更稳）；
- **问候引导**：问候语带昵称（"哈喽，小明！…"），自然引导孩子回应"你好波波"（buildGreeting 增加 pseudonym 参数）。
- **状态机加固（commit 689d6dd）**：
  - **状态锁/冷却**：active 后冷却 25s（`useVoiceCallMode` COOLDOWN_SECONDS），冷却期内无说话 → TTS 温柔收尾回 standby，避开自听回声循环（TTS 声音被识别为再次唤醒）
  - **首轮过滤**：active 后首轮 SpeechRecognition 结果过滤唤醒词残留（`useVoiceCallMode` firstRoundRef，避免对话内首句被唤醒词识别干扰）
  - **即时反馈**：命中唤醒词立即语音+动效反馈，不等后续词，避免孩子重复叫喊
- **串行识别防积压（当前实现，A4 重构后替代 continuous 模式）**：`useWakeWord` 串行识别——上一窗未识别完不提交新窗，识别慢时丢弃过老的积压音频（保最新窗）
- **识别参数（config/wakeWord.ts 当前值）**：WAKE_WINDOW_SECONDS=2.0 滑窗 + WAKE_KEEP_SECONDS=1.5 保留窗 + SILENCE_RMS_THRESHOLD=0.03 VAD 静音预过滤（静音窗跳过转写，抑制 Whisper 静音幻觉）
- **占位符昵称过滤（2026-08-01，9200b83）**：孩子未告知名字前 buildGreeting 不硬塞昵称——「某人/同学/小朋友/学生/user/test/测试/匿名/unknown」9 个占位词判定为**非真实姓名**（`ConversationUtils.buildGreeting` 内嵌过滤 + `ConversationContextAgent.isPlaceholderName`（L339）同规则），不使用占位词称呼；会话内自述 realName 经 `extractPersonalInfo` 提取后下一轮起用真名称呼（会话级，结束销毁）。

## 7.7 冷场决策模型（28 定稿）

### 7.7.1 模型输出与信号

**输出**：warmthLevel（0=留白 / 1=轻陪伴 / 2=引导破冰）+ direction（往哪个方向说）。

| 信号 | 来源 | 影响 |
|------|------|------|
| A 情绪唤醒度 | emotionTag + 语音情绪 | 高唤醒负面先留白；恐惧只轻陪伴；低落适时轻陪伴 |
| B 沉默时长 | 距上次互动 | <25s 留白；25-45s 轻陪伴；>45s 破冰 |
| C 上一轮类型 | 对话历史 | 上一轮为提问则留白（给作答时间），为陈述可轻陪伴 |
| D 会话阶段 | SessionState | 开场/结尾不暖场；情绪倾诉阶段轻陪伴 |
| E 风险硬门槛 | 风险等级 | 风险场景**禁止破冰玩笑**，仅温柔陪伴 |
| F 画像沟通偏好 | 画像 | 话多（≥0.6）→ -1 偏留白；沉默（≤0.4）→ +1 偏主动 |

**评分**：warmScore = B + C + D + F；≤0 留白、=1 轻陪伴、≥2 破冰。

**direction 六情形表**：依情绪场景/上一轮类型决定方向——难过→陪伴方向、开心→分享方向、中性+冷场久→轻松小问题（破冰）、紧张→低压力话题、风险→安抚陪伴、收尾→收束句。

### 7.7.2 nudge 接口与护栏

- **接口**：`POST /nudge { silenceSeconds }`（后端计算，复用现有 SSE/TTS/安全过滤管线）；留白时返回空 SSE 流；
- **护栏**：nudgeCount 上限、lastNudgeAt 间隔（≥20s）、连续暖场 <2 次后转安静陪伴、chatProactive 不写伪造学生消息、复用双层安全过滤；
- **触发条件（7 条全满足才触发）**：≥25s 沉默、距上次暖场 ≥20s、连续 <2 次、voiceCallMode === 'off'、非风险硬门槛、学生说话即重置、单句 ≤40 字。

### 7.7.3 TSK-004 冷场模板（定稿全文）

- 单句 ≤40 字、不催促、不深挖、不原样重复上一问；
- 示例："我在呢，你想说的时候说就好"、"要不要跟波波说说今天好玩的事？"；
- 暖场强度分级：1=安慰陪伴句（不提问），2=轻松小问题（引导破冰）。
