## 1. 竞品分类

- **校园心理平台**：心理云平台（国内领先校园心理 SaaS）、壹点灵等。
- **AI 心理应用**：Wysa（英国）、Woebot（美国斯坦福）、察言观色（国内）。
- **心理咨询平台**：简单心理、壹心理。
- **儿童教育类**：凯叔讲故事、小步在家早教等的心理模块。

## 3. 各竞品要点

- **Wysa**：AI 情绪支持机器人，匿名 + 随时可用，基于 CBT。优势循证 + 全球规模 + 隐私；劣势不支持中文、AI 深度有限、企业定制弱。免费增值 + B2B EAP。
- **Woebot**：斯坦福团队、CBT 理论驱动、PHQ-9/GAD-7 量表，大学校园广泛应用。优势科学背书 + 场景适配；劣势无人工转接、仅英语、功能单一。B2B（高校/企业/保险）为主。
- **国内校园心理平台**：SCL-90/SDS/SAS 量表 + 心理档案 + 预警 + 教师后台 + 数据分析。按学校规模收费（基础 2-3 万、标准 5-8 万、旗舰 10 万+/年）。心理云平台覆盖约 30 省 10000+ 校，壹点灵 5000+ 校。

## 4. 差异化分析

- **我们的优势**：AI 能力领先（大模型多轮对话/情绪识别/个性化）、垂直场景深度适配（青少年/大学生）、人机协同三级体系（AI 初步干预 + 人工转接 + 危机干预）、数据驱动迭代。
- **竞品劣势**：Wysa/Woebot 不支持中文、仅面向轻度用户；国内 SaaS AI 薄弱、以量表为主、体验差；心理咨询平台以人工为主、无法规模化。
- **市场空白**：AI 原生 + 专业深度结合的产品国内几乎空白；面向中学生的 AI 心理辅导供给不足；具危机干预能力的智能系统需求强烈；低门槛 + 隐私保护的匿名倾诉产品缺口大。

## 5. 竞争策略

- **差异化定位**：「AI 原生校园心理健康平台」，区别于传统 SaaS 量表工具，强调 AI 对话；目标 13-25 岁学生（中学、大学）。
- **功能超越路径**：① 1-3 月基础对话 + 情绪识别 + 标准量表；② 4-6 月个性化推荐 + 危机预警 + 人工转接；③ 7-12 月高级情绪分析 + 干预策略库 + 数据看板。
- **壁垒构建**：数据壁垒（中文心理对话数据）、算法壁垒（青少年模型微调）、专业壁垒（心理专家合作）、服务壁垒（危机干预流程）。

## 6. 竞品定价参考

| 竞品 | 免费功能 | 付费模式 | 企业定价 |
|------|------|------|------|
| Wysa | 基础对话+量表 | $9.99/月个人 | 按员工数议价 |
| Woebot | 基础对话 | 不对个人收费 | 高校合作项目 |
| 校园心理 SaaS | 测评+基础管理 | 2-10 万/年 | 按人数阶梯 |
| 简单心理 | 科普内容 | 200-1000 元/次 | 不适用 |

- **市场均价**：个人 AI 订阅约 50-100 元/月；企业/学校年费 2-10 万；人工咨询 200-1000 元/次。

## 7. 用户评价

- **应用商店评分**：Wysa 4.6/4.5（App Store/Google Play）、Woebot 4.4/4.3。
- **好评点**：Wysa 随时可用/隐私好/AI 不评判/CBT 工具实用；Woebot 专业背书/界面简洁/情绪追踪。
- **差评点**：Wysa 高级功能贵/复杂问题无法处理/不支持中文；Woebot 功能单一/无人工转接/长期使用新鲜感下降。

## 8. 竞品技术架构参考

| 组件 | 主流选型 |
|------|------|
| 前端 | React Native / Flutter（跨平台移动端） |
| 后端 | Node.js / Python（Django/FastAPI） |
| AI 模型 | 自研 LLM / GPT-4 / Claude API / 开源微调 |
| NLP | 对话管理 / 情绪识别 / 意图分类 / 实体抽取 |
| 数据存储 | PostgreSQL / MongoDB / Redis |
| 云服务 | AWS / GCP / Azure / 阿里云 |

- **AI 实现方式**：Wysa 自研对话引擎 + CBT 流程 + 文本情感分析；Woebot 规则 + 机器学习混合 + CBT 状态机；国内 SaaS 传统规则引擎 + 关键词匹配、量表为核心、部分接入第三方 AI API。

---

> **落地提示**：本文档为市场侧参考。技术选型上我们与竞品的关键差异是**大模型微调 + RAG 专业知识库**（见 12/15），而非传统「规则引擎 + 关键词 + 量表」路线；数据存储选择 PostgreSQL + pgvector + Redis（与竞品主流一致，见 12 技术架构决策 #5）。竞品「无中文/无人工转接/AI 弱」正是我们的差异化落点。
