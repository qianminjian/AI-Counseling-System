# 04 风险识别规则库

> 来源：`doc/04_风险识别规则库.docx`（原文 543 行）
> 状态：已转换 | 关联：13 Agent 工作流（Safety/Escalation Agent）、03 CBT 流程树（风险前置 R0-R4）、06 数据库（risk_events 表）
> 核心：**硬规则 + 语义识别 + 上下文评分 + 人工复核** 的混合架构。AI 不做诊断，只负责更早发现风险、稳定对话、输出结构化证据、把高风险事件交给人。

---

## 一、结论与适用范围

- **MVP 范围**：优先覆盖文本对话风险识别；语音、表情、行为日志作为后续增强信号，非第一阶段强依赖。
- **核心目标**：红色风险宁可多报也不能漏报；橙黄风险通过误报控制和人工分流降低老师负担。
- **部署前提**：学校私有云或校控环境存储；授权教师可见；班主任默认只看等级和协作事项，不看完整聊天。
- **儿童场景原则**：语言短、稳、非评判；不追问创伤细节；遇安全风险立即转人工。

## 二、依据与设计原则

规则库依据产品源材料、**C-SSRS 自杀风险筛查框架**、**WHO 心理急救（PFA）原则**、学生心理健康政策、未成年人保护和个人信息保护要求综合设计。C-SSRS 用于自伤/自杀问法与误报控制；WHO PFA 提供危机后非诊疗化支持原则；教育部文件强调筛查预警、家校协同、严重危机送医协助。

| 工程原则 | 落地方式 | 潜在违背与修正 |
|------|------|------|
| KISS | 先用 4 级风险、10 类信号、统一评分公式和 JSON 输出 | 过早引入多模态/复杂诊断会增加误判；第一版只做文本+人工转介 |
| YAGNI | 只实现校园早筛、预警、转介、记录闭环 | 硬件、人脸识别、本地大模型属后续阶段 |
| SOLID | Safety Agent、规则引擎、评分器、通知器、报告器分离，各职责单一可独立测试 | 风险判断不写死在 Prompt；Prompt 只解释和对话，规则引擎负责决策 |
| DRY | 统一关键词词典、语义模式、评分权重、SLA 映射；复用同一 `risk_event` JSON | 各模块自维护等级会导致口径不一致，必须统一版本管理 |

## 三、系统处理链路

| 步骤 | 模块 | 输入/输出 | 说明 |
|:---:|------|------|------|
| 1 | 预处理 | 原始文本 → 分句、脱敏、年龄段、时间词 | 保留最小必要证据，避免默认长期保存完整聊天 |
| 2 | 硬规则检测 | 关键词/正则/白名单 → hard_rule_matches | 自伤计划、性侵披露、武器威胁先判定，优先级高于 LLM |
| 3 | 语义分类 | 句子 → 风险类别、意图、计划、对象、置信度 | 识别含混表达、隐喻、否定、引用、网络语境 |
| 4 | 上下文引擎 | 当前会话 + 历史趋势 → recurrence/trend | 接 Memory Agent，只取风险摘要和趋势，不暴露全文 |
| 5 | 评分与分级 | 信号 → score、level、forced_upgrade | 先执行强制升级，再按评分阈值分级 |
| 6 | 响应路由 | risk_event → 学生响应/教师通知/记录 | 红橙风险限制自由生成，优先安全稳定和人工转介 |
| 7 | 人工复核 | 教师处理结果 → final_label | 人工标签反哺测试集和规则版本迭代 |

## 四、红橙黄绿风险分级

风险等级同时由**分数阈值**和**强制升级条件**决定。强制升级优先级高于评分公式，尤其适用于自伤/他伤、性侵、严重虐待、离家失联和急性医学危险。

| 等级 | 分数/触发 | 典型场景 | 系统动作 | 教师 SLA |
|:---:|------|------|------|------|
| **红 R4** | 75–100 或触发硬升级 | 明确自杀/自伤意图且有计划/工具/时间/地点；已实施自伤；他伤计划或武器；性侵/严重虐待正发生；急性医疗危险 | 立即中断普通对话进入安全响应；静默+强提醒心理老师/值班；必要时联系监护人、校医、110/120 | 1 分钟告警；5 分钟确认；15 分钟人工接触或应急衔接 |
| **橙 R3** | 50–74 | 死亡愿望但无计划；持续霸凌/虐待/性骚扰披露但无即时危险；严重焦虑/抑郁伴功能受损；明显离家念头；成瘾致安全风险 | 转人工队列；AI 只做稳定和求助引导，不深度追问；心理老师当天评估 | 30 分钟确认；2 小时首次接触；24 小时处置记录 |
| **黄 R2** | 25–49 | 中度压力、反复哭泣、睡眠食欲异常、轻度躯体化、同伴冲突、偶发消极但否定自伤且有保护因素 | 允许继续 CBT 微干预；生成摘要给心理老师；趋势观察和复测建议 | 24 小时后台可见；3 个在校日内关注 |
| **绿 R1** | 0–24 | 普通烦恼、考试压力、轻度情绪波动、明确否认安全风险且有稳定支持 | 常规陪伴、心理教育、放松训练；仅匿名化趋势统计 | 不触发个案告警；周/月汇总 |

## 五、风险信号分类与规则（10 类）

关键词只作召回入口，最终必须结合语义模式、上下文条件、强制升级和误报控制。

| 风险类别 | 强信号关键词 | 语义模式要点 | 强制升级条件 |
|------|------|------|------|
| 自伤/自杀 | 想死、跳楼、割腕、吃药、上吊、遗书、活着没意思 | 「我想/要/准备+伤害自己」；「已经+划/吞/跳」；「今天/放学+方法/地点」 | 计划+工具+时间/地点；已实施；出血/服药/高处/水域；被教唆；拒绝安全承诺 |
| 他伤/暴力 | 杀了他、打死、报复、带刀、砸学校、放火 | 「我要+伤害对象」；「明天/放学+带工具」；「列名单/跟踪/埋伏」 | 明确目标+方法+时间；携带武器；纵火/爆炸/群体伤害；已伤人 |
| 霸凌/网络欺凌 | 被打、被围、被孤立、被拍视频、群里骂、勒索、让我下跪 | 「每天/总是+欺负」；「发照片/视频/谣言」；「不敢去学校」 | 伴自伤意念；勒索/身体伤害；裸照传播；被迫危险行为；校外围堵 |
| 家庭虐待/忽视 | 被打、被踢、不给饭、赶出家门、锁屋里、皮带、酒后打我 | 「家长+经常/昨晚+打/骂」；「受伤不能说」；「害怕回家」 | 当前有伤、正被赶出/锁闭、威胁生命、无人照护、施害者为监护人且近期 |
| 性侵/性骚扰 | 摸隐私部位、脱衣服、发裸照、让我保密、恶心的事情 | 「成人/同学+摸/拍/要求发照片」；「威胁保密」；「不敢拒绝」 | 任何明确性侵披露；成人/教职工涉入；裸照勒索；近期且仍可接触施害者 |
| 离家/失联 | 离家出走、不回家、去车站、睡桥洞、见网友 | 「今晚/现在+不回家」；「已在路上/车站」；「带钱/行李」 | 已离校/在路上/位置不明；夜间出走；去见网友；无安全住所；伴自伤/他伤 |
| 严重焦虑/恐慌 | 喘不过气、心跳快、要崩溃、睡不着、手抖、不能上学 | 「一想到某事就强烈身体反应」；「连续多天」；「无法上学」 | 胸痛晕厥等急性医疗信号；惊恐伴自伤念头；长期拒学 |
| 严重抑郁/绝望 | 什么都没意思、我是累赘、每天哭、活着很累、没希望 | 持续低落+兴趣下降+功能受损；「把东西送人/告别」 | 与死亡愿望、告别、遗书、工具准备合并；完全拒绝求助；明显精神异常 |
| 躯体化/进食睡眠 | 头痛、肚子痛、恶心、胸闷、吃不下、暴食、噩梦 | 压力事件后反复身体不适；多次校医无明确原因 | 急性疼痛、晕厥、呼吸困难、进食严重受限、疑似自伤/服药 |
| 成瘾/网络沉迷 | 停不下来、通宵游戏、偷钱充值、烟酒、药片 | 「明知后果仍无法停止」；「为上网/物质欺骗偷拿」；「戒断烦躁」 | 药物/酒精中毒；成瘾性药物；严重旷课失联；为获取物质出现违法/暴力 |

## 六、关键词词典与否定控制

词典分**强信号**（快速召回）、**弱信号**（需上下文增强）、**否定/误报修饰**（降噪但不覆盖红色硬规则）。

- **误报修饰示例**：不/没有/不会/以前（否定）、故事里/新闻/游戏角色（引用）、比赛/夸张/气话（修辞）、健康课学习/医学检查（知识语境）。
- **原则**：自杀问法不能因「像开玩笑」直接降级，必须二次澄清；性侵/虐待/离家/武器即使含混也至少进橙色人工核验。

## 七、语义模式与上下文条件

儿童表达常不完整，需抽取「谁、对谁、做什么、何时、何地、用什么、是否已发生、是否被威胁保密、是否愿求助」槽位。

| 模式 | 识别逻辑 | 评分影响 |
|------|------|------|
| 直接意图 | 第一人称+想/要/准备/决定+自伤/他伤/离家/求死 | +15，合并计划则硬升级 |
| 计划与工具 | 方法/工具/地点/时间/对象任意两项以上 | +20，工具可得时红色 |
| 近期行为 | 刚刚/昨天/已经+实施行为 | +25，已实施自伤直接红色 |
| 被迫保密 | 威胁不能告诉老师/家长 | +15，性侵/虐待场景红色 |
| 持续与升级 | 每天/总是/越来越/控制不住 | +10，触发趋势跟踪 |
| 功能受损 | 不上学/不吃饭/不睡觉/成绩骤降 | +10，严重时橙色 |
| 保护因素 | 愿找老师；身边有人；明确不会伤害；有安全计划 | -5 到 -15，但不覆盖硬升级 |
| 误报语境 | 否定/引用/文学新闻影视游戏/假设/健康课 | -10 到 -30，转普通解释或轻度关注 |

**关键上下文条件**：近期性（正在发生>今天>7天>30天>历史分层）、对象与权力差（成人/教职工/亲属/群体风险更高）、可及性（工具/药物/高处/水域/夜间车站/陌生网友）、重复性、保护因素（可降分不覆盖硬升级）、信息来源（本人直接表达最高）。

## 八、强制升级条件

一旦命中直接进入红色或至少橙色人工复核，不等待模型自由判断：

- **自伤/自杀**：明确意图 + 计划/工具/时间/地点任一；已实施；服药/出血/高处/水域。
- **他伤**：明确目标对象 + 工具/时间/地点；携带武器；纵火/爆炸/群体伤害/报复名单。
- **性侵/性骚扰**：任何明确身体隐私侵犯、裸照勒索、成人/教职工涉入、被要求保密。
- **虐待/忽视**：监护人近期严重暴力、赶出家门、禁食、锁闭、伤痕、无人照护。
- **离家/失联**：已离校/在路上、夜间出走、去见网友、位置不明、无安全住所。
- **严重身心危险**：胸痛晕厥、呼吸困难、疑似中毒、极端睡眠/进食异常、精神异常伴安全风险。
- **多信号共现**：霸凌/虐待/性侵任一项与死亡愿望、自伤工具、离家计划合并。

## 九、误报控制

目标不是降低安全敏感度，而是把老师精力从明显误报中释放。**红色硬规则不可被自动降级，只能标记「需人工核验」**。

- 否定识别、引用识别（标记 `source_context`）、夸张修辞降噪、澄清优先（1–2 个封闭式安全问题）、儿童保护优先、人工反馈闭环（记录 `false_positive_reason`）。

## 十、风险评分公式

评分用于普通风险排序，**不能替代强制升级**，保持可解释便于复核审计。

```
base_score = max(category_base_scores)
raw_score  = base_score + intent_weight + plan_weight + recency_weight + action_weight
             + repetition_trend_weight + cooccurrence_weight + source_weight
             - protective_factor_weight - false_positive_penalty
score = clamp(round(raw_score * confidence_adjustment), 0, 100)
level = forced_upgrade_level if any_hard_rule_matched else threshold(score)
threshold(score): 0-24 green, 25-49 yellow, 50-74 orange, 75-100 red
```

| 评分项 | 建议权重 |
|------|------|
| 类别基础分 B | 自伤/性侵/严重虐待 60；他伤 55；离家计划 50；霸凌/焦虑/抑郁 35；躯体化/成瘾 25（取最高，不累加） |
| 意图 I | 明确想/要/准备/决定 +15；含混愿望 +8；第三方转述 +5 |
| 计划 P | 方法/工具/地点/时间/对象每项 +5，最高 +20 |
| 近期性 R | 正在发生/今天 +15；7 天内 +10；30 天内 +5；历史 +0（「放学后/今晚」按今天） |
| 行为证据 A | 已实施自伤/暴力/出走 +25；身体伤害或医学危险 +20；可验证第三方报告 +10 |
| 重复与趋势 T | 连续 3 次 +10；7 天内升级 +10；多类共现 +5（由 Memory Agent 提供） |
| 保护因素 G | 可信成人在旁/愿求助/安全承诺 各 -5；已在专业处置 -10（硬升级下只记录不降级） |
| 误报惩罚 F | 明确引用/否定/虚构 -10 到 -30；置信度不足 -10（红色硬升级不适用） |

> 上线后需用真实匿名化样本和人工标签校准阈值，特别关注**红色漏报率**与**橙色误报率**。

## 十一、JSON 输出结构（risk_event）

所有 Agent 和教师后台统一消费同一个 `risk_event` JSON，支持审计、脱敏、人工复核、版本回溯。

```json
{
  "rule_version": "risk-ruleset@1.0.0",
  "event_id": "risk_evt_20260529_000001",
  "session_id": "sess_xxx",
  "student_ref": { "school_id": "school_001", "student_id_hash": "sha256:...", "grade": "G4" },
  "timestamp": "2026-05-29T20:40:00+08:00",
  "input_channel": "text",
  "risk": {
    "level": "red", "score": 92, "categories": ["self_harm"], "forced_upgrade": true,
    "reason_codes": ["SH-PLAN-003", "RECENT-TODAY", "MEANS-AVAILABLE"]
  },
  "evidence": [
    { "span": "今天放学后要从教学楼跳下去", "normalized_signal": "self_harm.intent.plan.time.location",
      "confidence": 0.94, "rule_id": "SH-PLAN-003" }
  ],
  "context": {
    "recency": "today", "has_intent": true, "has_plan": true, "has_means": "unknown",
    "protective_factors": [], "trend": { "same_category_7d_count": 1, "score_delta_7d": 0 }
  },
  "false_positive_control": { "negation_detected": false, "fiction_or_quote_detected": false, "needs_clarification": false },
  "recommended_action": {
    "student_response_mode": "safety_stabilization", "teacher_sla": "ack_5min_contact_15min",
    "notify_roles": ["psych_teacher", "duty_admin"], "share_scope": "minimum_necessary"
  },
  "privacy": { "store_raw_input": false, "store_evidence_span": true,
    "retention_policy": "school_configured_sensitive_event_retention", "redaction_applied": true },
  "human_review": { "status": "pending", "reviewer_id": null, "reviewed_at": null, "final_label": null }
}
```

**字段约束**：`rule_version` 必填保证可追溯；`student_id_hash` 用哈希/内部匿名 ID 不暴露姓名；`evidence.span` 只存最小必要片段（红色事件可按学校制度加密保留，普通情绪默认不长期保存）；`recommended_action` 只输出流程动作，不生成诊疗建议。

## 十二、老师处理 SLA 与权限边界

| 等级 | 负责人 | 通知方式 | 处理时限 | 注意事项 |
|:---:|------|------|------|------|
| 红 | 心理老师/值班；必要时校医、校领导、监护人、应急机构 | 弹窗+短信/钉钉/电话多通道；锁定「待确认」 | 5 分钟确认；15 分钟人工接触或转外部应急 | 不得让学生独处；不承诺绝对保密；不要求学生自行处理施害者；完整记录 |
| 橙 | 心理老师主责；班主任只接收等级和协作事项 | 后台优先队列；当天待办 | 30 分钟确认；2 小时首次接触；24 小时闭环 | 先稳定再评估；必要时升红；家校沟通最小必要 |
| 黄 | 心理老师或班主任按权限协作 | 关注列表；趋势提醒 | 24 小时阅读；3 在校日跟进 | 团辅/个别谈话/放松训练；持续升高则复评 |
| 绿 | 系统自动支持；心理老师看汇总 | 不产生个案告警 | 周/月趋势分析 | 匿名化最小化，避免标签化 |

**权限边界**：心理老师看风险摘要、证据片段和趋势；班主任默认只看等级、协作事项、是否需联系家长；管理员看配置和审计，不看敏感对话全文；家长沟通遵循最小必要和学生安全优先。

## 十三、测试样例（第一版回归集）

| 编号 | 学生输入样例 | 期望等级 | 命中规则 |

## 十四、规则版本管理

- **版本号**：semantic version `risk-ruleset@major.minor.patch`。红色硬升级/SLA/JSON schema 变更升 major；新增普通规则升 minor；关键词修订升 patch。
- **规则 ID**：`类别-意图-序号`（如 SH-PLAN-003、SEXUAL-SECRET-001）；ID 永不复用，废弃规则保留 tombstone。
- **变更流程**：作者提交变更说明+依据+影响+测试样例 → 心理老师/产品/安全三方评审 → 灰度后发布。
- **测试门禁**：固定回归集 + 红色召回专项集 + 误报专项集；红色漏报为阻断项，橙黄误报超阈值回滚。
- **质量指标**：红色召回率（不漏报第一）、橙色误报率、平均确认时长、人工标签一致性、学生体验。

## 十五、第一阶段实施建议

第一阶段只做「文本对话 + 风险规则引擎 + 教师后台 + 告警闭环」，不同时上人脸识别/多模态/机器人硬件/复杂诊断模型。

- Safety Agent 前置：所有学生输入先过风险规则，再进 CBT/陪伴流程。
- 先做红橙两级强规则：自伤、他伤、性侵、虐待、离家、急性医学危险优先。
- 教师后台闭环：告警、确认、处理、转介、关闭、复盘全部结构化记录。
- 上线前用测试样例和匿名化历史样本校准阈值，上线后每周复盘误报漏报。
- 数据最小化：默认不保存原始语音和完整聊天；证据片段加密、权限隔离、可审计。

> 核心价值不是"识别更多情绪标签"，而是把少量真正危险的信号**稳定、可解释、可审计**地交给人处理。

## 十六、Java 实现层适配

> 关联决策 #5/#8/#9。规则引擎落地在 `counseling-ai` 模块的 Safety Agent 中，与 Spring AI 编排配合。
>
> ⚠️ **实现状态说明（2026-07-23 核对）**：本节为**目标设计**，使用设计期类名（`HardRuleMatcher`/`SafetyAgent`/`SafetyInputAdvisor` 等）。M1 实际落地采用**精简关键词硬规则版**，真实类名与已实现范围见 **§十七（已实现）**。设计期类名与实现类的对应关系以 §十七 为准。

| 设计要求 | Java 实现方案 |
|------|------|
| 硬规则检测（步骤 2，优先级最高） | `HardRuleMatcher`：编译期加载关键词词典 + 预编译 `Pattern`（正则），返回 `hard_rule_matches`，在 LLM 调用**之前**执行 |
| 语义分类（步骤 3） | `SafetyAgent` 调用 Spring AI `ChatClient`，结构化输出映射为 `SemanticRiskResult` record（Jackson 反序列化 LLM JSON） |
| 上下文引擎（步骤 4） | `TrendAnalyzer` 从 Redis/Memory 读取 `same_category_7d_count`、`score_delta_7d`，不加载全文 |
| 评分与分级（步骤 5） | `RiskScoreCalculator`：纯函数按 §10 权重计算，`金额/分值用 int` 避免浮点误差；`forced_upgrade` 优先短路 |
| 规则版本管理 | 规则集打包为版本化配置（`risk-ruleset@x.y.z`），启动时校验；规则 ID 常量集中管理，tombstone 保留 |
| risk_event 落库 | 映射 06 文档 `risk_events` 表；`evidence.span` 走字段级加密 TypeHandler；`store_raw_input=false` 时不落原文 |
| 前置执行顺序 | Spring AI `SafetyInputAdvisor`（输入侧）在 `ConversationOrchestrator` 中最先执行，命中红/橙直接短路到 `EscalationAgent` |
| SLA 计时与升级 | `@Scheduled` 或延时队列监控确认时限，超 SLA 自动升级值班负责人；用 `Instant` 记录告警/确认/接触各时间点 |
| 测试门禁 | JUnit 参数化测试加载 §13 的 T01-T15 回归集；红色漏报为 CI 阻断项 |

**执行顺序铁律**：硬规则 → 强制升级判断 → LLM 语义 → 评分 → 分级。硬规则和强制升级**不可**被 LLM 输出或误报惩罚覆盖，只能标记「需人工核验」。

### 17.3 输出侧双层安全审查（已实现，核心增强）

| 层 | 实际实现类 | 模块 | 机制 |
|:---:|------|------|------|
| **Layer1**<br>流式实时硬过滤 | `OutputContentFilter` | `counseling-ai/.../safety/` | 对 LLM 流式 token 做**滑动窗口**敏感词匹配（窗口=词库最长关键词，防 token 切碎漏检）。命中 block 级 → 立即中断输出流 + 发射安全话术（自伤/伤人类追加危机热线）+ 上报 |
| | `SafetyKeywordLibrary` | `counseling-ai/.../safety/` | 词库底座：启动加载 `safety/output-sensitive-keywords.json`，分 block/flag 级。词库**保守**（仅收录 AI 绝不应说出的高置信多字短语，避免误伤危机干预中的共情复述） |
| **Layer2**<br>异步语义审查 | `OutputReviewService` | `counseling-ai/.../safety/` | 流结束后对 AI 完整回复做非流式 **SAF-002** 审查（检测适龄性/隐性诊断/依赖诱导等细微违规）。**fire-and-forget**：专用线程池 `outputReviewExecutor` 异步执行，绝不阻塞主流（用户零延迟） |

**危机热线铁律**：`OutputContentFilter.CRISIS_HOTLINE = "400-161-9995"` 为**硬编码常量**，危机干预资源绝不交给 LLM 决定（对齐 design/14 §11 铁律）。

**SAF-002 Prompt**：`prompts/safety/safety_output_guard_zh-CN_v1.0.0.md`，输入占位符 `{candidate_reply}` + `{context}`（context = 学生情绪标签），输出严格 JSON（decision: pass/rewrite/block/escalate）。详见 design/18 §3。
