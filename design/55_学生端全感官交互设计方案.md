## 一、设计目标

| 维度 | 目标 |
|------|------|
| 视觉 | 男女双主题 + 可自定义，让孩子有"这是我的空间"的归属感 |
| 听觉 | AI 每句话同步语音播报，低龄儿童无需识字也能完整交互 |
| 情感 | 语音情绪随孩子心情自适应——开心时活泼、难过时温柔、害怕时安抚 |
| 包容性 | 不强制性别二元，提供"自选"而非"被分配" |

## 二、视觉主题系统

### 2.1 双主题 + 自定义

> ⚠️ 2026-07-26 更新：角色已固定为小海豚"波波"（品牌固化，见 `design/27_波波小精灵品牌与宠物交互设计.md`）。主题仅切换颜色，不切换角色。原"棉花糖/小星"角色已废弃。

| 主题 | 色调 | 伙伴形象 | 背景风格 | 适用 |
|------|------|---------|---------|------|
| 🌊 海洋探险（默认） | 蓝绿 #0EA5E9 → #06B6D4 | 小海豚"波波"（天蓝） | 海底世界、气泡动效 | 偏好蓝绿色系 |
| 🌸 花园精灵 | 粉紫 #EC4899 → #A855F7 | 小海豚"波波"（粉调） | 花园、星星动效 | 偏好粉紫色系 |
| 🌈 彩虹自由（自定义） | 用户自选主色 | 小海豚"波波"（紫调） | 简洁渐变 | 不偏好以上两种 |

### 2.2 设计原则

- **不强制**：首次进入时展示 3 个主题预览卡片，孩子自己选（而非根据性别自动分配）
- **可切换**：设置中随时更换，不锁定
- **色觉无障碍**：所有主题对比度 ≥ 4.5:1（WCAG AA），不依赖纯色区分信息
- **暗色模式**：跟随系统设置（Android 10+ 深色模式），保护视力

### 2.3 主题影响范围

```
主题变量 → CSS Variables
├── --primary: 主色（按钮、高亮）
├── --primary-light: 浅色（气泡背景、卡片）
├── --companion: 伙伴形象（PNG/Lottie 动画）
├── --bg-gradient: 背景渐变
├── --accent: 强调色（情绪标签、风险提示）
└── --voice-btn: 语音按钮色
```

## 三、TTS 语音播报系统

### 3.1 核心需求

> "孩子通过语音更能够听得懂，有些文字孩子理解不了。"

**每条 AI 回复 = 文字气泡 + 同步语音播放**

### 3.2 技术选型：CosyVoice 2（阿里 FunAudioLLM）

| 能力 | 说明 |
|------|------|
| 情感控制 | 自然语言指令："用开心语气说"、"用温柔语气说"，27 种基础情绪标签识别率 >96% |
| 音色克隆 | 3 秒参考音频即可定义专属音色 |
| 流式合成 | 首包延迟 1.4 秒，支持边生成边播放 |
| 本地部署 | Docker 容器，与 voice-service 同机房，数据不出校 |
| 中文优化 | 原生中文训练，儿化音、轻声、语气词自然 |

### 3.3 部署架构

```
[学生端 H5]
    │
    ▼ POST /api/v1/tts/synthesize
[Java 后端 - TtsController]
    │
    ▼ HTTP (流式)
[Python tts-service - CosyVoice2]
    │ 端口 10096
    ▼ 返回 audio/wav 流
[学生端 H5 - AudioContext 播放]
```

### 3.4 前端播放策略

```javascript
// 流式播放：AI 文字逐字出现时，语音同步播放
// 1. AI 回复完成一句话（句号/问号/感叹号）→ 触发该句 TTS
// 2. 前端维护播放队列，按句顺序播放
// 3. 用户点击气泡 → 重播该句
// 4. 用户发送新消息 → 停止当前播放
```

**关键交互：**
- 气泡右侧显示 🔊 图标（播放中变为声波动画）
- 点击 🔊 可暂停/重播
- 首次使用弹出"开启语音"引导（默认开启）
- 静音模式：顶部状态栏一键静音（不播放语音，仅显示文字）

## 四、情感化语音合成

### 4.1 情绪 → 语音参数映射

基于 emotion2vec+ 识别的孩子情绪，动态调整 AI 语音风格：

| 孩子情绪 | AI 语音策略 | CosyVoice 指令 | 语速 | 音调 |
|---------|-----------|--------------|------|------|
| 😊 开心 | 一起开心，活泼回应 | "用开心语气说" | +10% | 偏高 |
| 😢 难过 | 温柔安慰，放慢节奏 | "用温柔语气、用轻声说" | -15% | 偏低偏柔 |
| 😠 生气 | 先共情再引导，平稳 | "用平静语气、用轻声说" | -5% | 中等偏低 |
| 😨 害怕 | 安抚为主，坚定温暖 | "用温柔语气说" | -10% | 中等偏柔 |
| 😰 紧张 | 轻松化解，带点俏皮 | "用轻松语气说" | 正常 | 中等 |
| 😐 中性 | 自然亲切 | "用亲切语气说" | 正常 | 正常 |

### 4.2 指令工程规范（CosyVoice2 最佳实践）

```python
# ✅ 正确：精简指令，单一情绪标签
instruct = "用温柔语气、用轻声说"

# ❌ 错误：堆砌修饰词
instruct = "用非常非常温柔又充满关怀的语气轻声细语地说"

# ✅ 组合用顿号分隔
instruct = "用开心语气、用俏皮语气说"

# ❌ 禁用"和""又""还"
instruct = "用开心又温柔的语气说"  # 后半段丢失
```

### 4.3 风险场景语音特殊处理

| 风险等级 | 语音策略 |
|---------|---------|
| YELLOW | 正常温柔语气，不制造紧张感 |
| ORANGE | 语速再降 10%，加入"我在这里陪着你"的安抚语调 |
| RED | 极度温柔 + 坚定："老师马上就来，你不是一个人"，语速最慢 |

**红线：任何情况下 AI 语音不得表现出惊慌、急促、指责。**

## 五、音色人设系统

### 5.1 三种可选音色（孩子自选）

| 音色名 | 人设 | 特征 | 适合 |
|--------|------|------|------|
| 🌟 小星（默认） | 温暖的大姐姐/大哥哥 | 中高音、亲切自然、像邻家姐姐 | 全年龄段 |
| 🎈 气球 | 活泼的小伙伴 | 偏高音、语速稍快、俏皮感 | 1-3 年级 |
| 🌙 月亮 | 温柔的讲故事者 | 中低音、语速慢、催眠感 | 情绪低落时 / 高年级 |

### 5.2 音色技术实现

```yaml
# 每种音色 = 一段 3-5 秒参考音频 + 固定 instruct 前缀
voice_personas:
  xiaoxing:
    ref_audio: "voices/xiaoxing_ref.wav"  # 3秒参考音频
    base_instruct: "用亲切语气说"
    pitch_shift: 0        # 无偏移
    speed: 1.0
  qiqiu:
    ref_audio: "voices/qiqiu_ref.wav"
    base_instruct: "用俏皮语气说"
    pitch_shift: +2       # 略高
    speed: 1.05
  yueliang:
    ref_audio: "voices/yueliang_ref.wav"
    base_instruct: "用温柔语气、用轻声说"
    pitch_shift: -1       # 略低
    speed: 0.92
```

### 5.3 情绪叠加公式

```
最终指令 = 音色基础 instruct + 情绪叠加 instruct

示例：
  音色"月亮" + 孩子"难过" → "用温柔语气、用轻声说"
  音色"气球" + 孩子"开心" → "用俏皮语气、用开心语气说"
  音色"小星" + 孩子"害怕" → "用亲切语气、用温柔语气说"
```

## 六、补充设计（业界最佳实践）

### 6.1 语速自适应（儿童认知研究）

| 年龄段 | 建议语速 | 原因 |
|--------|---------|------|
| 6-8 岁（1-2年级） | 180-200 字/分钟 | 工作记忆容量有限，需要消化时间 |
| 9-10 岁（3-4年级） | 200-240 字/分钟 | 阅读能力提升，可稍快 |
| 11-12 岁（5-6年级） | 240-280 字/分钟 | 接近成人理解速度 |

**实现方式**：根据学生 grade 字段自动调整 CosyVoice speed 参数。

### 6.2 句子切分策略（TTS 自然度）

```
AI 完整回复 → 按标点切分为句子 → 逐句合成 → 逐句播放
切分规则：
- 句号、问号、感叹号 → 强切分（停顿 400ms）
- 逗号、分号 → 弱切分（停顿 200ms）
- 单句 > 30 字 → 在"的""了""和"处二次切分
```

### 6.3 播放状态与文字同步

```
[文字气泡]                    [语音播放]
  "你今天看起来有点难过。"  →  🔊 播放中...（声波动画）
  "没关系，我在这里。"      →  ⏳ 排队等待
  "想和我说说吗？"          →  ⏳ 排队等待
```

- 当前播放句高亮（浅底色）
- 播放完毕的句子恢复正常
- 用户可随时点击任意句子的 🔊 重播

### 6.4 儿童语音 UX 10 原则（Futurice/UNICEF 适配）

| # | 原则 | 我们的实现 |
|---|------|-----------|
| 1 | 包容性 | 主题自选不强制性别；音色自选不锁定 |
| 2 | 给予控制感 | 孩子可暂停/重播/切换音色/静音 |
| 3 | 安全 | 语音不含任何惊吓元素；风险场景语音极度温柔 |
| 4 | 灵活 | 支持纯文字/纯语音/混合模式切换 |
| 5 | 理解用户 | 情绪识别驱动语音风格自适应 |
| 6 | 鼓励互动 | 语音结尾带引导性问句，鼓励孩子开口 |
| 7 | 允许探索 | 音色/主题可自由尝试，无惩罚 |
| 8 | 恰当表达 | 表扬努力而非天赋（"你很勇敢"而非"你真聪明"） |
| 9 | 有意义 | 语音人设有记忆感（"上次你说喜欢画画"） |
| 10 | 保持新鲜 | 定期更新音色/主题/问候语 |

### 6.5 近同伴原则（Near-Peer）

研究表明，儿童更信任"近似同伴"而非"权威成人"的声音。

**我们的实现：**
- AI 音色设计为 16-18 岁的"大哥哥/大姐姐"，而非 30+ 成人
- 语态：平等对话，不居高临下
- 禁止用语："你应该..."、"你必须..."、"听话"
- 推荐用语："我觉得..."、"你可以试试..."、"我陪你"

### 10.2 实现偏差登记（定稿，正文保留作选型记录）

1. **音色技术路线**：§5.2 设计为「3-5 秒参考音频（ref_audio）+ pitch_shift」，实际实现为 **CosyVoice 内置说话人（cosy_speaker）+ edge-tts 音色（edge_voice）双轨**，无参考音频文件。定稿理由：免维护音频资产、合规上更干净（不引入任何真人克隆源）、KISS。
2. **§八「语音合成数据不出校」在降级路径下不成立**：edge-tts 降级将 AI 文本送微软云合成。该合规表述问题已归 `design/22` §6.3 统一决策（待确认清单项），本篇不重复展开。
3. 细部观察：LoginPage 登录页吉祥物 emoji 为 🐬/🍭/🚀（garden/rainbow 用糖果/火箭而非波波），与「角色固定为波波」存在装饰性偏差，归 27 品牌一致性低优先项。
