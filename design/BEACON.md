# AI 小学生心理辅导系统 - 项目明灯

> 创建：2026-07-23 | 更新：2026-07-26 | 阶段：商业化版本开发完成（Phase 1-20）+ 生产部署上线（mindsafe 用户隔离）；当前进行「波波小精灵」品牌固化与宠物交互（design/27）

---

## 目标与成功标准

1. 建成面向小学生的 AI 心理辅导 SaaS 系统（多学校隔离）
   - 成功标准：MVP 落地（见 `design/08_MVP最小可行版本.md`），含学生端 AI 对话 + 老师后台 + 风险识别
2. 心理专业性与儿童安全双达标
   - 成功标准：CBT 对话流程（`design/03`）、风险识别规则（`design/04`）、儿童安全规范（`design/14`）在系统中完整实现

---

## 范围边界

**做：**
- 学生端 AI 心理辅导对话（Prompt 体系 + CBT 流程树 + 心理知识库）
- 老师后台与风险预警、SaaS 多学校隔离、数据库与隐私合规

**不做：**
- 教师/家长端 AI 自动干预决策（红线：监管责任事项 AI 只提供信息不做决策）
- 超出 MVP 定义的非核心功能（YAGNI）

| 5 | 技术栈：**Java 21+Spring Boot 3.4+Spring AI 1.0** / PostgreSQL16 / React19+JS+Vite8+Tailwind(学生端)+AntDesign6(教师端) / Maven / Docker Compose | 私有化/信创是主营（钱敏健决策）：Java 信创适配成熟、政企交付预期、用户银行背景；前端实际采用 JS（非 TS）以降低开发复杂度 | 2026-07-23（实现期修正） |

| 7 | LLM 供应商无关化：Spring AI 配置驱动接入任意国产合规 LLM，主备降级 | 钱敏健决策：不锁定供应商；Spring AI 天然多 Provider；合规候选 DeepSeek/通义/GLM | 2026-07-23 |
| 8 | 后端架构：**模块化单体（Maven 多模块）**，MVP 不上微服务 | 微服务运维税（注册/配置/链路/分布式事务）MVP 纯负担；Maven 模块隔离领域未来可拆；私有化单体容器化对学校机房更友好 | 2026-07-23 |
| 9 | Agent 编排：**Spring AI（ChatClient+Advisor 链+状态机）替代 13 号的 LangGraph** | Java 下 LangGraph(Python) 不适用；7 Agent 职责划分(design/13)保留，仅替换实现技术；CBT 流程树本质是状态机 | 2026-07-23 |
| 10 | 内容安全采用**双层输出审查 + 输入 PII 脱敏**：Layer1 流式关键词硬过滤（`OutputContentFilter`）+ Layer2 异步 SAF-002 语义审查（`OutputReviewService`）+ `PiiDesensitizer` 服务端脱敏 | 流式硬过滤零延迟拦截高危输出；异步审查不阻塞主流；PII 脱敏对齐 PIPL 数据最小化；危机热线硬编码不交给 LLM。已实现见 design/04 §十七 | 2026-07-23 |
| 11 | 公网试用前增加**认证兼容方案 + 告知同意流程**（design/21）：复用现有 JWT 身份契约（`{userId,userType,tenantId}`）+ 可插拔认证策略 + 试用租户隔离 + 门控告知同意页 + 同意留痕 | 现有 JWT 契约已 80% 兼容，补全 SecurityContext 集成即可；未成年人合规底线（PIPL 第31条监护人同意）；定位"告知+同意"而非免责金牌 | 2026-07-23 |
| 12 | **设计文档与代码一致立为项目底线规则**（core-red-lines §4.5 + AGENTS §3.5 + design-persistence §4.2） | 前期发现 design/04、14、18 用设计期类名与实际代码不符；design/*.md 是单一事实源，改代码必同步文档、改文档必核对代码、设计期与已实现明确区分 | 2026-07-23 |
| 13 | 试用准入策略定案（design/21 D1-D4 + §3.1）：**成人体验者 + 邀请码 + 邀请码/昵称/年龄认证 + 试用咨询师（钱敏健本人）承接预警**；通知用 **P0 站内消息+教师端轮询+浏览器桌面通知**（WebSocket/邮件短信为 P1/P2 目标） | 钱敏健确认：成人体验者规避 PIPL 第31条监护人同意的高合规成本；邀请码可控发放；最小化数据收集；试用咨询师验证完整预警闭环。M1 通知仅站内消息被动拉取，P0 纯前端轮询+桌面通知补即时性 | 2026-07-23 |
| 14 | **品牌固化为「波波小精灵」**：产品名/图标/AI 人设/伙伴角色全部统一为「波波」（小海豚）；三主题保留换色但角色固定为波波（删除棉花糖/小星） | 钱敏健决策：品牌资产单一化，孩子记得住；角色固定+颜色可变兼顾个性化与品牌沉淀（design/27 §三） | 2026-07-26 |
| 15 | **伙伴宠物化 + 语音输入圆球化，二者合一**：波波即语音输入圆球（按住蜷成发光圆球），AI 说话时头顶冒话语气泡（TTS 当前朗读句）；不做麦克风/圆球配置切换 | 手机屏悬浮物宜少不宜多；Pad 左栏本就是「伙伴+麦克风」上下摆放，天生一个东西；YAGNI——与其两个 60 分不如一个 95 分；架构留口（圆球独立组件，将来可加回麦克风模式）。纯前端改动，后端零改动（design/27 §四/§五） | 2026-07-26 |

## 当前状态

- **阶段**：商业化版本开发完成（Phase 1-20）+ 已生产部署上线；「波波小精灵」品牌与宠物交互升级（design/27）已完成，待部署
- **已实现规模**：

  - 学生端 H5：13 个组件（对话/情绪选择/放松练习/情绪日记/成就徽章/PWA/语音/TTS）

  - 家长端 H5：家庭码注册/登录 + 情绪周报（frontend/parent-h5）
  - 部署：Docker Compose 一键启动（PostgreSQL + Spring Boot + Nginx）；生产已迁移至 mindsafe 专用用户（非 root）
  - 商业化功能：企微 OAuth、会话导出 PDF、批量导入、满意度分析、干预话术模板、新手引导
- **最近动作**：波波小精灵（design/27）全部实现——品牌固化（PWA 名/海豚图标/角色固定波波）+ 波波 SVG 四态动画 + 圆球变形触感 + 话语气泡（TTS 逐句同步）+ 接入 ChatRoom（手机悬浮/Pad 左栏，删麦克风按钮与录音遮罩）+ WelcomeGuide 引导 + AI 人设改波波（后端 prompt/问候语）；vite build 通过
