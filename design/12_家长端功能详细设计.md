# 一、总览

## 1.1 本卷范围与定位

家长端是 MindSafe "学生-AI-教师-家长"四位一体体系的最后一环：家长在手机端查看孩子的情绪周报、接收 AI 建议、管理数据授权。

**核心原则（定稿）**：

- **低门槛注册为主**：家庭码一次绑定（后续手机号登录）＋教师链接兼容——家庭码解决了教师逐个生成链接的运营成本，且支持多孩绑定；
- **只读为主**：家长只看统计报告，不看对话原文（隐私保护）；
- **合规闭环**：监护人同意确认、同意撤回均可在家长端完成。

## 4.2 验证/登录页（`/`，双模式定稿）

**模式 A：手机号+密码登录**（日常路径）：

```
手机号  [138 1234 5678]
密码    [********]
[登录] → 跳转 /report
```

**模式 B：家庭码注册**（首次绑定，支持多孩）：

```
家庭码  [______]（6 位，学生注册时生成）
手机号  [138 1234 5678]
密码    [********]
关系    [爸爸 / 妈妈 / 其他]
[绑定并注册] → 绑定学生 → 跳转 /report
```

**模式 C：教师链接 + 验证码**（兼容保留）：链接含初始 Token（教师生成，`?token=xxx`）→ 输入手机号 → `POST /parent/send-code` → 输入验证码 → `POST /parent/verify-phone` → 获得正式 7 天 Token → Token 存 localStorage → 跳转 `/report`。
> **doing/95 安全注记（BACK-008）**：`/api/v1/parent/**` 为 permitAll 自校验域，统一出口 `ParentIdentityResolver.validateParentToken` 五重校验——签名有效 + 非 refresh + 非声纹凭证 + **tokenType 必须 parent_report** + userType=parent；新端点漏调即被拒（20001）。

# 八、安全与合规（源：26 §8）

| 项 | 措施 |
|---|---|
| Token 安全 | 初始 Token 仅用于验证流程；正式 Token 7 天过期（与 17 §10.2 口径一致）。JWT `tokenType=parent_report`（SEC-006）独立于学生 access token：家长报告链接 token 不可调用学生接口，防学生自持 token 调家长接口（08 §3.1） |
