> 创建：2026-07-28 | 状态：设计完成，待实施 | 对应规划任务：AI-009（design/30 §功能清单）
>

## 一、业界对标（避免空想的依据）

### 1.1 测量导向照护（Measurement-Based Care, MBC）

- **SAMHSA《Advancing Measurement-Based Care in School Mental Health》**（美国学校心理健康国家中心）确立了学校场景 MBC 的核心范式：**定期施测 → 结果反馈给照护者 → 依据分数变化调整干预**。单次筛查价值有限，纵向趋势才是干预依据。
- 核心实践要点（本设计直接采纳）：
  1. 施测频率与干预强度挂钩：普测每学期 1 次；进入个案跟踪的学生 2-4 周复测 1 次
  2. 结果必须回流到干预者（教师/心理老师）的工作流中，而不是存档了事
  3. 分数分档必须使用量表原始验证文献的 cut-off，不得自造阈值

### 1.2 量表选型的循证依据

| 量表 | 适用年龄 | 验证依据 | 分档（原始文献 cut-off） |
|------|---------|---------|------------------------|
| PHQ-A（PHQ-9 青少年版） | 11-17 岁（本系统用于 5-6 年级） | Johnson 2002；Fonseca-Pedrero 2023 证实学校场景可用 | 0-4 无 / 5-9 轻度 / 10-14 中度 / 15-19 中重度 / ≥20 重度 |
| GAD-7 | 12+（5-6 年级参考使用） | Spitzer 2006；青少年群体多次验证 | 0-4 minimal / 5-9 mild / 10-14 moderate / ≥15 severe |
| SDQ 长处和困难问卷（学生自评版 11-17 / 家长版 4-17 / 教师版 4-17） | 覆盖全学段 | Goodman 1997；有中国常模（杜亚松等） | 五维度分 + 困难总分三分档（正常/边缘/异常），按中国常模 |
| MHT 心理健康诊断测验 | 小学四年级以上 | 周步成修订，国内学校广泛使用 | 8 内容量表 + 效度量表，总分 ≥65 需关注 |

**选型结论**：
- **1-3 年级**：不使用自评量表（低龄儿童自评信效度不足，业界共识），仅使用 **SDQ 教师版/家长版**（他评）
- **4-6 年级**：MHT（国内常模完善）+ SDQ 学生自评；PHQ-A / GAD-7 作为个案跟踪的复测工具（题目少、对分数变化敏感，符合 MBC 高频复测需要）

### 1.3 版权与许可（红线，先于开发确认）

| 量表 | 版权状态 | 使用前置条件 |
|------|---------|------------|
| PHQ-A / GAD-7 | Pfizer 声明免费使用，无需许可 | 保留原版署名，不得修改题目 |
| SDQ | 版权归 Youthinmind，**纸质/逐题人工使用免费，数字化嵌入 App 需向 sdqinfo.org 申请许可并可能付费** | ⚠️ 商用发布前必须完成许可谈判，未取得许可前 SDQ 模块不得上线 |
| MHT | 国内修订版，版权归属华东师范大学（周步成修订） | 需与出版方确认数字化授权 |

> 落库要求：`assessment_scales.license_info`（jsonb，表已存在，见 design/06）必须记录许可状态、许可方、有效期；`status='active'` 的量表必须 license 状态为 `granted` 或 `free`。**这是发布门禁，纳入 design/32 商用前置清单。**

### 1.4 儿童数字化施测的交互范式（Artemis-A 等 UCD 研究结论）

JMIR 发表的 Artemis-A（英国中学数字心理评估工具）用户中心设计研究给出的可直接借鉴结论：

1. **逐题呈现**优于长列表——降低认知负荷，完成率显著更高
2. **进度可见**（"还有 3 题"）减少中途放弃
3. **语言本地化改写不可行**（破坏信效度），但**语音朗读题目**、图形化选项（表情量尺）是允许的呈现层适配
4. 学生最反感"像考试"——施测应嵌入既有陪伴场景（本系统 = 波波小精灵引导）
5. 结果反馈给学生本人时必须**去病理化**（不出现"抑郁 12 分"字样）

## 三、总体架构

```
教师端发起施测任务                    学生端施测                         结果消费
┌──────────────────┐    ┌──────────────────────────┐    ┌─────────────────────┐
│ 选量表+选对象+定周期 │ →  │ 波波小精灵引导 · 逐题呈现    │ →  │ 计分引擎（纯规则，无LLM）│
│ (普测/个案复测)      │    │ 语音朗读 · 表情量尺        │    │ → assessment_results │
└──────────────────┘    │ 关键条目即时熔断           │    │ → 预警联动(S0-S3)     │
                        └──────────────────────────┘    │ → 教师端趋势视图       │
                                                        └─────────────────────┘
```

**模块归属**：`counseling-service` 新增 `assessment` 包（现无独立包）；不引入新服务。计分为纯规则计算，**零 LLM 调用**（量表计分必须确定性、可复现，这是 MBC 的前提）。

## 四、数据模型细化（在 design/06 四表基础上补充）

### 4.1 `assessment_scales.item_schema`（jsonb 结构定义）

```json
{
  "version": "1.0",
  "instructions": "过去两周里，以下问题困扰你的频率…",
  "items": [
    {
      "id": "phqa_1",
      "text": "做事时提不起劲或没有兴趣",
      "type": "likert",
      "options": [
        {"value": 0, "label": "完全没有", "emoji": "😀"},
        {"value": 1, "label": "有几天", "emoji": "🙂"},
        {"value": 2, "label": "一半以上时间", "emoji": "😐"},
        {"value": 3, "label": "几乎每天", "emoji": "😞"}
      ],
      "reverse_scored": false,
      "dimension": "depression",
      "critical": false
    },
    {
      "id": "phqa_9",
      "text": "…（自杀意念条目，原文不改写）",
      "type": "likert",
      "critical": true,
      "critical_threshold": 1
    }
  ]
}
```

要点：
- `critical: true` 条目触发**即时熔断**（见 §六），不等整卷完成
- 题目文本一字不改（信效度要求），儿童适配只做**呈现层**：emoji 量尺 + TTS 朗读
- `reverse_scored` 支持 SDQ 反向计分条目

### 4.2 `assessment_scales.scoring_rules`（jsonb 结构定义）

```json
{
  "method": "sum",
  "dimensions": {
    "depression": {"items": ["phqa_1", "...", "phqa_9"], "method": "sum"}
  },
  "bands": [
    {"min": 0,  "max": 4,  "level": "none",     "label": "无明显症状", "alert": null},
    {"min": 5,  "max": 9,  "level": "mild",     "label": "轻度",     "alert": "S3"},
    {"min": 10, "max": 14, "level": "moderate", "label": "中度",     "alert": "S2"},
    {"min": 15, "max": 19, "level": "mod_severe","label": "中重度",  "alert": "S1"},
    {"min": 20, "max": 27, "level": "severe",   "label": "重度",     "alert": "S1"}
  ],
  "critical_item_alert": "S0",
  "norm_reference": "Johnson 2002 PHQ-A validation"
}
```

要点：
- `bands` 完全照抄原始验证文献 cut-off，`norm_reference` 记录出处（可审计）
- SDQ 使用 `method: "banded_dimensions"`（五维分别分档 + 困难总分），常模引用中国修订版
- 计分引擎是 jsonb 规则解释器，新增量表**零代码**（开闭原则）

### 4.3 `assessment_tasks` 补充字段（设计期修订）

| 新增字段 | 类型 | 说明 |
|---------|------|------|
| `task_type` | varchar(20) | `screening`（普测）/ `followup`（个案复测）/ `adhoc`（临时） |
| `recurrence` | jsonb | MBC 复测周期，如 `{"interval_days": 14, "until": "case_closed"}` |
| `rater_type` | varchar(20) | `self` / `teacher` / `parent`（SDQ 三版本；家长版走 parent-h5） |

其余表结构不变；所有表带 `tenant_id`，走 Schema 级隔离（design/07 约定）。数据敏感等级：responses 明细 = **S4（应用层信封加密）**，results 分数 = S3，遵循 design/06 分级。

## 五、施测流程设计（学生端）

### 5.1 触发方式（两条路径）

| 路径 | 触发 | 体验 |
|------|------|------|
| **任务驱动** | 教师下发 → 学生登录后波波提示："老师想更了解你最近的心情，愿意和我聊几个小问题吗？" | 可延后（remind API 已有），最多提醒 3 次 |
| **对话内引导**（二期） | AI 对话中连续 2 次会话检出持续低落情绪 → 建议教师发起施测（**不自动施测**，保持教师在环） | 教师端收到建议卡片 |

> 设计决策：**不做 AI 自动发起施测**。施测是准专业行为，必须教师在环（human-in-the-loop），与 design/14 儿童安全规范"AI 不做诊断决策"一致。

### 5.2 施测交互（Artemis-A 范式落地）

1. **开场去考试化**：波波小精灵引导语"这不是考试，没有对错，选最像你的就好"
2. **逐题呈现**：一屏一题，emoji 表情量尺 + 文字选项，点选即翻页
3. **TTS 朗读**：每题自动朗读（复用 tts-service，persona 沿用学生当前音色），低年级他评版不涉及
4. **进度提示**：顶部圆点进度 + "还有 N 题"
5. **可暂停恢复**：`pause` API（已设计），断点存 `assessment_responses` 草稿态
6. **完成反馈（去病理化）**：只对学生说"谢谢你告诉我这些，波波更懂你了 ⭐"，**不向学生展示分数与分档**；积分/成就体系加一枚"心里话勋章"（复用 Achievements）

### 5.3 作答质量控制

- 单题作答 < 800ms 视为疑似乱点，连续 3 题触发波波温和提示"慢一点，想想再选哦"
- 整卷用时 < 量表最短合理时长（题数 × 1.5s）→ `assessment_results.validity_flag = 'suspect'`，教师端标注"作答过快，结果仅供参考"
- MHT 自带效度量表（Lie Scale）≥7 分 → 同样标记

## 六、关键条目即时熔断（安全设计，最高优先级）

PHQ-A 第 9 题（自杀意念）等 `critical: true` 条目命中阈值时：

1. **不等整卷提交**，前端立即上报该条目
2. 后端直接生成 **S0 级预警**（复用 alert 包现有通道：短信 + 站内 + 电话升级 SLA 15min）
3. 学生端**无缝切换**到安全陪伴流程：波波转入 design/04 风险应对话术（"谢谢你愿意告诉我…"）+ 心理援助热线卡片（12355 等），**量表流程静默终止但不告知学生"触发了警报"**
4. 剩余题目标记 `skipped_by_safety`，结果记录部分分 + 熔断标志

> 依据：业界数字化筛查工具（如美国 Columbia Protocol 数字化实践）一致要求自杀条目阳性必须即时响应，不允许"提交后批处理"。

## 七、结果消费与 MBC 闭环

### 7.1 量表分档 → 预警联动

按 §4.2 `bands.alert` 映射生成预警（S1/S2/S3），走既有 alert 流程与 SLA。**普测场景做聚合抑制**：同一班级普测产生的 S2/S3 预警合并为一条"班级普测结果摘要"推送，避免教师端预警轰炸（一个班 40 人普测可能产生十几条轻中度记录）。S0/S1 永不合并。

### 7.2 复测调度（MBC 核心）

- `task_type='followup'` 任务按 `recurrence` 自动生成下一次施测（默认 14 天，教师可改 7-28 天）
- 个案结案（design/05 个案生命周期第 4 阶段）时自动终止复测
- 复测提醒走既有 remind 通道

### 7.3 教师端呈现（与 design/35 联动）

- 学生详情页新增"测评趋势"卡片：同一量表历次总分折线 + 分档色带（绿/黄/橙/红）
- **可靠变化指标（RCI）提示**：分数变化 ≥5 分（PHQ-A 文献建议的临床显著变化）标注"显著改善/恶化"箭头，避免教师对 ±1 分波动过度解读
- 班级普测视图：分档分布直方图；**小样本抑制**（<10 人不显示班级聚合，防止反推个体，沿用 design/05 规则）

### 7.4 家长端（parent-h5，SDQ 家长版）

- 家长收到 H5 链接完成 SDQ 家长版（rater_type='parent'）
- 家长**只能看到自己填写的问卷与建议话术**，看不到学生自评分数（合规：design/22 告知同意范围）

## 九、合规与伦理

1. **知情同意**：施测属于 design/22 同意书覆盖范围需逐校确认；家长版首次施测前 H5 内嵌告知条款。**✅ 施测已定稿暂缓（2026-07-28，见头部）**：接线前须与首校共定施测方案并完成逐校同意确认，接线时点由钱敏健另行决策
2. **不做诊断**：所有结果呈现均标注"筛查结果不构成临床诊断，请咨询专业机构"——量表是筛查工具，这是 PHQ/GAD 官方使用条款的明确要求
3. **数据最小化**：学生端不留存分数；responses 明细 S4 加密，仅心理老师角色可见明细，班主任只见分档（沿用 design/05 权限矩阵）
4. **版权门禁**：见 §1.3，SDQ/MHT 未取得数字化许可前不得激活

## 落地记录

### SCALE-001 M1 计分引擎（2026-07-28 完成，不接线施测）

**范围**：scoring_rules jsonb 规则解释器 + PHQ-A/GAD-7 内置定义 + 关键条目即时熔断（零 LLM）

**实现文件**：
- `counseling-service/.../assessment/AssessmentScoringEngine.java`：@Component 计分引擎（sum/banded_dimensions + critical 熔断 + bands 分档）
- `counseling-service/.../assessment/ScoringResult.java`：record(totalScore/dimensionScores/bandLevel/bandLabel/alertLevel/criticalTriggered/criticalItemIds)
- `counseling-service/.../assessment/BuiltinScales.java`：PHQ-A(Johnson 2002 cut-off) + GAD-7(Spitzer 2006) scoring_rules JSON 常量

**关键设计决策**：
- 引擎接口 `score(scoringRulesJson, responses, criticalItemIds)` —— 新增量表零代码（开闭原则）
- critical 熔断优先于 bands 分档（phqa_9≥1 → S0 覆盖总分分档）
- 不建 entity/mapper/不接线（施测暂缓决策，待首校共定施测方案）

**测试**：AssessmentScoringEngineTest 24 用例金标准全绿（PHQ-A 5 档边界 + GAD-7 4 档 + 熔断 + 异常）

**未做（SCALE-002 M2）**：任务调度 + 复测 recurrence + 教师端趋势卡片 + 实体/表接线
