## 二、根因说明（为什么不能顺手完成）

- **生产数据回填**：现有声纹模板 TEXT embedding → vector(256) 列转换，涉及存量数据正确性（红线：数据迁移需独立设计 + 回滚方案）
- **阈值语义调优**：`<=>` 返回余弦距离（0=相同），现有 threshold 为余弦相似度——转换需回归验证，且 SEC-007"不回显相似度分数防阈值探测"防护不能破坏
- **写入链路影响**：`VoiceprintDomain.parseEmbedding`（TEXT 解析）调用方多处，改 vector 列影响 enroll/verify 全链路
- 需独立 SPEC（AC 验收 + 回滚 + 性能基准），非小步可交付

## 三、解冻流程

声纹模板量级达到性能阈值（或向量检索需求立项）时，由项目负责人发起解冻；
实施回 doing/90 P-003 深化方向（V46 迁移 + SQL 相似度 TOP-K + 阈值回归），
验收按独立 SPEC 的 AC 清单。
