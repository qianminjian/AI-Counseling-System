## 一、设计原则（继承 design/14 §6 铁律）

1. **转人工动作绝不经过 LLM 判断**——纯规则执行，100% 确定性触发。
2. **话术用预审核常量**——复用 `RecallPhrases` 常量模式，不经 LLM 生成，防幻觉。
3. **只升不降**——学生自报"我安全了"不自动降级会话，解除由教师处置完成。
4. **幂等防风暴**——已 escalated 会话重复点击不重复通知。
5. **会话归属校验前置**——防跨租户/跨学生劫持（既有 `isSessionOwner` 模式）。
6. **复用优先**——通知/SLA/热线全部复用既有组件，不新建平行链路。

## 二、后端设计

### 2.1 端点契约

```
POST /api/v1/chat/sessions/{sessionId}/escalate
Authorization: Bearer <学生 JWT>

请求体（可选）：
{
  "reason": "student_initiative"   // student_initiative=主动求助 | safety_button=safety_mode 按钮
}

响应 200：
{
  "escalated": true,
  "teacherName": "王老师",          // 归属心理老师，无则 null
  "responsePhrase": "好的，老师已经知道了。…",  // 预审核安抚话术常量
  "hotlines": ["400-161-9995"]      // SAFE-203 租户配置化热线
}

响应 200（幂等命中，会话已 escalated）：
{
  "escalated": true,
  "alreadyEscalated": true,
  "responsePhrase": "老师已经知道啦，你做得很对。…"  // 不重复通知，仅安抚
}

错误：403 会话归属校验失败；20003 CONSENT_REQUIRED（监护人同意门禁，与既有端点一致）
```

### 2.2 处理链（ConversationService.escalateSession）

```
1. 会话归属校验 isSessionOwner(tenantId, studentUserId)（防劫持）
2. 监护人同意门禁（与 ChatController 既有端点一致）
3. 幂等判断：sessionStatus 已 escalated → 返回安抚文案，不写事件不通知
4. 写 risk_events：
   - risk_type = student_initiated_escalation
   - risk_level = RED
   - source_type = student_action
   - evidence = 学生最近一轮原话（加密存储，对齐 FieldEncryptionService 既有模式）
5. 会话置 escalated + 安全响应模式（后续消息走 RED 硬短路，既有逻辑自动接管）
6. AlertService 通知：
   - WebSocket 实时推归属心理老师（AlertWebSocketHandler 既有通道）
   - 企微 webhook 兜底（WeComAlertService 既有出口）
7. 返回预审核安抚话术（不经 LLM）
```

### 2.3 升级链（无新代码）

- 立即：WebSocket 推在线教师（教师端已有弹窗/声音）。
- 5 分钟未认领：`SlaEscalationScanner` 既有机制覆盖——需确认 `AlertSlaPolicy` 对 `student_initiated_escalation` 类型生效（实施时加一个用例守卫，非新逻辑）。
- 「自动改派备份老师」仍归 WB-001，本项不扩。

### 2.4 数据库

**无 schema 变更**。risk_events 既有表 + 既有 JSONB evidence 字段足够。

## 三、前端设计（student-h5）

### 3.1 safety_mode 状态机

```
触发源 A（系统）：SSE 流收到 RED 安全模板 → 自动进入 safety_mode
触发源 B（主动）：学生点击常驻「找老师」入口 → 确认弹窗 → POST /escalate → 进入 safety_mode

safety_mode 界面：
  - 输入框禁用（含语音输入）
  - 三个大按钮（儿童友好尺寸，复用 design/36 工具箱 SOS 视觉语言）：
    [找老师]   → POST /escalate（reason=safety_button）
    [打电话]   → tel: 协议拨打 SAFE-203 配置热线
    [我安全了] → 不降级，仅追加 risk_event 学生自报信号（source_type=student_report）

退出条件：教师端处置完成（claim/resolve）后，下一会话正常开启；
本会话内不自动退出（只升不降原则）。
```

### 3.2 常驻「找老师」入口

- 位置：对话页非侵入式常驻入口（建议设置区/对话页角落，具体随实施时界面详细设计）。
- 任意会话状态可点击（非仅 RED 后）——这是当前系统**唯一**的学生主动求助通道。
- 点击后二次确认（防误触）：「要让老师来陪你吗？」→ 确认后调用 /escalate。

### 3.3 TTS 联动

- safety_mode 下暂停 TTS 播放队列；安抚话术用低语速预合成路径（TTSFX-002 风险语音降级既有策略）。
