## 一、背景与目标

### 1.1 背景

系统现有自动化验证体系（design/05 §8）：

| 层 | 现状 | 缺口 |
|----|------|------|
| 单测/集成 | 后端 1466 + 前端 713 + Python 110 全绿 | 不覆盖真实浏览器渲染/交互 |
| 契约测试 | 三层防线（L1/L2/L3） | 只验证接口契约，不验证页面行为 |
| 冒烟测试 | smoke-test.sh（31 断言，curl 层） | 只验证 API 链路，**零 UI 交互验证** |
| UI 层 | R-4 仅登记 Playwright 预留态 | **无任何真实浏览器端到端遍历** |

结论：**三端 Web 界面从未被真实浏览器自动化遍历过**。本设计落地 R-4，用 Browser Agent 对三端 + 三端联动业务场景做全面遍历测试。

### 1.2 目标

1. 对三端（学生端 / 教师端 / 家长端）全部已实现页面与核心交互做浏览器级遍历，验证 UI 行为与 design/05 §4~§6 测试要点一致
2. 对三端之间按设计的数据联动与业务场景联动（F-01~F-07 + 家长端联动）做端到端验证
3. 每个测试发现的问题按「三端 + 场景」汇总登记问题清单
4. 每个端测试完毕后：自动按问题清单修复 → 自动部署 → 自动复测，直到该端收敛

### 1.3 范围边界

- **范围**：三端已实现功能（design/08 §1.1~§1.5 状态 🟩/🟫 模块）；F-06 测评流程（⬜ 门禁）、frozen/* 冻结专题不在遍历范围
- **不做**：性能压测（k6 已就绪，按需）、多实例高可用；**被测环境为 https://yun.gxjugu.com/ UAT 测试环境（HTTPS，2026-08-09 确认）**——数据全部为测试数据，系统范围内允许自由创建/修改/删除、无需恢复（§3.2 权限定义）；本地 test compose 仅作修复后复测与降级路径辅助环境
- **语音类**：分层自动化（见 §4.4）——声纹/ASR/TTS 服务级 API 与本地真链路可测（L0/L1），test compose 降级路径照常断言（L2）；对话窗口 7 类专项（性能/转写/长语音/唤醒/记忆/暖场/超时降级）见 §5.5 C-01~C-07

## 二、执行架构

### 2.1 工具链与执行方式

| 角色 | 工具 | 用途 |
|------|------|------|
| 执行器 | **Browser Agent**（Agent 子代理，含 browser-use/chrome-devtools MCP 或 agent-browser CLI） | 打开浏览器、导航、点击、输入、截图、断言 |
| 被测环境 | `https://yun.gxjugu.com/`（**UAT 测试环境**，nginx 反代：`/mindsafe/` `/teacher/` `/parent/`） | UAT，HTTPS |

| 部署 | `deploy.sh`（唯一发布通道，design/04 §5.6）或本地 compose 重建 | 修复后自动部署 |
| 复测 | Browser Agent 重跑失败场景 | 验证修复闭环 |

### 2.3 执行顺序

1. **环境与数据准备**（§三）→ 2. **学生端遍历**（S-01~S-10）→ 修复循环 → 3. **对话窗口专项**（C-01~C-07，学生端对话室为核心，含假麦克风注入与语音真链路）→ 修复循环 → 4. **教师端遍历**（T-01~T-08）→ 修复循环 → 5. **家长端遍历**（P-01~P-06）→ 修复循环 → 6. **联动场景**（L-01~L-06，依赖前三端账号与数据）→ 修复循环 → 7. 汇总报告 + 合并归档

> 依赖说明：L 场景依赖 S/T/P 端修复收敛后的环境，故联动排在最后；S 场景产生的对话/预警数据是 T 场景与 L 场景的前置数据源（UAT 测试数据，保留供后续场景复用，无需恢复）。

### 4.4 语音类：三层自动化策略（升级自 SKIP-语音）

声纹登录（remote）、ASR 录音、TTS 朗读不再整体跳过，按链路分层（2026-08-09 调研结论，见 doing/66 §4.4 关联）：

| 层 | 能力 | 环境 | 落地方式 |
|----|------|------|---------|
| L0 服务级 API | 声纹 enroll/verify（纯 256 维向量比对，不传音频）、ASR analyze（合成音频直传）、TTS synthesize（edge-tts 免 key） | CI / 本地开发机 | 后端测试 + Python 脚本（先例 `test_dashscope_asr_e2e.py` 合成正弦波） |
| L1 本地真链路 | **唤醒词（纯前端 whisper-tiny ONNX WASM 本地推理，test compose 即可测）**、ASR/TTS 经后端同源代理 | test compose + 开发机单独起 voice/tts（uvicorn 或容器，nginx 无需改） | Browser Agent UI + 服务级脚本 |
| L2 降级路径 | browserSpeak 兜底、浏览器识别、引擎失败提示 | test compose（无 voice/tts 即降级态） | S-04 内嵌断言 + C-07 降级链 |

- **唤醒词链路不依赖 voice/tts**（浏览器本地推理），照常全测（C-04）；
- 声纹按钮存在性 + 隐私文案（"声音信息只保存在这台设备上"）照常断言；
- ASR/TTS 真链路在本地开发机单独起服务后，前端经后端代理自动打通；
- 对话窗口 7 类专项（性能/转写准确性/长语音/唤醒灵敏/上下文记忆/暖场/超时降级）场景见 §5.5（C-01~C-07），UI 提示词见 §6.6。

## 八、自动修复-部署-复测循环

### 8.1 触发时机与范围

- **触发**：每端（S/T/P/L/C 五组）场景全部执行完毕，问题清单落盘后立即触发
- **修复范围**：该端 P0/P1 **必须修复**；P2/P3 每轮最多修 3 条（防范围蔓延，其余登记排期）
- **循环轮次上限**：每端 **3 轮**（第 1 轮修 P0/P1 + 顺手 P2/P3；第 2 轮修剩余 + 复测失败项；第 3 轮收尾）

### 8.2 循环步骤（每端执行）

| 步 | 动作 | 细节 | 退出条件 |
|----|------|------|---------|
| 1 | 解析问题清单 | 读 ISSUES-<端>.md 中状态=OPEN 且属本轮的条目 | 无条目 → 直接进入汇总 |
| 2 | 自动修复（TDD） | 每条问题：①先写失败测试（复现该 bug 的最小用例）→ ②修复 → ③全量回归（该模块 `mvn test`/`vitest run` 对应套件，串行 maxThreads=1） | 该端所有目标条目 FIXED 且回归全绿 |
| 3 | 自动部署 | 本地：`docker compose -f deploy/docker-compose.test.yml build frontend backend && up -d`；远程：`./deploy.sh`（唯一发布通道，含 smoke 门禁）；部署后必须 `curl /actuator/health` UP + `smoke-test.sh` 通过 | 部署成功 + smoke 通过 |
| 4 | 自动复测 | 仅重跑该端**失败场景**（复用 §六提示词，Agent 只执行 BUG 对应步骤 + 原场景全步骤） | 原失败断言通过 |
| 5 | 更新状态 | 通过 → `FIXED→VERIFIED`；仍失败 → `REGRESSION`，回滚该修复（`git revert`）重新 OPEN，进入下一轮 | 该端 P0/P1 全 VERIFIED 且 P2/P3 未关闭 ≤ 3 |
| 6 | 轮次控制 | 达 3 轮仍未收敛 → 停止自动循环，升级人工（输出：未收敛问题清单 + 修复尝试记录） | 人工介入 |

### 8.3 修复纪律（对齐项目规则）

- **TDD 强制**：修复必须「先红后绿」（.qoder/rules/tdd-workflow.md）
- **回归纪律**：全量回归每次只跑一次，串行 worker（vitest maxThreads=1 已配置级写死）；查测试详情改读报告文件，不重复跑
- **提交粒度**：每条问题独立 commit（`fix(<scope>): BUG-<ID> <简述>`），check-commit.sh --last 1 门禁
- **不得**：删除文件/改 .env/动 DB schema（红线，需人工确认）

### 8.4 收敛定义（该端完成）

```
该端：P0 = 0 且 P1 = 0 且 P2/P3 未关闭 ≤ 3 且 未关闭条目均已在 ISSUES-闭环记录.md 登记排期
```

### 8.5 全局完成定义

```
三端 + 联动 + 对话专项五组全部收敛 → ISSUES-SUMMARY.md 终版（含回归结论）→ 测试报告落 reports/browser-test/ 根目录
→ 本 doing/82 设计文档合并归档（按主题归入 design/05 §8 测试体系 + design/08 §2 流程四态，过程数据不入主文档）
```
