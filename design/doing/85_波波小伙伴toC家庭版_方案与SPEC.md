## 二、家长端模式（抽取自 74 §1.5）

```
【初始设置】（家长，一次性）
  家长手机号注册/登录（验证码）
  → 创建使用者档案（孩子昵称/年龄/性别/兴趣，一账号多孩）
  → 绑定设备（扫码/搜索附近设备）
  → 配网（Soft-AP，终端连家庭 WiFi）
  → 个性化设置（波波角色/音色/对话偏好/互动预期）

【日常使用】（孩子，无屏自然交互）
  抱/摸波波 → 捏一捏/语音 → 对话聊天

【家长查看】（家长端 App/H5）
  成长报告（周报：兴趣演变/情绪变化/心理洞察，算法提炼非原始对话）
  → 预警通知（识别风险信号推送家长）
  → 远程管理（音量/灯光/音色/对话偏好）
```

**家长端核心功能**（与老师端二合一，能力一致仅数据范围不同）：

| 功能 | toC 家长端 | toB 老师端 | 二合一说明 |
|---|---|---|---|
| 注册/登录 | 家长手机号注册 | 老师账号（学校分配） | 统一账号体系，角色区分 |
| 使用者管理 | 创建孩子档案（一账号多孩） | 学生档案（班级批量导入） | 统一档案模型，数据来源不同 |
| 设备绑定 | 绑定家庭波波终端 | 绑定学校波波终端 | 统一设备管理，归属不同 |
| 成长报告 | 自己孩子的周报/心理洞察 | 班级/全校报告 | 同一报告引擎，数据范围不同 |
| 风险预警 | 自己孩子的预警 | 班级/全校预警 | 同一预警引擎，推送对象不同 |
| 远程管理 | 音色/音量/灯光/对话偏好 | 音色/默认心情/设备状态 | 同一配置能力，权限不同 |
| 隐私合规 | 儿童隐私（个人信息保护） | 校园数据合规 | 统一合规框架，场景适配 |

**二合一架构价值**：报告引擎/预警引擎/档案模型/设备管理/配置能力一套代码（DRY），角色+数据范围区分；家校协同可选（数据授权互通）。

## 三、隐私红线（toC 家庭场景特有，抽取自 74 §1.6）

- **报告替代原始对话**：家长看算法提炼的心理洞察（非对话原文）——尊重孩子隐私权
- **孩子知情**：孩子知道"波波会把我的心情告诉爸爸妈妈"（透明不欺骗）
- **最小化收集**：仅收集对话必需语音/文本，不收集位置/相册/通讯录等无关权限
- **本地优先**：声纹/唤醒本地处理，敏感数据本地/私有化存储
- **家长控制**：查看/删除数据、关闭设备、设置使用时间
- **风险缓解**：私有化部署 + 报告替代原始对话 + 内容安全围栏 + 透明知情

## 八、toC 部署形态（TOC-009 落地，2026-08-10）

### 8.1 云端 SaaS（默认，已落地）

- **多租户隔离**：toc_family_accounts / toc_child_profiles / device_preferences 全部平台级表（tenant_template schema，无 tenant_id 列，TenantLineHandler 豁免），数据隔离键 = family_account_id（token 上下文注入，客户端不可指定——TocProfile/TocDevice/TocPrivacy/TocPreference 全部端点验证）
- **账号体系**：手机号验证码注册/登录（独立于校园体系），PLATFORM 级平台表天然跨租户
- **部署**：与 toB 同机/独立实例均可（后端无租户依赖），Nginx 路由 /api/v1/toc/** 与 /api/v1/parent/** 并存

### 8.2 家庭私有化（备选，方案文档化）

- 形态：家庭树莓派/迷你主机部署精简栈（PostgreSQL + Redis + counseling-app 单实例 + tts/voice 本地模型），数据不出家（与 toB 私有化红线一致）
- 差异点：toc 表无需多租户隔离（单家庭），TenantLineHandler 豁免表维持不变；验证码通道需本地短信网关或语音播报
- 演进条件：云端 SaaS 验证商业模式后评估；不在本期实施（YAGNI）
