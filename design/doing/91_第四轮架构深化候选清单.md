## 二、候选清单

### Q-001 敏感类别收敛（单一规则源）【Strong】

- **涉及**：LongTermMemoryService.SENSITIVE_EMOTIONS（L52 硬编码集合）vs counseling-ai safety/HighSensitivityCategories（L22）
- **问题**：同一"高敏感情绪"概念两处独立维护——记忆域召回评分与 AI 安全过滤各用一套，新增情绪类别需双点修改，漏改即风险评估口径分裂（记忆误判 vs 过滤漏判）。
- **解决**：收敛为单一规则源（common 或 ai 包导出，记忆域依赖）。
- **删除测试**：删一处 → 集中（真正深度在"谁定义敏感"——显式化后单点维护）。

### Q-002 租户忽略名单规则化（迁移一致性测试）【Strong】

- **涉及**：MindSafeTenantLineHandler.IGNORE_TABLES——近三天 4 提交（4c64ad9/c6bb2cc/9d82870/4d39665）连续手工追加
- **问题**：新平台表漏加 → 注入不存在 tenant_id 列 → SQL 500（fail-fast 但误伤生产）；his/88 AD-003 已列候选未实施——**下个平台表（如声纹向量化 V46）必踩**。
- **解决**：列表 → 可推导规则（表无 tenant_id 列即平台表）或迁移一致性测试（遍历迁移文件断言平台表 ∈ 名单）。
- **删除测试**：名单无法删（fail-fast 保护），问题在来源。

### Q-003 平台表 schema 边界收敛【Strong（独立批次）】

- **涉及**：V34 注释自称"平台级事件表"却 CREATE TABLE tenant_template.degradation_events；V35/V39/V42-45 同模式
- **问题**：schema 命名承载"模板"语义，平台级表物理落此——边界与语义漂移；迁移工具按模板 schema 建租户时若复制该 schema，平台表被误复制。
- **解决**：平台表收敛至独立 platform schema（或显式决策 tenant_template 为"默认 schema"重命名语义）。涉生产迁移（搬迁 + 回滚设计）——**独立批次，参照 P-003 冻结先例可登记 frozen**。

### Q-004 降级话术数据面标记【Worth exploring】

- **涉及**：LlmStreamEnhancer / ResilientChatModel 降级链——降级提示以 token 事件流入流式响应
- **问题**：降级话术被记忆提炼/质量评分/审查当真实用户样本消费（数据面污染不止展示层）。
- **解决**：降级响应加显式标记（meta/事件类型），消费方（MessageSummaryService/QualityService）过滤。
- **删除测试**：删标记 → 污染回归（需先有测试锁定）。

### Q-005 AiChat 同步辅助链路加固【Worth exploring】

- **涉及**：AiChatServiceImpl——4 个同步 LLM 方法无超时 + 暖场零审计 + 4 个 Prompt 硬编码
- **问题**：同步辅助调用无超时 → 上游慢速时请求线程悬挂；暖场无审计 → 运营盲区；Prompt 硬编码 → 不可配置。
- **解决**：同步调用包超时（复用 ResilientChatModel 降级链超时语义）；暖场接审计（auditOperation 模式）；Prompt 收 PromptVersionService 管理。

### Q-006 错误码面收敛（P-010 模式延续）【Worth exploring】

- **涉及**：ErrorCode 单一文件 vs 各处 IllegalArgumentException/IllegalStateException
- **问题**：同一错误语义多种抛出方式 → 全局异常处理器映射面不完整，前端错误码契约漂移。
- **解决**：全量扫描 IllegalArgumentException 抛出点，收敛 BizException 风格。

### Q-007 迁移序列一致性检查【Worth exploring】

- **涉及**：counseling-app migration/（V24-V45）
- **问题**：Q-003 schema 边界矛盾 + 近三天新增迁移（V44/V45）延续平台表挂 tenant_template 模式。
- **解决**：迁移模板/检查脚本（verify 平台表 schema 归属）+ Q-003 独立批次连带。

### Q-008 指标口径收敛（N-004 关联）【Worth exploring】

- **涉及**：monitoring/MetricsQueryService + OpsService（近三天 7 次变更）
- **问题**：指标查询端点口径与 TeacherService.getStats/DataAnalyticsService 三处统计并行（his/89 N-004 未实施）。
- **解决**：N-004 Metric VO 族深化批次连带覆盖。

### Q-009 CI 流程变更感知【Speculative】

- **涉及**：.github/workflows/ci.yml
- **问题**：后端单元/前端/联通/覆盖率门禁全量跑 vs 变更感知（待细查）。
- **解决**：paths 过滤降本。

### Q-010 日志脱敏规则源收敛【Speculative】

- **涉及**：counseling-app/logging/PiiDesensitizingAppender + ai/PiiDesensitizer
- **问题**：脱敏器双处（同 Q-001 模式），覆盖模式一致性待细查。
- **解决**：收敛单一脱敏规则源。
