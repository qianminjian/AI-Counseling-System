## 2. 事项详情

### 2.1 DEP-001 变量名错配修复（本次登记，P0）

**问题**：`deploy/docker-compose.prod.yml:78` 写 `MINDSAFE_CONSENT_TRIAL_AUTO_GRANT: ${CONSENT_TRIAL_AUTO_GRANT:-false}`，与 `.env.example:41`（`MINDSAFE_CONSENT_TRIAL_AUTO_GRANT`）及 dev compose:97 不一致 → prod 部署中 `.env` 配置该开关**静默失效**，永远取默认 false。

**修复**：`:78` 改为 `${MINDSAFE_CONSENT_TRIAL_AUTO_GRANT:-false}`。

**风险说明**：当前默认 false 恰为安全值（fail-closed），无实际危害；但若试运行期意图开启 true（跳过 SMS 监护人验证）会静默失效——表现为 age<14 试用用户注册后 guardian_consent 缺失、被 ChatController 门禁拦截。**开启 true 属合规决策（PIPL §31 未成年人同意豁免），须钱敏健显式拍板**，与部署修复解耦。
