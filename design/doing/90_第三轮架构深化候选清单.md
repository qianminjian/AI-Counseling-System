## 二、候选清单

### P-001 客户端 IP 解析统一（ClientIpResolver 公共组件）【Strong】

- **涉及**：AuditLogService.extractClientIp（L113 取 XFF 最左 split(",")[0]）vs VoiceprintDomain.resolveClientIp（L108 取最右，注释论证最右不可伪造）
- **问题**：同一"客户端 IP"概念两套相反语义——审计 IP 哈希可被伪造 XFF 头污染（攻击者加 XFF 前缀覆盖真实 IP），安全审计失真。
- **解决**：`ClientIpResolver` 公共组件（取最右不可伪造语义），AuditLogService 与 VoiceprintDomain 收敛共用。
- **删除测试**：删双实现改单组件——集中。

### P-002 四空壳域清理（experiment/offline/cache/metrics）【Strong】

- **涉及**：service/experiment（零文件，MoodCheckRecorder 注释声称效果数据进 design/39）/ offline（零文件）/ cache（零文件，PromptVersionService 手写缓存无处收敛）/ metrics（零文件，实现在 monitoring 包）
- **问题**：4 个命名空壳域——metrics 实现移位（包与域分裂）；experiment 消费方缺失；cache 无收敛点。
- **解决**：metrics 目录删除或 monitoring 对齐；experiment 补消费或删声明（YAGNI 裁决）；cache 域留待 PromptCachePort 落地时创建。

### P-003 声纹 1:N 比对 pgvector 化（技术杠杆跨域复用）【Strong】

- **涉及**：VoiceprintVerifyService（L63-113，全租户模板加载内存 + 三重循环 O(N×M×K)）
- **问题**：pgvector 已引入（KB 域在用），声纹 embedding 未入向量列——每次 verify 全量内存比对，会话量大即瓶颈。
- **解决**：声纹 embedding 入 pgvector 列，verify 走 SQL 相似度 TOP-K。
- **验证补充**：声纹与主认证关系正确（认证因子适配器 + 共用 JwtTokenProvider 签发内核，非重复造轮子）。

### P-004 PromptVersionService 缓存与聚合深化【Worth exploring】

- **涉及**：PromptVersionService（560 行，8 依赖；L75-76 手写 ConcurrentHashMap 5 分钟 TTL；L447-510 AB 双 Mapper 内存分组）
- **问题**：多副本部署 invalidateCache() 仅清本地实例（AB 组切换读到过期版本）；AB 聚合无分页/无 SQL 聚合；KEY_TO_CLASSPATH 27 个模板 key 手工映射。
- **解决**：缓存抽 `PromptCachePort`（Redis 实现）；AB 下沉 SQL 聚合或分页游标。状态机本身三门禁完整（深度良好）。

### P-005 student-h5 LoginPage 真实 UI 缺陷×2【Strong（真实 bug）】

- **涉及**：student-h5/src/components/LoginPage.tsx（665 行）——L254 `className="login-field login-field--${themeId}"`（**双引号不插值**，主题样式静默失效）；L224/L375 pin.length < 7 允许第 7 位（文案与 disabled 声明 4-6 位）
- **问题**：主题类名永远字面量（主题切换无声失败）；PIN 上限 7 vs 声明 6（修复未达声明）。
- **解决**：L254 改反引号模板串；PIN 上限收敛为 6（与文案/disabled 一致）。引入时间 7/30（f02a0fb4），非近三天。

### P-006 nginx 声纹公开端点限流补层【Worth exploring】

- **涉及**：deploy/nginx/default.conf（L97-123 limit_req 仅覆盖 /auth/ 与 /parent/auth/）
- **问题**：/api/v1/voiceprint/verify（公开 + 计算昂贵）未纳入网关层——认证端点有网关+应用双闸，声纹端点只有应用单闸。
- **解决**：nginx 补 /voiceprint/ 限流区（与 /auth/ 同配置）。

### P-007 metrics_common 复制共享收敛【Worth exploring】

- **涉及**：tts-service app.py L57 注释自证"与 voice-service 复制共享"metrics_common.py
- **问题**：指标契约改动需双点同步（复制粘贴共享违反局部性）。
- **解决**：提为共享包（backend/common 或 wheel）或生成同步。连带：voice-service 降级语义不对称（funasr fail-fast vs SER fail-soft）需统一策略。

### P-008 tenant archived 漂移 + 配额常量死代码【Worth exploring】

- **涉及**：TenantProvisioningService（L26-27 声称三态 active/suspended/archived，代码无 archived 路径；L36-37 默认配额常量无消费方——死代码）
- **问题**：声明接口与真实深度不符；租户状态语义被两处解释（tenant 域 + billing TenantPlanResolver）。
- **解决**：补 archived 实现或删注释收敛声明；状态→计划映射收敛为 TenantPlanResolver 单点。附带：wecom 复用 pseudonym 字段暂存企微 ID（字段语义复用，画像域误读风险）。

### P-009 admin-web 风险等级映射收敛【Worth exploring】

- **涉及**：RiskPage L27-28 / SlaPage L13 / LedgerPage L28（levelName/levelColor 字典复制三份）
- **问题**：改色需三处同步；五页全是 fetch→setState→antd Table 样板（无 useAdminTable hook）。
- **解决**：等级映射收敛共享常量模块；抽 `useAdminTable`。

### P-010 小域策略不统一【Speculative】

- **涉及**：KnowledgeBaseService（L283 门禁校验由调用方完成——域内无 ReviewPolicy 接口）/ notification markAsRead 抛 IllegalArgumentException（异常风格分裂）/ DataRetentionCleanupJob（4 条 delete 无事务无分批）
- **解决**：门禁上移域内 ReviewPolicy 接口；异常风格统一；留存清理分批+事务。
