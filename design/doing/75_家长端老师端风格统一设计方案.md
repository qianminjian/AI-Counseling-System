## 一、现状分析

### 1.1 家长端（parent-h5，Taro 4 + React 18）

样式集中在 `src/app.scss`（401 行，已类名化，Taro 化完成）：

| 维度 | 现状 |
|------|------|

| 背景 | `#f5f7fa` 浅灰 + 白色卡片（圆角 12px、阴影 0 2px 8px） |
| 语义色 | 危险 `#e74c3c` / 成功 `#27ae60` / 警示 `#e67e22` / 次要文字 `#7f8c8d` |
| 形态 | 全宽 48px 按钮、胶囊按钮（圆角 24px）、输入框 48px 圆角 10px |
| 问题 | 蓝白工具风，无品牌记忆点；与老师端、学生端无视觉关联 |

### 1.2 老师端（teacher-web，React + antd）

`src/index.css` 仅 5 行 body 基础样式，**全部样式为组件内联 style**：

| 维度 | 现状 |
|------|------|
| 技术栈 | antd（Layout/Menu/Card/Form/Table）+ 内联 style 覆盖 |
| 登录页 | 紫蓝渐变背景 `#667eea → #764ba2` + 🛡️ emoji + 白卡片 |
| 工作台 | Header/Sider/Content 布局 + 12 个功能面板（Overview/AlertQueue/Student/Admin/Platform/Quality 等）+ BigScreen 大屏 |
| 混杂色 | 浅蓝 `#4fc3f7` / 绿 `#07c160` / 黄 `#ffd54f` / 粉 `#ff8a80` / 紫 `#ce93d8` / 灰 `#999` |
| 问题 | 无设计体系；内联样式不可维护；色彩无语义约束（黄粉紫随用） |

### 1.3 学生端（student-h5，参考基准）

马卡龙彩色系：粉 `#be185d`/`#9d174d` + 薰衣草 `#818cf8`/`#8b5cf6` + 青 `#06b6d4`——儿童向、活泼。

### 1.4 结论

- 家长端：有基础体系但无品牌感，蓝白工具风；
- 老师端：无体系，颜色混杂，与家长端零关联；
- 三端无统一品牌语言（同产品 MindSafe 心理健康，三端风格割裂）。

## 二、设计约束（不可妥协项）

1. **心理健康行业**：主色避免高饱和红/橙大面积使用（刺激焦虑），优先青/蓝/紫/暖中性
2. **成年人工具**（家长 H5 移动端 / 老师 Web 工作台 + 大屏）：专业可信、信息密度适中、可长时间注视
3. **与学生端差异化**：儿童端马卡龙彩已确立，成人端用同品牌系但降低饱和度、提高专业度
4. **技术落地约束**：家长端 Taro app.scss 用 CSS 变量 token 化；老师端 antd 用 ConfigProvider theme token + 内联样式收敛（不能重写 12 个面板，需低风险渐进式）
5. **语义色分离**：无论选哪个主色系，危险/警告/成功语义色需单独定义（方案 C 暖橙需特别处理与警示色冲突）

## 三、候选方案（4 个）

### 方案 A「青屿」—— 治愈青绿 · 自然平静系（推荐）

> 定位：像湖面一样平静。心理健康场景最贴合的色彩心理学选择，青绿色系被广泛验证具有平静、信任、恢复感。

**色板 token（实际落地命名 `--ms-*`，两端共用同一套变量名）：**

| Token | 值 | 用途 |
|-------|-----|------|
| `--ms-primary` | `#2BA8A0` | 主色（按钮/链接/选中态） |
| `--ms-primary-strong` | `#1E7F7A` | 主色按压/渐变深端 |
| `--ms-primary-soft` | `#E8F6F4` | 浅色填充/选中背景 |
| `--ms-bg` | `#FAF9F6` | 页面背景（暖米白，非纯灰） |
| `--ms-bg-elevated` | `#F4F7F6` | 输入框/次级按钮底 |
| `--ms-card` | `#FFFFFF` | 卡片 |
| `--ms-text` | `#22303A` | 主文字（深青灰，非纯黑） |
| `--ms-text-secondary` | `#5C6B76` | 次文字 |
| `--ms-text-muted` | `#8A97A0` | 弱文字/占位 |
| `--ms-border` | `#E3E8E6` | 常规边框 |
| `--ms-border-soft` | `#EEF2F0` | 浅底边框（tab 容器等） |
| `--ms-success` | `#2E9E6B` | 成功 |
| `--ms-success-soft` | `#E8F6EE` | 成功浅底 |
| `--ms-warning` | `#D98E32` | 警告 |
| `--ms-warning-soft` | `#FDF1E3` | 警告浅底 |
| `--ms-warning-border` | `#F2DCC0` | 警告边框 |
| `--ms-danger` | `#D9534F` | 危险 |
| `--ms-danger-soft` | `#FDEBEA` | 危险浅底 |

**形态 token：** 圆角 16px（卡片）/ 12px（输入框）/ 24px（胶囊按钮）；阴影 `0 4px 16px rgba(43,168,160,0.08)`；间距基准 8px 网格。

**组件特征：**
- 按钮：主色实心、次要描边、危险保持语义红（浅底 + 红字）
- 卡片：大圆角 + 极浅青绿阴影，顶部可带 4px 主题色条
- 输入框：浅青灰底、聚焦青绿描边
- 老师端工作台：Sider 深青 `#163B38`、激活项青绿软填充；预警队列用语义色分级（黄/橙/红）
- 登录页：米白底 + 右上青绿渐变光晕（克制，不整屏渐变）

**落地：** 家长端 CSS 变量替换 app.scss 全部色值（机械替换，视觉重映射）；老师端 antd `ConfigProvider theme.token.colorPrimary='#2BA8A0'` + 收敛 12 面板内联色。

### 方案 C「暖杏」—— 温润暖橙 · 家庭亲和系

> 定位：像回家一样温暖。家长端天然的家庭温度感，老师端温暖不冰冷；与主流蓝绿竞品形成差异。

**色板 token：**

| Token | 值 | 用途 |
|-------|-----|------|
| `--brand-primary` | `#E08A5E` | 主色（暖杏橙） |
| `--brand-primary-strong` | `#C96F4A` | 按压/渐变深端 |
| `--brand-primary-soft` | `#FDF1EA` | 浅色填充/选中背景 |
| `--bg-page` | `#FFF9F4` | 页面背景（奶油白） |
| `--bg-card` | `#FFFFFF` | 卡片 |
| `--text-primary` | `#3D322B` | 主文字（暖深棕，非纯黑） |
| `--text-secondary` | `#7A6A5E` | 次文字 |
| `--text-tertiary` | `#A89A8E` | 弱文字/占位 |
| `--semantic-success` | `#3E9B6B` | 成功（绿，与主色分离） |
| `--semantic-warning` | `#C77B1E` | 警告（深琥珀，与主橙拉开） |
| `--semantic-danger` | `#C0392B` | 危险（深红，必须与主橙区分） |
| `--border-default` | `#F0E6DC` | 边框（暖米） |

**形态 token：** 圆角 18px（卡片）/ 12px（输入框）/ 28px（胶囊按钮）；阴影 `0 4px 20px rgba(224,138,94,0.10)`；留白多、字重柔和。

**组件特征：**
- 按钮：主橙实心胶囊；危险操作深红描边按钮（视觉明确区别于主色）
- 卡片：暖米边框 + 奶油底点缀，顶部圆角大
- 老师端工作台：Sider 暖白 `#FFF4EA` + 主橙激活条；预警分级：警告用深琥珀、危险用深红（与主橙严格分离，防混淆）
- 登录页：奶油底 + 左下暖橙渐变光晕
- 大屏：暖黑底 `#2B211B` + 琥珀数据光效

**落地：** 家长端全量色值替换 + 圆角调整；老师端 antd `colorPrimary='#E08A5E'` + 语义色专项检查（AlertQueue 的黄/红不改，粉紫改暖系）。

**风险提示：** 橙色系与"警告"语义天然接近，主色大面积使用需配合第 5 条语义色分离约束；建议家长端主橙占比 ≤30%（白底为主），老师端预警组件主色占比低、语义色占比高。

**落地：** 家长端色值替换 + 登录/隐私页软底；老师端 antd `colorPrimary='#6C5CE7'`，登录页渐变替换为品牌双紫，12 面板粉紫色收敛为语义色。

## 四、方案对比与推荐

| 维度 | A 青屿 | B 睿蓝 | C 暖杏 | D 晨紫 |
|------|--------|--------|--------|--------|
| 行业契合（心理/平静） | ★★★★★ | ★★★★ | ★★★★ | ★★★★ |
| 品牌差异化 | ★★★★ | ★★（蓝泛滥） | ★★★★★ | ★★★★★ |
| 迁移成本（家长端） | 中（全量色值） | **低**（仅 6 处主色） | 中高（含圆角/语义分离） | 中（全量色值） |
| 迁移成本（老师端） | 中（内联色收敛量大） | 低 | 中（预警语义检查） | 中低（登录/大屏已带紫基因） |
| 大屏表现力 | 好 | 中 | 好 | **最佳** |
| 家庭温度感 | 中高 | 低 | **最高** | 中 |
| 风险点 | 无 | 无（最稳） | 橙=警告语义冲突需专项处理 | 紫色长时间注视疲劳（老师工作台需白底为主） |

**推荐顺序：A（青屿）> D（晨紫）> B（睿蓝）> C（暖杏）**

- **首选 A 青屿**：心理健康场景色彩心理学最优解，家长端温暖、老师端专业，青绿系兼具平静感与差异化；
- **B 睿蓝**为最低成本备选（若优先保进度、降风险）；
- 最终选定后，三端共享同一 token 表（学生端色板保留儿童向映射，仅品牌图形统一）。
