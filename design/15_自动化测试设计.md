## 二、执行架构（承接 his/82 §二）

- **工具链**：chrome-devtools MCP（CDP Input）+ Browser Agent 提示词；语音类三层自动化（L0 服务级 API / L1 本地真链路 / L2 降级路径）

## 六、管理端 SPEC（AC-15-xx，EARS）

| ID | 需求（EARS） | 验收 |
|----|-------------|------|
| AC-15-01 | WHEN 任一平台角色登录 /admin WHEN 角色无视图权限 THEN 显示 ForbiddenPage AND 后端返回 403 | 四角色矩阵全过 |
| AC-15-02 | WHEN super_admin 访问平台总览 THEN 渲染学校/学生/教师/会话 KPI AND 与 /overview API 一致 | 数据一致性断言 |
| AC-15-03 | WHEN 修改系统配置项 THEN 写入 sys_config_history AND SECRET 类型掩码显示 | 留痕含操作人 |
| AC-15-04 | WHEN 提示词版本 submit→review→activate THEN 状态机按 draft→pending_review→approved→active 流转 | 全流程可执行 |
| AC-15-05 | WHEN 预警逾期 THEN 进入 overdue 列表 AND 可转派 AND 写 sla_escalation_log | 台账可查 |
| AC-15-06 | WHEN 批量导入学生 CSV THEN 学生批量创建成功 AND 审计 IMPORT_STUDENTS 落库 AND 失败行不部分提交 | 原子性 |
| AC-15-07 | WHEN 邀请码停用 THEN 该码注册被拒 AND 使用情况计数冻结 | 生命周期闭环 |
| AC-15-08 | WHEN 降级事件发生（auto/manual）THEN DegradationPage 时间线可见 | 矩阵一致 |
| AC-15-09 | WHEN 查看用量报表 THEN 与 usage_events 聚合一致 AND 支持时间过滤 | 报表正确 |
| AC-15-10 | WHEN 合规视图导出 THEN 输出审计全景 AND 导出审批冻结提示可见 | 合规完整 |
| AC-15-11 | WHEN 租户 suspend THEN 该租户隔离（登录/数据不可达）AND resume 后恢复 | 生命周期 |
| AC-15-12 | WHEN admin 登录 teacher-web THEN 落地大屏 AND 管理控制台菜单可用 | 角色裁剪 |
