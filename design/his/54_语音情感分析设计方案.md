## 1. 背景与目标

### 1.1 为什么需要语音情感分析

| 维度 | 纯文本分析（M1 现状） | 语音情感分析（M2 目标） |
|------|---------------------|----------------------|
| 信息量 | 仅语义内容 | 语义 + 韵律 + 音调 + 语速 + 停顿 |
| 低龄适配 | 依赖打字能力 | 自然说话即可 |
| 风险信号 | 关键词匹配 | 可检测"语气异常"（如平淡叙述自伤） |
| 误判率 | 反讽/玩笑易误判 | 结合语气可降低误判 |

**核心目标**：在学生语音输入时，同步提取情感特征，作为风险识别的**辅助信号源**（非独立判断依据），提升预警准确率。

### 1.2 功能边界

**做：**
- 语音情绪分类（9 类 → 映射为 4 级风险辅助信号）
- 情绪异常检测（连续多轮消极情绪 → 升级预警）
- 情绪趋势追踪（会话内情绪曲线）

**不做（M3+）：**
- 实时语音对话（WebSocket + TTS）
- 声纹识别/说话人验证
- 方言情绪识别（M2 仅覆盖普通话）

## 2. 技术选型

### 2.1 候选方案对比

| 方案 | 模型 | 优势 | 劣势 | 推荐度 |
|------|------|------|------|--------|
| **A. SenseVoice 一体化** | 阿里 FunAudioLLM SenseVoiceSmall | ASR+SER+LID+AEC 四合一；一次推理；中文优化 | 模型较新，社区验证少；情感粒度有限 | ⭐⭐⭐⭐ |
| **B. emotion2vec+ 专用** | 阿里达摩院 emotion2vec_plus_large | 9 类情绪，准确率 91%+；FunASR 生态；可单独部署 | 需额外 ASR 管线；模型体积较大（~1.2GB） | ⭐⭐⭐⭐⭐ |
| **C. Whisper + 分类头** | OpenAI Whisper + 线性分类器 | 学术验证充分；多语言 | 需自行训练分类头；中文情绪数据少 | ⭐⭐⭐ |
| **D. 云 API** | Azure/阿里云语音情绪分析 | 零运维；即开即用 | 儿童数据上云合规风险高；按量计费贵 | ⭐⭐ |

### 2.2 推荐方案：B（emotion2vec+）+ FunASR 管线

**理由：**
1. emotion2vec+ 是目前开源 SER 领域 SOTA（ACL 2024），9 类情绪识别准确率 91%+
2. FunASR 生态完整：VAD → ASR（Paraformer）→ 标点 → emotion2vec，一行代码串联
3. 本地部署，儿童语音数据不出校/不出服务器，满足合规
4. 支持 GPU/CPU 推理，Small 版本可 CPU 实时

### 2.3 emotion2vec+ 情绪类别

| 编号 | 情绪 | 英文 | 映射到系统风险辅助 |
|------|------|------|------------------|
| 0 | 愤怒 | angry | 黄色（+1） |
| 1 | 厌恶 | disgusted | 黄色（+1） |
| 2 | 恐惧 | fearful | 橙色（+2） |
| 3 | 开心 | happy | 绿色（0） |
| 4 | 中性 | neutral | 绿色（0） |
| 5 | 其他 | other | 忽略 |
| 6 | 悲伤 | sad | 橙色（+2） |
| 7 | 惊讶 | surprised | 忽略 |
| 8 | 未知 | unknown | 忽略 |

## 3. 系统架构

### 3.1 数据流

```
[学生端 H5]
    │
    │ 1. 录音（MediaRecorder API → webm/opus）
    │ 2. 上传音频文件（multipart/form-data）
    ▼
[后端 API: /api/v1/chat/sessions/{id}/voice-messages]
    │
    ├──► ASR 服务（FunASR Paraformer）→ 文字 → 进入现有对话流
    │
    └──► SER 服务（emotion2vec+）→ 情绪标签 + 置信度
              │
              ▼
        [风险辅助判断]
              │
              ├── 情绪信号 + 文本关键词 → 综合风险等级
              └── 情绪趋势追踪（连续 N 轮 sad/fearful → 升级）
```

### 3.2 部署架构

```
┌─────────────────────────────────────────┐
│           Docker Compose (M2)            │
├─────────────────────────────────────────┤
│  mindsafe-app (8080)                    │
│  mindsafe-pg (5432)                     │
│  mindsafe-redis (6379)                  │
│  mindsafe-funasr (10095)  ← 新增       │
│    ├── Paraformer-large (ASR)           │
│    ├── emotion2vec_plus_large (SER)     │
│    └── FSMN-VAD + CT-Transformer       │
└─────────────────────────────────────────┘
```

FunASR 提供 Docker 镜像 + WebSocket/gRPC 服务，支持多并发。

### 3.3 后端集成点

```java

```

## 4. 前端改造

### 4.1 录音方案

```javascript
// MediaRecorder API（替代 Web Speech API，保留原始音频）
const stream = await navigator.mediaDevices.getUserMedia({ audio: true })
const recorder = new MediaRecorder(stream, { mimeType: 'audio/webm;codecs=opus' })
// 录音结束 → Blob → 上传后端
```

**为什么不用 Web Speech API？**
- Web Speech API 仅返回文字，无法获取原始音频
- emotion2vec 需要原始音频波形进行情感分析
- M1 的 Web Speech API 保留为降级方案（浏览器不支持 MediaRecorder 时）

### 4.2 交互变化

- 按住麦克风录音 → 松开结束 → 显示"分析中..." → 文字填入输入框 + 情绪标签展示
- 可选：情绪气泡（😊😢😠）显示在消息旁，让学生感知"被理解"

## 5. 风险识别增强逻辑

### 5.1 多信号融合（M2 核心升级）

```
最终风险等级 = max(文本关键词等级, 语音情绪等级, 趋势升级等级)
```

| 信号源 | 权重 | 说明 |
|--------|------|------|
| 文本关键词（M1 已有） | 主信号 | "想死""不想活" → RED |
| 语音情绪（M2 新增） | 辅助信号 | sad/fearful 连续 3 轮 → ORANGE |
| 情绪趋势（M2 新增） | 升级信号 | 会话内情绪持续下降 → +1 级 |

### 5.2 情绪趋势追踪

```java
// 会话级情绪队列（最近 5 轮）
Queue<VoiceEmotionResult> emotionWindow;

// 规则：连续 3 轮 sad/fearful 且置信度 > 0.7 → 触发 ORANGE 预警
// 规则：连续 5 轮消极 → 触发 RED 预警（即使文本无关键词）
```

## 6. 合规与隐私（关键约束）

### 6.1 法律要求

| 法规 | 核心要求 |
|------|---------|
| 《个人信息保护法》 | 不满 14 周岁未成年人信息 = 敏感个人信息，需监护人单独同意 |
| 《未成年人网络保护条例》(2024.1) | 年度合规审计 + 报送；最小必要原则 |
| 《数据安全法》 | 数据分级分类；重要数据不出境 |

### 6.2 技术合规措施

| 措施 | 实现方式 |
|------|---------|
| **音频不落盘** | 推理完成后立即删除原始音频，仅保留情绪标签（枚举值） |
| **本地部署** | FunASR + emotion2vec 部署在学校本地/私有云，数据不出校 |
| **监护人授权** | 首次使用语音功能前，需监护人签署电子知情同意书 |
| **最小必要** | 仅提取情绪分类结果（9 选 1），不存储声纹/原始特征 |
| **可选退出** | 学生/监护人可随时关闭语音功能，回退纯文字模式 |

### 6.3 数据存储策略

```
存储：emotion_label (enum) + confidence (float) + detected_at (timestamp)
不存储：原始音频文件、MFCC 特征向量、声纹 embedding
保留期：跟随会话记录，会话删除时一并清除
```

## 9. 风险与缓解

| 风险 | 影响 | 缓解 |
|------|------|------|
| 儿童语音识别准确率低 | ASR 文字错误 → 对话质量下降 | 保留文字编辑修正步骤；FunASR 对儿童语音持续优化 |
| 情绪识别在儿童语音上表现未知 | 模型主要用成人数据训练 | 用 ChildMandarin 数据集做 fine-tune 验证 |
| 环境噪声（教室/操场） | 情绪误判 | VAD 前端降噪 + 置信度阈值（< 0.6 忽略） |
| 合规审查不通过 | 功能无法上线 | 提前与学校法务沟通；音频不落盘为底线 |
| GPU 资源不足 | 推理延迟高 | emotion2vec_base（CPU 可实时）为降级方案 |
