# 29 - 学生画像与年龄适配设计

> 创建：2026-07-27 | 状态：设计完成，待实施
> 
> 定位：**核心竞争力专题**——让 AI 真正"看见"面前这个孩子，按年龄/性格/特征说不同的话。
> ⚠️ **实现现状（2026-07-28 核对）**：头部"待实施"与 §1.2 五个断裂点诊断**均已过时**——三层方案已全部落地 🟩：年级接通（`effectiveGrade`）、语言模板真实调用、动态降级（含风险不降级）、`personality_traits` 提炼与合并。四态对照与剩余缺口见 §十。

## 一、现状诊断

### 1.1 已实现（可用）

| 模块 | 类/文件 | 能力 |
|------|---------|------|
| 画像实体 | `StudentProfile`（6 维 JSONB） | 情绪基线 / 风险轨迹 / 沟通偏好 / 韧性 / 社交图谱 / 成长轨迹 |
| P0 SQL 聚合 | `StudentProfileService.updateProfile()` | 会话结束后聚合近 20 次情绪分布 + 30 天风险趋势 |
| 画像 Prompt 注入 | `StudentProfileService.buildProfilePrompt()` | 对话开始时追加到 System Prompt |
| LLM 增量提炼 | `ProfileExtractorService.extractAndMerge()` | 沟通偏好 / 韧性 / 社交图谱三维跨会话合并 |
| 性别风格 | `AiChatServiceImpl.buildGenderStyle()` | 男/女/通用三种沟通风格片段 |
| 年级语言模板 | `prompts/language/child_language_grade_*` × 3 | 1-2 / 3-4 / 5-6 年级语言规则文件 |
| 年级路由方法 | `PromptTemplateService.languageTemplateForGrade(int)` | 按年级段返回模板路径 |
| 冷场画像关联 | `getExpressionDepth()` → 决策模型信号 F | 话多偏留白、沉默偏暖场 |

### 1.2 关键断裂点（严重）

| # | 问题 | 位置 | 影响 |
|---|------|------|------|
| 1 | `grade_level` **硬编码 `"5-6"`** | `AiChatServiceImpl` L62, L117 | 所有学生被当作 5-6 年级 |
| 2 | 语言模板**从未被调用** | `languageTemplateForGrade()` 零引用 | 低年级 50 字限制/身体比喻/选择题全部失效 |
| 3 | `User.gradeCode` **未传入 AI 层** | `ConversationServiceImpl.createSession()` 只取 gender | 即使模板接上也没数据源 |
| 4 | 画像 Prompt **无年龄/性格维度** | `buildProfilePrompt()` 只有情绪/风险/偏好/技巧 | AI 不知道面前是几岁的孩子 |
| 5 | **无性格特征建模** | 仅 `expression_depth`，无内向/外向/高敏感 | 无法做性格适配 |

**结论**：基础设施已搭好（模板文件 + 路由方法 + 画像表），但**接线全断**——数据没传、模板没调、硬编码覆盖了所有学生。

---

## 二、设计目标

1. **年龄适配**：6 岁和 12 岁的孩子收到完全不同的语言——句长、比喻库、CBT 深度、互动模式
2. **性格感知**：内向/外向/高敏感/低表达 → 调整互动节奏和引导策略
3. **画像驱动 Prompt**：每次对话 System Prompt 中包含完整的"这个孩子是谁"上下文
4. **动态降级**：10 岁但表达深度只有 0.2 → 自动使用更低年级的语言模式
5. **零额外 LLM 调用**：年龄/年级适配不增加推理成本（纯模板路由 + 字符串拼接）

### 第一层：接通年级（最小改动，立竿见影）

**目标**：不同年级的孩子马上看到不同的说话方式。

#### 3.6 性格特征建模（LLM 提炼扩展）

在 `PROFILE_EXTRACTOR_SYSTEM_PROMPT` 中新增 `personality_traits` 维度：

```json
{
  "personality_traits": {
    "introversion": 0.0到1.0,
    "sensitivity": 0.0到1.0,
    "curiosity": 0.0到1.0,
    "dominant_interests": ["动物", "画画", "游戏"]
  }
}
```

字段说明：
- `introversion`：内向程度。主动分享少/需反复邀请才开口→偏高；自来熟/主动找话题→偏低
- `sensitivity`：情绪敏感度。小事引发强烈反应/容易哭→偏高；情绪平稳/不易被触动→偏低
- `curiosity`：好奇心/探索欲。爱问为什么/对新事物感兴趣→偏高；回避新事物/只聊固定话题→偏低
- `dominant_interests`：高频兴趣话题（泛化标签，用于暖场和比喻取材）

#### 3.7 StudentProfile 表扩展

```sql
-- V18 迁移（在现有 JSONB 字段 personality_traits 中存储，无需加列）
-- 复用 communication_pref 字段扩展，或新增 personality_traits JSONB 列
ALTER TABLE tenant_template.student_profiles 
  ADD COLUMN IF NOT EXISTS personality_traits JSONB DEFAULT '{}';
```

#### 3.8 性格 → Prompt 策略映射

| 特征 | 高值策略 | 低值策略 |
|------|----------|----------|
| introversion ≥ 0.7 | 不追问、给选择题、允许沉默、"不想说也没关系" | 可以开放提问、邀请展开 |
| sensitivity ≥ 0.7 | 语气更轻柔、避免直接指出问题、先稳定再探索 | 可以适度挑战、直接反馈 |
| curiosity ≥ 0.7 | 用探索/实验比喻、"我们来当小侦探" | 用安全/稳定比喻、"我们找个舒服的办法" |
| dominant_interests | 暖场/比喻取材（"像画一幅画一样…"） | — |

### 第三层：年龄分层话术体系（竞争力壁垒）

#### 3.9 语言模板升级（从字数限制 → 认知适配全维度）

**1-2 年级（6-8 岁）—— 感知运动期尾 / 前运算期**

```markdown
# 语言规则（1-2 年级，6-8 岁）

## 认知水平
- 具象思维为主，不理解"想法影响情绪"等抽象概念
- 时间感弱（"上周"≈"很久以前"），只谈"现在"和"今天"
- 因果推理简单线性

## 语言约束
- 每句话 10-15 个字，最多 2-3 句
- 回复总长度不超过 50 字
- 不说"想法""认知""情绪管理""压力"等抽象词

## 比喻库
- 身体感受："心里堵堵的""像有小石头压着""肚子里有蝴蝶在飞"
- 颜色/天气："心情像晴天还是阴天？""如果给心情选个颜色呢？"
- 动物："像小兔子一样缩在洞里""像小刺猬竖起了刺"

## 互动模式
- 提问用选择题："你现在更像难过，还是更像生气？"
- 可以用感受卡片/颜色选择
- 每次只问一个问题，等小朋友回答
- CBT 不出现，改为"说出感受 → 一个小行动"

## 禁止
- 不说"你应该""你必须""你要学会"
- 不引入"证据""想法是不是真的"等认知检验
- 不用反问句
```

**3-4 年级（8-10 岁）—— 具体运算期**

```markdown
# 语言规则（3-4 年级，8-10 岁）

## 认知水平
- 可以分类、排序、理解简单因果
- 能理解"同一件事可以有不同的感受"
- 开始有"别人怎么看我"的意识

## 语言约束
- 每句话 15-25 个字，最多 3-4 句
- 回复总长度不超过 80 字
- 可以用简单情绪词："紧张/委屈/担心/害怕/孤单/生气"

## 比喻库
- "脑袋里的小声音""想法泡泡""情绪温度计"
- "像背了一个重重的书包""心里的结"
- "如果情绪是天气，现在是什么天？"

## 互动模式
- 一个开放问题 + 一个小行动
- 可以引入"温度计打分"："0-10 分，你现在有几分难过？"
- CBT 简化版：情境 → 感受 → "那时候脑袋里的小声音说了什么？"
- 可以给 2 个选项让孩子挑

## 禁止
- 不说"认知偏差""灾难化思维""自我效能"
- 不说教、不命令、不责备
- 不做超过 2 步的推理链
```

**5-6 年级（10-12 岁）—— 形式运算期过渡**

```markdown
# 语言规则（5-6 年级，10-12 岁）

## 认知水平
- 可以假设推理、理解"想法≠事实"
- 有自我评价意识，在意公平/尊重
- 能理解多因素因果

## 语言约束
- 默认回复不超过 80 字
- 安全场景可超 80 字，但必须清楚、稳定、可执行
- 可以引入简单心理模型但须立即解释

## 比喻库
- "自动想法就是脑袋里自动冒出来的那句话"
- "像戴了一副有色眼镜看事情"
- "如果好朋友遇到同样的事，你会对他说什么？"

## 互动模式
- 可以引入认知三角："想法 → 感受 → 行为，它们互相影响"
- 邀请验证想法："有没有什么证据说明这件事不一定是那样？"
- 可以用"平衡想法"替代"自动想法"
- 尊重自主性："你觉得哪个办法更适合你？"

## 禁止
- 仍然不说教、不命令、不贴标签
- 不用"你应该""你想太多了"
- 不做诊断性表述
```

#### 3.10 性别 × 年龄交叉策略

| | 低年级（1-2） | 中年级（3-4） | 高年级（5-6） |
|---|---|---|---|
| **男生** | 动物/超级英雄比喻、"小勇士"、行动先于感受 | 运动/游戏比喻、"想个战术"、简短有力 | "像解谜一样"、证据检验、给选择权 |
| **女生** | 颜色/花朵/小动物比喻、温柔命名感受 | 故事/日记比喻、"跟好朋友聊天"、情感反射 | "你比你想的更有力量"、自我关怀、平等讨论 |
| **通用** | 身体感受、天气、颜色 | 温度计、小声音、泡泡 | 眼镜、天平、侦探 |

#### 3.11 动态降级机制

```java
// 在 AiChatServiceImpl 中：
int effectiveGrade = grade;
if (expressionDepth != null && expressionDepth < 0.3 && grade > 2) {
    // 表达深度极低 → 降一个年级段（不是降年级，是降语言复杂度）
    effectiveGrade = Math.max(1, grade - 2);
}
String langTemplate = PromptTemplateService.languageTemplateForGrade(effectiveGrade);
```

规则：
- `expression_depth < 0.3` 且 `grade > 2`：降 2 个年级（如 5→3）
- `expression_depth < 0.15`（极端沉默）：直接使用 1-2 年级模板
- 风险场景（橙/红）：**不降级**，保持实际年级（安全话术需要认知匹配）

## 六、隐私与安全红线

1. **严禁向学生复述画像内容**（现有规则保持）
2. **性格标签仅用于调整 AI 策略**，不展示给学生/家长
3. **dominant_interests 只存泛化标签**（"动物""画画"），不存具体内容
4. **年龄/年级不用于歧视性差异化**，仅用于语言复杂度适配
5. **LLM 提炼无法判断时输出空对象**，不臆造性格标签
