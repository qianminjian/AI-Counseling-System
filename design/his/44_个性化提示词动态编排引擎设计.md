# 44 - 个性化提示词动态编排引擎设计（年龄 × 画像 × 心情 × 合规）

> 创建：2026-07-28 | 状态：🟡 大部分已实施（P0/P1 核心已落地，见文末落地记录；P2 性格层深化与 P3 A/B 量化余量仍在）| 2026-07-28 冻结区审计校正
>
> 定位：**提示词工程核心竞争力专题**——把"进入心情状态"补成一等公民，并把年龄(29)×画像(29)×心情(本文)×合规(04/14)从"静态字符串拼接"升级为"**先算策略、再拼提示词**"的动态编排引擎。
>
> 关系：本文是 design/29（年龄/性格适配）的**上位统筹**，是 design/28（冷场）的**情绪侧扩展**，实施效果由 design/39（A/B）量化，安全优先级受 design/04+14 约束。

## 一、现状诊断

### 1.1 三条个性化数据流现状（对照真实代码）

| 维度 | 数据源 | 注入方式 | 现状 | 位置 |
|------|--------|----------|------|------|
| **年龄/年级** | `grade`（真实年级） | `languageTemplateForGrade()` → `LANG_001/002/003` + `buildGenderStyle(gender,grade)` | ✅ 已接通，认知/比喻/互动分层 | `AiChatServiceImpl` L63-77 |
| **心理画像** | `StudentProfile`(6 维 JSONB) | `buildProfilePrompt()` 追加到 System | ⚠️ 框架在，缺年龄/性格维度注入（design/29 待实施） | L80-82 |
| **进入心情状态** | `emotionTag`（学生开场选的情绪） | 仅作为 `{{emotion_tag}}` 填入 SYS-001 | ❌ **只占位、不驱动任何策略** | L64-69 |

### 1.2 根因：缺少"编排层"

当前 System Prompt 是**顺序静态拼接**（[AiChatServiceImpl.chat L64-82](file:///Users/minjianq/Documents/66-Project/Qoder/AI-Counseling-System-dev/backend/counseling-ai/src/main/java/com/mindsafe/ai/chat/AiChatServiceImpl.java#L64-L82)）：

```
SYS-001（emotion_tag 只是填空）
  + 语言模板（只看 grade）
  + 性别风格（只看 gender+grade）
  + 画像（不含年龄/性格/情绪）
```

四个维度**互不知晓、无优先级、无冲突裁决、会话内不随情绪变化**。结果：

- 一个**焦虑**进入的孩子和一个**开心**进入的孩子，AI 的开场白、节奏、要不要立刻做 CBT——**完全一样**。
- 情绪只影响了 SYS-001 里一句"当前情绪：焦虑"的陈述，指望 LLM 自己"看着办"，无稳定策略约束。

### 1.3 最大缺口清单（本文要解决的）

| # | 缺口 | 严重度 | 本文对应章节 |
|---|------|--------|------------|
| G1 | 进入心情状态不驱动开场与回应策略 | 🔴 最高 | 五 |
| G2 | 无编排层，四维静态拼接不联动、无优先级 | 🔴 高 | 四 |
| G3 | 会话内情绪漂移无检测、无策略切换（一次定终身） | 🟠 中高 | 七 |
| G4 | 情绪 × 年龄 × 性格未交叉（同一情绪对 7 岁和 12 岁话术应不同） | 🟠 中 | 五、六 |
| G5 | 情绪稳定与 CBT 时机无门控（对情绪淹没的孩子硬做认知重构） | 🟠 中 | 5.4 |

## 二、设计目标

1. **心情驱动**：进入心情状态决定开场方式、对话节奏、优先技能（PFA/SEL/CBT）与禁止动作。
2. **四维联动**：年龄 × 画像 × 心情 × 合规经**一个编排引擎**计算出统一策略，再拼提示词。
3. **动态变化**：会话内每轮识别当前情绪，情绪升级/缓解→策略实时切换，危机→切风险管线。
4. **优先级裁决**：合规安全 > 情绪稳定 > 年龄适配 > 性格适配 > 画像个性化 > 兴趣取材。
5. **专业可辩护**：每条策略可回溯到公认心理学理论/工具（见第三章），非拍脑袋。
6. **零/低额外推理成本**：编排为纯规则计算 + 字符串拼装；情绪识别复用已有 Emotion 信号，不新增串行 LLM 调用。

**明确不做**（对齐 design/14）：不诊断、不贴心理标签、不因情绪做诱导性追问、不向学生复述画像、不用情绪数据做营销。

## 三、心理专业理论与业界最佳实践对标

### 3.1 理论工具箱（策略的专业依据）

| 理论/工具 | 核心主张 | 在本文的落地 |
|-----------|----------|------------|
| **皮亚杰认知发展阶段** | 前运算(6-8)/具体运算(8-10)/形式运算过渡(10-12)决定抽象能力 | 年龄语言分层（沿用 design/29 §3.9） |
| **情绪容纳之窗 Window of Tolerance**（Siegel） | 过度激活/低唤醒时理性脑离线，认知干预无效 | **情绪门控 CBT**（5.4）：先回到窗口内再做认知工作 |
| **心理急救 PFA / Look-Listen-Link**（WHO） | 危机首要是**稳定与安全**，不是解决问题 | 焦虑/害怕/危机情绪→先稳定策略（5.2） |
| **情绪 ABC 理论**（Ellis, REBT） | 诱发事件→信念→情绪后果 | 高年级 CBT 的认知检验话术（LANG_003） |
| **命名即驯服 Affect Labeling**（Lieberman） | 说出情绪能降低杏仁核激活 | 各情绪先做"情绪镜映"命名（5.3） |
| **动机式访谈 MI / Rolling with Resistance** | 抗拒不硬推，顺势而为、给自主权 | 抗拒/沉默→留白+选择权（5.2） |
| **SEL 社会情感学习**（CASEL 五能力） | 自我觉察/自我管理/社交觉察/关系/负责决策 | 平静/开心→SEL 巩固扩展（5.2） |
| **依恋理论 / 安全基地** | 先建立安全感，探索才可能发生 | 害怕/新用户→安全感优先话术 |
| **儿童情绪粒度**（Feelings Wheel 简化） | 低龄需具象、身体化的情绪词 | 情绪镜映话术按年龄取材（5.3） |

### 3.2 业界产品范式对标

| 产品 | 可借鉴做法 | 本文采纳 |
|------|-----------|---------|
| **Woebot** | 每次会话以 mood check-in 开场，规则化安全兜底优先于 LLM 自由发挥 | 进入心情=编排输入；合规硬规则优先级最高 |
| **Wysa** | 情绪分级触发不同工具（SOS/接地/正念），"先工具后对话" | 焦虑/害怕优先推接地/呼吸（衔接 design/36 工具箱） |
| **SAMHSA/MBC 测量导向照护** | 用可观察信号驱动干预调整 | 情绪状态机 + 漂移检测（7）驱动策略切换 |
| **儿童向对话式 AI 通则** | 短句、单焦点、可预期、不追问隐私 | 编排对低龄强制单焦点、限字数 |

### 3.3 一句话对标结论

业界共识是"**check-in → 按状态裁剪策略 → 安全规则硬兜底**"。本系统已有 check-in（`emotionTag`）和安全兜底（双层过滤），**唯独缺中间的"按状态裁剪策略"这一层**——这正是本文补齐的编排引擎。

## 四、动态编排引擎架构

### 4.1 从"静态拼接"到"先算策略、再拼提示词"

新增一个**编排服务**（设计期命名 `PromptOrchestrationService`，落在 counseling-ai 或 counseling-service prompt 包）：输入上下文信号 → 输出结构化 `StrategyProfile` → 再由现有拼装逻辑渲染为 System Prompt 片段。

### 4.2 编排流水线

```
输入信号（每轮对话）
  ├── grade（真实年级）
  ├── entryMood（进入心情，会话级）
  ├── currentEmotion（本轮 Emotion Agent 识别，轮级）
  ├── riskLevel（RiskDetector 输出：绿/黄/橙/红）
  ├── StudentProfile（情绪基线/性格/表达深度/兴趣/风险轨迹）
  └── coldStartSignal（design/28 冷场信号，可选）
        │
        ▼
┌─────────────────────────────────────────────┐
│ PromptOrchestrationService.resolve()         │
│  1. 合规裁决：riskLevel 橙/红 → 直接锁定安全策略，短路返回 │
│  2. 情绪门控：由 currentEmotion → EmotionState（稳定/激活/危机）│
│  3. 语言层：effectiveGrade（含 design/29 动态降级）→ LANG_00x │
│  4. 情绪策略：EntryMoodStrategyResolver → 开场/节奏/技能/禁忌 │
│  5. 性格层：introversion/sensitivity/curiosity → 策略微调 │
│  6. 画像层：兴趣取材 + 基础属性 + 已掌握技巧 │
│  7. 优先级裁决合并冲突（4.4）│
└─────────────────────────────────────────────┘
        │
        ▼
  StrategyProfile（结构化策略）
        │
        ▼
  Prompt 渲染（在现有 fullSystem 拼装点插入"情绪策略层"）
```

### 4.3 StrategyProfile 数据结构（设计期）

```java
record StrategyProfile(
    int effectiveGrade,          // 含动态降级后的语言年级
    EmotionState emotionState,   // STABLE / ACTIVATED / CRISIS
    String entryMood,            // 进入心情原始标签
    OpeningStrategy opening,     // 开场：稳定优先/接住情绪/正常推进/留白低压
    Pace pace,                   // 节奏：slow / normal
    SkillPriority skillPriority, // PFA > SEL > CBT 的本轮排序
    List<String> forbiddenActions, // 本状态禁止动作（如"禁止立刻做认知重构"）
    String emotionMirrorHint,    // 情绪镜映话术取材（按年龄+情绪）
    boolean allowCbt,            // 情绪门控：是否允许进入 CBT
    boolean degraded,            // 是否触发语言降级
    boolean safetyLocked         // 是否被合规裁决锁定（橙/红）
) {}
```

`StrategyProfile` **不直接给学生看**，仅渲染为 System 层策略片段（隐私红线见第八章）。

### 4.4 优先级裁决（冲突解决铁律）

```
合规安全（04/14 红橙）      ← 最高，可短路一切个性化
  > 情绪稳定（容纳之窗）      ← 情绪淹没时压制 CBT/追问
    > 年龄适配（认知匹配）    ← 语言复杂度不可超龄
      > 性格适配（内向/高敏） ← 微调节奏与追问强度
        > 画像个性化          ← 偏好风格/已掌握技巧
          > 兴趣取材          ← 最低，仅供比喻/暖场取材
```

冲突示例：高敏感孩子(倾向温柔慢)遇到**橙色风险**→ 安全策略优先，切稳定+静默升级，性格层让位。

## 五、进入心情状态驱动策略（核心补缺 G1）

### 5.1 情绪分类与来源

- **来源①（会话级）**：`entryMood` = 学生进入时选的表情（学生端 5 情绪，映射到下表规范集）。
- **来源②（轮级）**：`currentEmotion` = Emotion Agent 每轮识别，用于动态切换（第七章）。
- **规范情绪集**：`calm 平静` / `happy 开心` / `anxious 焦虑` / `sad 低落` / `angry 生气委屈` / `fearful 害怕` / `withdrawn 抗拒沉默` / `crisis 绝望麻木`（危机态，交由风险管线）。

### 5.2 情绪 → 开场与回应策略映射表（重点）

| 进入心情 | 理论依据 | 开场策略 | 节奏 | 优先技能 | 禁止动作 |
|----------|----------|----------|------|----------|----------|
| **平静 calm** | SEL 巩固 | 轻松寒暄，可承接上次话题 | normal | SEL＞CBT | 无特殊 |
| **开心 happy** | 正向扩展/SEL | 一起分享开心，放大积极体验 | normal | SEL（放大资源） | 不强行找问题、不扫兴 |
| **焦虑 anxious** | PFA + 容纳之窗 | **先稳定**：命名+接地/呼吸，再问发生了什么 | slow | PFA(接地)＞CBT | 不立刻追问细节、不做认知重构、不堆信息 |
| **低落 sad** | Affect labeling + 陪伴 | **先接住**：共情命名，允许难过，不急于给方案 | slow | 倾听共情＞CBT | 不说"别难过"、不急于解决、不讲道理 |
| **生气/委屈 angry** | 情绪宣泄 + 不评判 | **先允许**：认可情绪合理，给宣泄出口 | slow | 倾听＞SEL | 不说教、不评判对错、不站队 |
| **害怕 fearful** | 依恋/安全基地 | **安全感优先**："这里很安全，波波陪着你" | slow | PFA(安全感)＞CBT | 不追问恐惧源、不放大威胁 |
| **抗拒/沉默 withdrawn** | MI 顺势而为 | **给留白**：低压力、选择题、"不想说也没关系" | slow | 陪伴＞留白 | 不追问、不劝说、不连续提问 |
| **危机 crisis** | C-SSRS/PFA | 交由**橙/红风险管线**：稳定话术+静默升级 | — | 危机处置 | **禁止 CBT/探索/深挖**（design/14） |

### 5.3 情绪镜映话术库（情绪 × 年龄取材）

命名即驯服——先反射情绪，取材随年龄具象度调整（沿用 design/29 比喻库）：

| 情绪 | 低年级(1-2) | 中年级(3-4) | 高年级(5-6) |
|------|------------|------------|------------|
| 焦虑 | "心里是不是像有小鹿在乱撞呀？" | "听起来心里有点七上八下的" | "有点紧张、放不下心，对吗？" |
| 低落 | "你现在是不是像下雨的小天空？" | "心里像背了个重重的书包" | "感觉有点提不起劲、有点闷" |
| 生气 | "你是不是像小火山有点想喷发？" | "这件事让你很不服气对吧" | "被这样对待，生气很正常" |
| 害怕 | "有点怕怕的？波波牵着你的手" | "有点担心会发生不好的事？" | "这种不确定让你没有安全感" |

### 5.4 情绪门控 CBT（容纳之窗）

- `EmotionState = ACTIVATED`（焦虑/生气/害怕高唤醒）或 `sad` 深度低落 → `allowCbt=false`：**先做情绪调节（PFA/接地/呼吸/命名），回到窗口内再考虑 CBT**。
- `EmotionState = STABLE` 且非风险 → `allowCbt=true`：可按年龄推进 CBT（低年级只到"感受+小行动"，高年级可到认知三角）。
- `EmotionState = CRISIS` → 一律不做 CBT，交安全管线。
- 门控落地：在 System 策略片段中明确写入"本轮是否可进入认知工作"，替代当前"全靠 LLM 自己判断"。

## 六、四维交叉编排推演（示例场景）

> 验证编排引擎在真实组合下产出合理策略。

**场景 A：8 岁 / 女 / 高敏感(0.8) / 进入=低落 / 绿色**
→ effectiveGrade=3；EmotionState=ACTIVATED(偏低落)；opening=先接住；pace=slow；skill=倾听＞CBT；allowCbt=false；镜映="心里像背了重重的书包"；性格层追加"语气更轻柔、避免直接指出问题"。

**场景 B：11 岁 / 男 / 低表达深度(0.2) / 进入=抗拒沉默 / 绿色**
→ 触发 design/29 动态降级 effectiveGrade=9→用 LANG_002；opening=留白低压；pace=slow；skill=陪伴＞留白；forbidden=连续提问；给选择题+"不想说也没关系"（MI）。

**场景 C：10 岁 / 女 / 进入=低落 / 本轮识别出"想消失" → 橙色**
→ 合规裁决短路：safetyLocked=true；切稳定话术 + 静默通知老师；allowCbt=false；年龄/性格/画像层全部让位；**不降级**（安全话术需认知匹配，design/29 §3.11）。

## 七、动态变化机制（会话内 G3）

### 7.1 情绪状态机

```
        情绪缓解/命名生效
   ┌──────────────────────┐
   ▼                      │
STABLE ──高唤醒/负性加深──► ACTIVATED ──风险信号──► CRISIS
   ▲                      │                          │
   └──────────────────────┘        （风险管线接管，不自动回落）
```

- **STABLE**：可推进（含 CBT，按年龄）。
- **ACTIVATED**：情绪优先，压制 CBT/追问，走稳定策略。
- **CRISIS**：交 RiskDetector/Escalation，编排让位（design/04/14）。

### 7.2 漂移检测与切换

- 每轮由 Emotion Agent 输出 `currentEmotion`；编排比较 `entryMood → currentEmotion` 与状态机转移规则。
- **升级**（如 sad→crisis、calm→anxious）：立即切换策略，不等下一会话。
- **缓解**（如 anxious→calm 持续 ≥2 轮）：解除情绪门控，`allowCbt` 可转 true。
- 切换以 System 策略片段更新体现（下一轮 fullSystem 重算），对学生表现为"AI 察觉到我情绪变了"。

### 7.3 与冷场(28)/降级(29)协同

| 机制 | 触发 | 与本文关系 |
|------|------|-----------|
| 冷场引导（28） | 静默/长时间无输入 | 冷场是"无情绪信号"场景；编排在冷场时优先取 `withdrawn` 策略 + nudge |
| 动态降级（29） | 表达深度<0.3 | 编排的语言层直接复用 `effectiveGrade` 计算 |
| 情绪门控（本文） | 高唤醒/低落 | 新增，压制 CBT 时机 |

三者统一在 `PromptOrchestrationService` 内计算，避免各自为战。

## 八、合规底线与优先级红线

1. **安全 > 一切个性化**：橙/红风险时编排短路，`safetyLocked` 锁定，情绪/年龄/性格/画像全部让位（design/04 §17、design/14）。
2. **危机情绪不做 CBT/探索**：`crisis`/`ACTIVATED` 深度激活时禁止认知重构与深挖（容纳之窗 + design/14 高风险处置）。
3. **不诊断、不贴标签**：情绪状态仅用于内部策略，绝不对学生说"你有焦虑症/你抑郁了"。
4. **不复述画像**：`StrategyProfile` 只进 System 层，严禁向学生复述性格/情绪判断（沿用 design/29 §六）。
5. **不做诱导性追问**：情绪策略以"接住/稳定"为主，不为采集信息而追问隐私或创伤细节。
6. **降级不适用于安全场景**：风险话术保持实际年级认知匹配（design/29 §3.11）。
7. **情绪数据最小化**：进入心情/状态机仅会话内使用与脱敏留痕，不用于营销或对家长逐条披露。

## 十一、EARS 验收标准

| ID | EARS 验收条款 |
|----|--------------|
| AC-01 | When 学生以"焦虑"进入会话, the 系统 shall 在首条回复采用"先命名情绪+接地/呼吸"开场, 且本轮不追问事件细节。 |
| AC-02 | When `EmotionState=ACTIVATED` 或 `CRISIS`, the 系统 shall 令 `allowCbt=false`, 不进行认知重构。 |
| AC-03 | While riskLevel 为橙/红, the 编排 shall `safetyLocked=true` 短路个性化, 情绪/年龄/性格/画像层全部让位于安全策略。 |
| AC-04 | When 会话内 `currentEmotion` 由 sad 升级为 crisis, the 系统 shall 立即切换到风险管线, 不等待下一会话。 |
| AC-05 | Where 学生为低年级(1-2), the 情绪镜映话术 shall 仅使用身体化/具象比喻, 不出现"焦虑/认知/情绪管理"等抽象词。 |
| AC-06 | While `withdrawn`(抗拒沉默), the 系统 shall 使用选择题/留白, 单轮提问不超过 1 个, 且提供"不想说也没关系"出口。 |
| AC-07 | The 系统 shall 不向学生复述任何 `StrategyProfile` 内的情绪/性格判断。 |
| AC-08 | When anxious 缓解为 calm 且持续 ≥2 轮, the 系统 shall 解除情绪门控允许按年龄推进 CBT。 |
| AC-09 | The 情绪策略层 shall 经 `PromptVersionService` 管理版本, 支持 A/B 与灰度回滚。 |
