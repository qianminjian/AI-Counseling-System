# 19 界面详细设计

> 状态：新建 | 关联：17 前端架构设计、05 老师后台设计、16 API 接口设计、14 儿童安全对话规范
> 核心：为每个页面提供**布局规格、交互流程、组件 Props/State/Event 定义、视觉规范**，开发人员可直接按此实现 UI。
> ⚠️ **实现现状（2026-07-28 核对）**：本篇 TypeScript 组件规格为目标设计（实际 JSX 无类型定义）；学生端主流程/性别个性化(§8)已落地 🟩，教师端**个案管理/预约日历/预警详情页未实现** ⬜，实态为单页面板式工作台；四态对照见 §9。

## 0. 设计系统（Design Tokens）

### 0.1 色彩体系

| Token | 值 | 用途 |
|-------|-----|------|
| `--color-primary` | `#4A90D9` | 主按钮、链接、选中态 |
| `--color-primary-light` | `#E8F1FB` | 卡片背景、hover 态 |
| `--color-success` | `#52C41A` | 成功提示、安全状态 |
| `--color-warning` | `#FAAD14` | 黄色预警（R2） |
| `--color-orange` | `#FA8C16` | 橙色预警（R3） |
| `--color-danger` | `#FF4D4F` | 红色预警（R4）、错误 |
| `--color-bg` | `#F7F8FA` | 页面背景 |
| `--color-surface` | `#FFFFFF` | 卡片/面板背景 |
| `--color-text` | `#262626` | 主文本 |
| `--color-text-secondary` | `#8C8C8C` | 辅助文本 |
| `--color-border` | `#E8E8E8` | 分割线、边框 |

**风险等级色板**（预警队列专用）：

| 等级 | 背景色 | 文字色 | 标签 |
|------|--------|--------|------|
| R4 红 | `#FFF1F0` | `#CF1322` | 紧急 |
| R3 橙 | `#FFF7E6` | `#D46B08` | 高 |
| R2 黄 | `#FFFBE6` | `#D4B106` | 关注 |
| R1 绿 | `#F6FFED` | `#389E0D` | 普通 |

### 0.2 字体

| 场景 | 字号 | 行高 | 字重 |
|------|------|------|------|
| 学生端对话气泡 | 18px | 1.6 | 400 |
| 学生端按钮/标签 | 20px | 1.4 | 600 |
| 教师端标题 | 16px | 1.5 | 600 |
| 教师端正文 | 14px | 1.5 | 400 |
| 教师端辅助 | 12px | 1.4 | 400 |

字体族：`-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`

### 0.3 间距与圆角

| Token | 值 | 用途 |
|-------|-----|------|
| `--space-xs` | 4px | 图标与文字间距 |
| `--space-sm` | 8px | 紧凑元素间距 |
| `--space-md` | 16px | 卡片内边距、列表间距 |
| `--space-lg` | 24px | 区块间距 |
| `--space-xl` | 32px | 页面级间距 |
| `--radius-sm` | 8px | 按钮、输入框 |
| `--radius-md` | 12px | 卡片 |
| `--radius-lg` | 16px | 对话气泡 |
| `--radius-full` | 9999px | 情绪卡片、头像 |

### 0.4 儿童端视觉原则

| 原则 | 实现 |
|------|------|
| 大触控目标 | 按钮最小 48×48px，情绪卡片 120×120px |
| 高对比度 | 文字与背景对比度 ≥ 4.5:1 |
| 圆角友好 | 所有可交互元素圆角 ≥ 12px |
| 色彩温暖 | 主色调用暖蓝/浅绿，避免纯黑/纯红大面积使用 |
| 动效轻柔 | 过渡 200-300ms ease-out，避免闪烁/快速跳动 |
| 具象图标 | 用表情/动物/天气图标，不用抽象线性图标 |
| 最少文字 | 按钮用"开始聊聊""深呼吸"，不用"提交""确认" |

```typescript
  message: Message;
  isStreaming?: boolean;  // 流式逐字显示
}

// 样式规则：
// role='user'  → 右对齐，浅蓝背景(--color-primary-light)，圆角 16px 16px 4px 16px
// role='ai'    → 左对齐，白色背景，圆角 16px 16px 16px 4px，左侧 🤖 头像
// role='system'→ 居中，浅黄背景(--color-warning/10%)，圆角 12px，⚠️ 图标
// isStreaming  → 末尾显示闪烁光标 ▌
```

**交互流程**：

```
用户输入 → 前端校验(≤200字,非空) → POST /api/v1/student/sessions/{id}/messages
  → 显示用户气泡(status=sending)
  → 收到 SSE 流 → 逐字渲染 AI 气泡
  → 流结束 → 更新 remainingTurns, currentState
  → 如果 riskLevel >= L4 → 显示安全横幅 + 禁用输入框 + 显示快捷操作
  → 如果 remainingTurns == 0 → 显示收束弹窗
```

## 4. 核心交互流程

### 4.1 学生对话完整流程

```
[情绪选择首页]
  │ 点击情绪卡片
  ▼
[创建会话] POST /sessions → sessionId
  │
  ▼
[对话页] 显示 AI 开场白（S0_START）
  │ "你好！我是波波。你选了{{emotion}}，能告诉我发生了什么吗？"
  │
  ▼
[用户输入] → POST /sessions/{id}/messages
  │
  ├─ SSE 流式返回 AI 回复
  │  ├─ 正常：显示气泡，更新状态
  │  ├─ L4/L5：显示安全横幅，禁用输入，显示操作按钮
  │  └─ 超轮(12轮)：显示收束弹窗
  │
  ▼
[会话结束]
  ├─ 正常结束：显示"今天你做得很好" + 鼓励现实连接
  ├─ 转人工：显示"老师会来帮你" + 安全提示
  └─ 超时：显示"今天先聊到这里" + 明天再来
  │
  ▼
[会话评价] 可选：😊 有帮助 / 😐 一般 / 😟 没帮助
  │
  ▼
[返回首页]
```

### 4.2 教师预警处置流程

```
[WebSocket 推送新预警] → 桌面通知 + 侧边栏红点
  │
  ▼
[预警队列] 按风险排序，S0 置顶
  │ 点击预警卡片
  ▼
[预警详情] 查看证据 + AI 建议
  │
  ├─ [认领] → 状态变为 processing，记录认领时间
  │   ├─ [创建个案] → 跳转个案创建表单
  │   ├─ [安排预约] → 跳转预约日历
  │   ├─ [通知班主任] → 生成脱敏协同任务
  │   └─ [标记误报] → 弹窗填写原因 → 关闭预警
  │
  ├─ [转派] → 选择目标老师 → 通知
  │
  └─ [升级] → 提升风险等级 → 通知管理者
  │
  ▼
[处理完成] 填写处置记录 → 关闭预警 → 进入个案跟进
```

### 4.3 高风险紧急流程（L4/L5）

```
[学生输入触发 L4/L5]
  │
  ├─ 学生端：
  │   ├─ 输入框禁用
  │   ├─ 显示安全横幅（橙色/红色）
  │   ├─ 显示三个大按钮：[找老师] [打电话] [我安全了]
  │   └─ 如果 L5：自动弹出紧急资源（120/110/热线）
  │
  ├─ 教师端（并行）：
  │   ├─ WebSocket 推送 S0/S1 预警
  │   ├─ 桌面弹窗 + 声音提醒
  │   ├─ 钉钉/企微/短信通知（按学校配置）
  │   └─ 5 分钟未确认 → 自动升级备份老师 + 管理者
  │
  └─ 系统：
      ├─ 写入 risk_events 表
      ├─ 生成教师摘要（ReportAgent）
      ├─ 记录审计日志
      └─ 会话标记为 safety_mode，后续消息走安全模板
```

## 8. 性别个性化设计

> 决策背景：小学生心理发展存在显著性别差异，沟通偏好、情绪表达方式、对 AI 伙伴的期待均不同。
> 原则：**差异化表达，统一底线**——风险识别、危机处置、隐私保护不随性别变化。

### 8.1 注册层

| 字段 | 类型 | 选项 | 说明 |
|------|------|------|------|
| `gender` | enum | `male` / `female` | 二选一，图标+文字按钮，默认不选（必选） |

- 存储位置：`tenant_template.users.gender VARCHAR(10)`
- 注册接口 `TrialRegisterRequest` 新增 `gender` 字段
- 前端 TrialRegister 组件在昵称下方、年龄上方展示

### 8.2 对话层（Prompt 注入）

在 SYS-001 System Prompt 中追加 `{{gender_style}}` 变量段：

**男生（male）：**
```
# 沟通风格（男生）
- 你像一个阳光、爱运动的小队友，说话简短有力、带点幽默
- 多用行动隐喻："咱们想个办法试试？""你已经很勇敢了"
- CBT 切入顺序：情境 → 行动 → 感受（先做再感受）
- 情绪命名简洁："看起来你有点不爽？"
- 鼓励方向：勇气、坚持、想办法
```

**女生（female）：**
```
# 沟通风格（女生）
- 你像一个暖心、细心的好闺蜜，说话温柔、有耐心
- 多用情感反射："听起来你心里有点委屈对吗？""你的感受很重要"
- CBT 切入顺序：感受 → 情境 → 行动（先命名情绪再解决）
- 情绪命名细腻："你是不是觉得有点孤单，又有点生气？"
- 鼓励方向：表达、自我关怀、愿意说出来就很棒
```

### 8.3 TTS 语音层

| 性别 | 默认音色偏好 | 语速 | 语调 |
|------|------------|------|------|
| male | 少年音（男声，活泼明亮） | rate: 1.05 | pitch: 1.0 |
| female | 少女音（女声，温柔亲切） | rate: 0.95 | pitch: 1.1 |

- 前端 `speechSynthesis` 根据 `user.gender` 筛选 voice（中文男声/女声）
- 用户可在设置中手动切换音色（覆盖默认）

### 8.4 界面层

| 元素 | 男生 | 女生 |
|------|------|------|
| 情绪选择页伙伴 | 🦸‍♂️ / 🐯（力量感） | 🧚‍♀️ / 🐰（温暖感） |
| 主题色微调 | 偏蓝绿（冒险/海洋） | 偏粉紫（花园/星空） |
| 成就徽章文案 | "闯关成功！" | "你做到了！" |

### 8.5 不变项（安全底线）

以下内容**不随性别变化**：
- 风险识别规则（绿/黄/橙/红四级）
