## 二、候选清单

### 前端深部

#### R-001 student-h5 API 服务面无端点登记【Strong】
- **涉及**：student-h5/src/api.ts（400 行四类职责：存储键/会话/9 个硬编码 fetch/通用 api()）
- **问题**：三端端点登记模式不一致——teacher-web 有 ENDPOINTS 常量表（FA-15）、parent-h5 有 endpoints.ts，student-h5 无等价物；新增端点靠手写路径 + apiContract 正则测试兜底（开发期无编译期提示）。
- **解决**：9 个 fetch + api() 收拢为 student 端 ENDPOINTS 常量表 + 统一入口（对齐 teacher-web 模式）；ConsentKeys 迁出独立模块。
- **删除测试**：getUser() 返回 Record<string, unknown>——类型弱但调用面可用，不强求。

#### R-002 teacher-web 审计日志端点资源归属错位【Worth】
- **涉及**：teacher-web api/endpoints.ts L51 `getAuditLogs: '/api/v1/admin/invite-codes/audit-logs'`
- **问题**：审计日志（全局资源）挂在 invite-codes 子资源下，REST 语义错位。
- **解决**：迁移至 /api/v1/admin/audit-logs（配向后兼容别名或一次性迁移）。

#### R-003 parent-h5 请求工厂三处自建 + toc 绕过 TokenStorage【Worth】
- **涉及**：parent-h5 services/index.ts + device.ts + toc.ts（三处 createPlatformRequest 独立实例）；toc.ts saveTocSession 直写 sessionStorageImpl（键名靠"巧合一致"）
- **问题**：三工厂实例分裂；toc 会话落盘绕过 TokenStorage 接口（无契约）；tokenStorage.ts L8 注释声称的"parent 适配层包装"**实测不存在**（注释应删或适配应补）。
- **解决**：服务层共享单一工厂实例（模块级单例）；toc 落盘改走 TokenStorage 接口。

#### R-004 useChatSession 编排深度 + deduplicateText 无单测【Worth】
- **涉及**：student-h5/src/hooks/useChatSession.ts（sendMessage ~110 行编排）+ deduplicateText（O(n²) 启发式无单测）
- **问题**：sendMessage 编排 9+ hooks 协调（ref 代理规避 TDZ——继续增长逼近"接线意大利面"）；deduplicateText 业务规则裸露。
- **解决**：deduplicateText 抽纯函数 + 单测（对比 chatRoomRules.ts 有配套测试）；sendMessage 可拆"发送编排/流收尾"两层。

#### R-005 teacher-web 色板双轨（StatsCharts MS 硬编码 vs CSS token）【Worth】
- **涉及**：teacher-web StatsCharts.tsx L29-36（MS 色板 TS 常量，注释自述与 index.css token 手工同步）；useECharts.ts 双 init 路径重复
- **问题**：主题 token 双轨（CSS var 与 TS 常量手工同步）；useECharts 双 init 靠 chartRef 防重。
- **解决**：色板从 shared 主题模块导出（或生成 CSS+TS 双产物）；useECharts 双 init 收敛单 effect + 重试。
- **删除测试**：ChartCard/StatCard **已删除**（被 StatsCharts/useECharts 取代，无残留——用户点名走查项证实健康）。

#### R-006 teacher-web DTO 手工对齐后端 VO【Worth】

### 后端服务域

#### R-007 consent 撤回后无法重新授权【Strong（合规敏感）】
- **涉及**：ConsentWithdrawalService（L91-93 撤回只 insert 留痕不删 guardian_consent）+ GuardianConsentService.requestConsent（L68-76 selectCount > 0 拒绝重复申请）
- **问题**：撤回后 guardian_consent 记录仍在 → **家长撤回后学生永远无法重新获得监护人同意**；账号 status=withdrawn 后无 reactivate 路径。
- **解决**：撤回语义补充"重新授权"流程（删除/失效旧 guardian_consent 或按撤回时间戳过滤）；明确 reactivate 产品路径。
- **删除测试**：ConsentWithdrawalService.STATUS_WITHDRAWN 兼容常量可删（User.STATUS_WITHDRAWN 已存在）。

#### R-008 GuardianConsentService 注释偏差 + 脱敏无长度守卫【Worth】
- **涉及**：GuardianConsentService L24-26（注释称"验证通过→激活"但 confirmConsent 只 insert 未更新 user.status）+ L80-81 手机号脱敏 substring 无长度守卫（<7 抛 StringIndexOutOfBounds）
- **解决**：注释更正（或补激活逻辑）；脱敏抽公共工具 + 长度守卫。

#### R-009 撤回数据删除覆盖面窄【Worth】
- **涉及**：ConsentWithdrawalService（撤回只删 student_profiles + 冻结账号；声纹/记忆/日记/对话均不随撤回删除）
- **问题**：PIPL §47 删除权语义下"画像已删、记忆仍在服务期"窗口。
- **解决**：定义"撤回删除范围"清单（表级）或撤回事件登记进 retention 优先队列。
