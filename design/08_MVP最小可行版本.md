## 一、MVP 定义

### 1.1 核心用户群体

- **目标用户**：4-6 年级小学生（10-12 岁）
- **使用场景**：情绪倾诉与基础心理支持
- **使用设备**：学校平板设备（主要）、PC 浏览器（次要）

### 1.2 核心场景

学生可在安全、隐私的环境中进行情绪表达，获得 AI 的共情回应和基础引导。

### 1.3 最小闭环

```
倾诉 → 共情回应 → 风险识别 → 必要转介
```

## 二、MVP 功能范围

### 2.1 学生端功能（必须实现）

#### 2.1.1 文本对话入口

- 简洁友好的聊天界面
- 适合小学生的视觉风格和交互设计
- 对话气泡清晰区分用户/AI 消息
- 支持发送文字消息

#### 2.1.2 情绪选择

- 提供 5 种基础情绪选项：**开心、难过、生气、害怕、紧张**
- 情绪图标采用儿童友好设计
- 支持点击情绪标签快速发起对话
- 情绪选择作为对话开场引导

#### 2.1.3 基础 CBT 引导对话

- 基于认知行为疗法原理的 AI 对话引导
- 引导学生表达情绪和想法
- 提供简单的自我调节建议
- 对话内容符合小学生认知水平

#### 2.1.4 放松呼吸练习

- 呼吸引导动画
- 3-2-3 呼吸法（吸气 3 秒 - 屏息 2 秒 - 呼气 3 秒）
- 简单的放松指导语
- 时长约 2 分钟

#### 2.1.5 风险预警触发

- 自动识别高风险关键词（如自伤、自杀相关表达）
- 识别到风险时自动通知教师端
- 学生端显示「已通知老师」的友好提示
- 保持学生继续对话的可能性

### 2.2 教师端功能（必须实现）

#### 2.2.1 预警通知接收

- 实时接收学生端触发的风险预警
- 通知包含学生信息和风险内容摘要
- 支持短信、站内消息多种通知方式
- 通知时间戳记录

#### 2.2.2 高风险学生列表

- 清晰展示当前需要关注的学生
- 显示预警时间、预警类型
- 支持按时间、风险等级排序
- 一键查看学生档案

#### 2.2.3 简单档案查看

- 学生基本信息（姓名、年级、班级）
- 本次对话摘要
- 历史预警记录（近 30 天）
- 心理老师备注功能

### 2.3 不在 MVP 范围的功能

| 功能 | 说明 | 计划阶段 |
|------|------|----------|
| 语音对话 | 语音输入/输出 | M3 |
| 人脸识别 | 情绪识别辅助 | M4 |
| 复杂测评量表 | 专业心理测评 | M3 |
| 趋势分析 | 学生情绪趋势大屏 | M3 |
| 移动端 App | iOS/Android 应用 | 远期规划 |

## 三、技术边界

### 3.1 部署方式

- 仅 Web 端支持（H5 适配平板浏览器）
- 云端部署模式
- 暂不支持私有化部署

### 3.2 交互方式

- 仅支持文本交互
- 不支持语音输入/输出
- 不支持视频交互

### 3.3 AI 能力

- 调用第三方 LLM API
- 使用合规的心理援助对话模型
- 支持国产大模型（优先）

### 3.4 数据合规

- 数据存储于国内云服务商
- 符合《个人信息保护法》要求
- 未成年人数据单独加密存储

## 四、用户流程设计

### 4.1 核心学生流程

#### 流程一：学生正常倾诉流程

```
[开始] → [登录验证] → [情绪选择] → [AI 共情对话] → [获得调节建议] → [对话结束] → [满意度评价] → [结束]
```

**详细步骤**：

1. 学生使用账号密码登录（或扫码登录）
2. 系统展示 5 种情绪图标
3. 学生点击当前情绪（如「难过」）
4. AI 基于情绪类型进行共情回应
5. 学生描述遇到的问题
6. AI 运用 CBT 技术进行引导
7. 系统根据对话内容判断是否需要提供放松练习
8. 对话自然结束或学生主动结束
9. 邀请学生对本次对话进行评价
10. 返回情绪选择页面

#### 流程二：风险识别与转介流程

```
[开始] → [登录验证] → [情绪选择] → [AI 对话] → [风险关键词识别] → [预警触发] → [通知教师] → [老师介入] → [结束]
```

**详细步骤**：

1. 系统识别到风险关键词（如「不想活了」）
2. AI 暂停当前对话，发送关怀消息
3. 系统同时向教师端发送预警通知
4. 教师收到通知后查看学生信息
5. 教师与学生进行线下沟通
6. 系统记录处理结果

### 4.2 教师介入流程

```
[收到预警] → [查看学生档案] → [评估风险等级] → [线下沟通] → [记录处理结果] → [标记处理完成]
```

### 4.3 完整用户旅程地图

| 阶段 | 学生行为 | 系统响应 | 教师行为 |
|------|----------|----------|----------|
| **入口** | 打开登录页 | 显示登录表单 | 打开管理后台 |
| **情绪选择** | 点击情绪图标 | 启动对应对话模板 | 查看预警列表 |
| **对话中** | 描述困扰 | AI 共情 + CBT 引导 | 等待预警（如有） |
| **风险触发** | 表达消极想法 | 识别 + 通知老师 | 收到预警通知 |
| **对话结束** | 获得建议 | 推送放松练习 | - |
| **评价** | 提交满意度 | 记录评价数据 | 查看对话记录 |

**users**：id, tenant_id, school_id, name, role(enum), grade, class_name, status, created_at

### 5.3 必须采集的数据项

- 用户基础信息（姓名、角色、学校、班级）

- 消息结构化摘要（情绪标签、风险信号、CBT 关键节点）
- 风险事件完整记录（risk_event JSON 结构，见 04 文档）
- 模型调用日志（prompt_version、model_version、latency）
- 审计日志（敏感访问、权限变更、风险处置）

### 5.4 可延迟采集的数据项

| 数据项 | 说明 | 延迟原因 |

## 六、性能要求

### 6.1 响应时间

- AI 首字响应时间：**< 3 秒**
- 页面加载时间：**< 2 秒**
- API 接口响应时间：**< 500ms**

### 6.2 并发能力

- 支持 100 所同时在线
- 单校同时在线用户：500 人
- 系统总并发：50000 用户

### 6.3 可用性

- 系统可用性：**> 99.5%**
- 每月计划内维护窗口：< 4 小时
- 故障恢复时间：< 30 分钟

### 6.4 数据安全

- 传输加密：HTTPS 全链路
- 存储加密：敏感字段 AES 加密
- 备份策略：每日全量备份 + 实时增量

## 七、MVP 阶段划分

### 7.1 M1 - 核心对话 + 风险识别（第 1-2 个月）

**目标**：完成最小闭环验证

**功能清单**：

- 学生端：登录、情绪选择、文本对话、CBT 引导
- AI 引擎：共情对话、风险关键词识别
- 预警通知：站内通知

**完成标准**：

- 100 名真实用户完成对话
- 风险预警准确率 > 80%
- 无重大安全问题

### 7.2 M2 - 放松训练 + 教师后台（第 3-4 个月）

**目标**：完善功能体验

**功能清单**：

- 学生端：呼吸引导放松练习、满意度评价
- 教师端：高风险学生列表、学生档案查看、处理记录
- 数据统计：使用量、预警量统计

**完成标准**：

- 放松练习使用率 > 30%
- 教师处理率 > 90%
- 用户满意度 > 4.0

### 7.3 M3 - 测评 + 趋势分析（第 5-6 个月）

**目标**：增加心理测量能力

**功能清单**：

- 基础测评量表（PHQ-9、GAD-7 简化版）
- 学生情绪趋势分析
- 教师工作台优化
- 家校通知功能

**完成标准**：

- 测评完成率 > 70%
- 趋势分析准确率 > 75%

### 7.4 M4 - 语音 + 私有化（远期规划）

**目标**：扩展能力和部署方式

**功能清单**：

- 语音输入/输出
- 人脸情绪识别辅助
- 私有化部署支持
- 移动端 App

### 10.1 阶段划分 vs 实际进度四态对照

**倒挂定性**：语音提前是合理漂移（学生端体验价值高、技术就绪）；**测评滞后是风险项**——它既是本篇 M3 承诺也是合规门禁（10 篇未成年人测评合规），必须在商用前补齐，现势排期以 design/30 为准。

### 10.2 M4/M5 边界定义（✅ 已定稿：按商用门禁重切，2026-07-28 钱敏健）
