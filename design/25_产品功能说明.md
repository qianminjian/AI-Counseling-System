# MindSafe AI 心理辅导系统 — 产品功能说明

> 版本：v2.0 | 更新日期：2026-07-28 | 适用对象：学校管理者、教师、家长、产品培训、测试人员
> 产品地址：https://yun.gxjugu.com/mindsafe/（学生端）| https://yun.gxjugu.com/teacher/（教师端）| /parent/（家长端）
> 测试培训详见：`design/33_系统测试培训手册.md`

---

## 一、产品简介

MindSafe 是一款面向小学的 AI 心理辅导 SaaS 系统，通过人工智能技术为 6-12 岁小学生提供 7×24 小时的心理倾诉与认知行为辅导服务，同时为教师提供实时预警看板，为家长提供情绪周报，构建"学生-AI-教师-家长"四位一体的心理健康守护体系。

**核心价值：**
- 学生随时有"人"倾听，不用等到预约心理咨询
- AI 严格遵循 CBT（认知行为疗法）专业流程，不是闲聊机器人
- 风险信号实时识别，高危情况秒级推送教师
- 多学校数据完全隔离，满足 SaaS 采购模式

## 三、学生端功能

> 访问方式：手机/平板浏览器打开 https://yun.gxjugu.com/mindsafe/
> 适用对象：小学 1-6 年级学生

### 3.1 注册与准入

| 功能 | 说明 |
|------|------|
| 告知同意门控 | 首次进入展示产品性质告知（非医疗/非危机热线）+ 隐私说明 + 监护人同意勾选 |
| 邀请码注册 | 输入教师分发的邀请码 + 昵称 + 年龄 + 性别 → 创建专属账号 |
| 性别个性化 | 男生/女生选择后，AI 沟通风格、默认语音音色自动适配 |
| 家庭码 | 注册成功后生成 6 位家庭码，供家长绑定（见第五章） |
| PIN 码设置 | 注册后引导设置 4-6 位数字 PIN，后续快捷登录 |
| 监护人同意闭环 | 发起监护人手机验证 → 短信确认 → 写入同意记录（AUTH-023） |

### 3.2 AI 心理对话（核心功能）

| 功能 | 说明 |
|------|------|
| 情绪选择入口 | 每次对话前选择当前心情（开心/平静/难过/生气/害怕/紧张），AI 据此调整开场 |
| CBT 结构化辅导 | AI 严格按"情境→感受→想法→行动"认知行为疗法流程引导，非自由闲聊 |
| 流式实时回复 | SSE 逐字输出，体验自然流畅 |
| 语音输入 | 按住波波说话，自动转文字（ASR）+ 语音情感分析（检测语调中的情绪） |
| 语音唤醒 | 说"你好波波"唤醒对话（Whisper 本地引擎，音频不出设备） |
| 语音朗读（TTS） | AI 回复可朗读播放，支持多种音色选择（小星星/小太阳等） |
| 性别差异化对话 | 男生：阳光简短、行动导向；女生：温柔细腻、情感先行 |
| 年龄适配对话 | 1-2 年级/3-4 年级/5-6 年级三档语言模板（认知水平/比喻库/互动模式/CBT 深度） |
| 动态降级 | 表达深度低的学生自动降低语言复杂度，风险场景不降级 |
| 学生画像记忆 | AI 记住学生的情绪模式、偏好、已掌握的技巧、性格特征，越聊越懂你 |
| 跨会话长期记忆 | 关键事件摘要 + 沟通偏好 + 技巧有效性跨会话回注 |
| 冷场暖场 | 沉默 30s+ 后决策模型判断：留白（不打扰）或暖场（AI 主动引导），最多 2 次 |
| 多模型路由 | DeepSeek 主 + 通义/GLM 备，故障自动切换 |
| 会话历史 | 可查看历史对话记录 |
| 满意度评价 | 对话结束后邀请评价（😊/😐/😢），数据反馈教师端 |
| 使用时长限制 | 每日累计 ≤ 30 分钟（未保法），达限提示休息 |

### 3.3 放松练习

| 功能 | 说明 |
|------|------|
| 呼吸训练 | 动画引导的 4-7-8 呼吸法（吸气-屏住-呼气圆圈动画） |
| 正念冥想 | 语音引导的身体扫描、注意力聚焦练习 |
| 想象放松 | 引导式视觉化（安全空间、自然场景） |
| 身体放松 | 蝴蝶拍、渐进式肌肉放松等躯体化练习 |

### 3.4 情绪日记

| 功能 | 说明 |
|------|------|
| 每日打卡 | 选择今天的情绪 + 强度（1-5）+ 一句话备注 |
| 趋势图 | 近 14 天情绪变化折线图 |
| 连续打卡 | 显示连续天数 + 累计天数 |
| 成就徽章 | 打卡里程碑奖励（3天/7天/14天/30天） |

### 3.5 个性化设置

| 功能 | 说明 |
|------|------|
| 语音音色选择 | 小星星（女声温柔）/ 小太阳（男声阳光）等多角色，按性别自动推荐 |
| 主题切换 | 跟随情绪变化的动态主题色（三主题，波波颜色随主题变） |
| 语速调节 | TTS 播放速度可调 |

### 3.6 波波小精灵（品牌伙伴）

| 功能 | 说明 |
|------|------|
| 品牌角色 | 小海豚"波波"，固定品牌角色，颜色随主题变化 |
| 四态动画 | idle（待机）/ listening（倾听）/ speaking（说话）/ happy（开心） |
| 语音圆球 | 按住说话时波波蜷成发光圆球 + 触感反馈（vibrate） |
| 话语气泡 | AI 说话时波波头顶冒气泡，逐句滚动与 TTS 同步 |
| 新手引导 | 首次进入展示"按住波波说话"引导动画 |

### 3.7 声纹登录（共享 Pad 场景）

| 功能 | 说明 |
|------|------|
| 声纹采集 | 注册后引导录制声纹（本地存储，不上传服务器） |
| 唤醒词触发 | 登录页说"你好波波" → 进入声纹识别对话 |
| 声纹比对 | 本地比对匹配 → 自动登录（Phase 1） |
| 超时休眠 | 5 分钟无交互停止监听，触摸恢复 |
| 每次认证 | 共享 Pad 每次打开必须重新认证 |

### 3.8 安全保护机制（学生不可见，后台运行）

| 机制 | 说明 |
|------|------|
| 实时风险识别 | 对话中自动检测自伤、霸凌、家暴等 10 类高危信号 |
| PII 自动脱敏 | 学生输入的手机号、身份证号等自动遮蔽后再传给 AI |
| AI 输出过滤 | 双重审查：关键词硬过滤 + 语义安全审查，确保回复适龄、安全 |
| 危机干预 | 检测到高危信号 → AI 切换危机模式 → 提供求助热线 → 同时推送教师预警 |

| 特性 | 说明 |

## 六、技术特性（面向学校 IT）

| 特性 | 说明 |
|------|------|
| 多租户隔离 | 每所学校数据 Schema 级隔离，互不可见 |
| JWT 双 Token | Access + Refresh 双令牌，支持无感续期 + 登出拉黑 |
| 数据加密 | 传输 HTTPS + 敏感字段 AES-256 加密存储 + 密钥轮换 |
| 审计日志 | 登录、操作、预警处理全部留痕 |
| 容器化部署 | Docker Compose 一键部署，支持私有化 |
| 自动迁移 | Flyway 数据库版本管理，升级无需手动 SQL |
| 多模型路由 | DeepSeek 主 + 通义/GLM 备，故障自动切换 |
| RAG 知识库 | pgvector 向量检索，心理知识增强 AI 回复专业性 |
| 结构化日志 | JSON 格式 + traceId 链路追踪 |
| 监控告警 | Prometheus + Grafana + AlertManager → 企微 webhook |
| 自动备份 | pg_dump 每日备份 + 异地存储 + 恢复演练 |

## 七、合规与安全

| 合规项 | 实现 |
|--------|------|
| 未成年人保护 | 告知同意门控 + 监护人同意闭环（短信验证）+ 非医疗声明 |
| 个人信息保护（PIPL） | 最小化采集 + PII 脱敏 + 不存原始对话于画像 + 撤回同意即删除 |
| 儿童安全对话 | AI 回复经双重安全审查，禁止不适龄内容 |
| 危机干预 | 高危信号 → 秒级预警 → 危机热线引导 → 教师通知 → 回访闭环 |
| 数据隔离 | 学校间数据完全隔离，转学不迁移 |
| 使用时长 | 每日 ≤ 30 分钟（未保法） |
| 数据保留 | 普通数据 30 天 / 高风险 365 天自动清理 |
| 音频隐私 | 语音唤醒/声纹识别全部本地处理，音频不出设备 |
| 密码策略 | 8 位+复杂度 + 90 天过期 + 登录失败锁定（5 次/15 分钟） |

## 八、使用流程速览

### 学生使用流程
```
打开链接 → 阅读告知同意 → 输入邀请码注册 → 获得家庭码 → 设置 PIN
→ 选择今天心情 → 进入 AI 对话（或说"你好波波"唤醒）
→ 文字/语音倾诉 → AI 按 CBT 流程辅导 → 结束评价
→ 可选：放松练习 / 情绪日记 / 查看成就徽章
```

### 教师使用流程
```
登录教师端 → 查看工作台概览 → 处理预警队列（认领→干预→解决→回访）
→ 查看学生档案/画像雷达 → 生成家长报告 → 质量监控 → 知识库管理
```

### 家长使用流程
```
获得家庭码（学生注册时显示）→ 打开 /parent/ → 家庭码+手机号+密码注册
→ 登录后查看孩子情绪周报 → 参考 AI 建议 → 可撤回同意
```
