# MindSafe AI 心理辅导系统 — 产品功能说明

> 版本：v1.0 | 更新日期：2026-07-23 | 适用对象：学校管理者、教师、家长、产品培训
> 产品地址：https://yun.gxjugu.com/mindsafe/（学生端）| https://yun.gxjugu.com/teacher/（教师端）

---

## 一、产品简介

MindSafe 是一款面向小学的 AI 心理辅导 SaaS 系统，通过人工智能技术为 6-12 岁小学生提供 7×24 小时的心理倾诉与认知行为辅导服务，同时为教师提供实时预警看板，为家长提供情绪周报，构建"学生-AI-教师-家长"四位一体的心理健康守护体系。

**核心价值：**
- 学生随时有"人"倾听，不用等到预约心理咨询
- AI 严格遵循 CBT（认知行为疗法）专业流程，不是闲聊机器人
- 风险信号实时识别，高危情况秒级推送教师
- 多学校数据完全隔离，满足 SaaS 采购模式

## 三、学生端功能

> 访问方式：手机/平板浏览器打开 https://yun.gxjugu.com/mindsafe/
> 适用对象：小学 1-6 年级学生

### 3.1 注册与准入

| 功能 | 说明 |
|------|------|
| 告知同意门控 | 首次进入展示产品性质告知（非医疗/非危机热线）+ 隐私说明 + 监护人同意勾选 |
| 邀请码注册 | 输入教师分发的邀请码 + 昵称 + 年龄 + 性别 → 创建专属账号 |
| 性别个性化 | 男生/女生选择后，AI 沟通风格、默认语音音色自动适配 |

### 3.2 AI 心理对话（核心功能）

| 功能 | 说明 |
|------|------|
| 情绪选择入口 | 每次对话前选择当前心情（开心/平静/难过/生气/害怕/紧张），AI 据此调整开场 |
| CBT 结构化辅导 | AI 严格按"情境→感受→想法→行动"认知行为疗法流程引导，非自由闲聊 |
| 流式实时回复 | 逐字输出，体验自然流畅 |
| 语音输入 | 支持按住说话，自动转文字 + 语音情感分析（检测语调中的情绪） |
| 语音朗读（TTS） | AI 回复可朗读播放，支持多种音色选择（小星星/小太阳等） |
| 性别差异化对话 | 男生：阳光简短、行动导向；女生：温柔细腻、情感先行 |
| 学生画像记忆 | AI 记住学生的情绪模式、偏好、已掌握的技巧，越聊越懂你 |
| 会话历史 | 可查看历史对话记录 |
| 满意度评价 | 对话结束后邀请评价（😊/😐/😢），数据反馈教师端 |

### 3.3 放松练习

| 功能 | 说明 |
|------|------|
| 呼吸训练 | 动画引导的 4-7-8 呼吸法（吸气-屏住-呼气圆圈动画） |
| 正念冥想 | 语音引导的身体扫描、注意力聚焦练习 |
| 想象放松 | 引导式视觉化（安全空间、自然场景） |
| 身体放松 | 蝴蝶拍、渐进式肌肉放松等躯体化练习 |

### 3.4 情绪日记

| 功能 | 说明 |
|------|------|
| 每日打卡 | 选择今天的情绪 + 强度（1-5）+ 一句话备注 |
| 趋势图 | 近 14 天情绪变化折线图 |
| 连续打卡 | 显示连续天数 + 累计天数 |
| 成就徽章 | 打卡里程碑奖励（3天/7天/14天/30天） |

### 3.5 个性化设置

| 功能 | 说明 |
|------|------|
| 语音音色选择 | 小星星（女声温柔）/ 小太阳（男声阳光）等多角色 |
| 主题切换 | 跟随情绪变化的动态主题色 |
| 语速调节 | TTS 播放速度可调 |

### 3.6 安全保护机制（学生不可见，后台运行）

| 机制 | 说明 |
|------|------|
| 实时风险识别 | 对话中自动检测自伤、霸凌、家暴等 10 类高危信号 |
| PII 自动脱敏 | 学生输入的手机号、身份证号等自动遮蔽后再传给 AI |
| AI 输出过滤 | 双重审查：关键词硬过滤 + 语义安全审查，确保回复适龄、安全 |
| 危机干预 | 检测到高危信号 → AI 切换危机模式 → 提供求助热线 → 同时推送教师预警 |

## 四、教师端功能

> 访问方式：电脑浏览器打开 https://yun.gxjugu.com/teacher/
> 适用对象：班主任、心理教师、学校管理员

### 4.1 登录与账号

| 功能 | 说明 |
|------|------|
| 账号密码登录 | 教师昵称 + 密码 |
| 首次改密 | 初始密码首次登录强制修改 |
| 企业微信免密（预留） | 支持企微 OAuth 一键登录（需学校配置） |
| 深色模式 | 支持明/暗主题切换 |

### 4.2 工作台（首页）

| 功能 | 说明 |
|------|------|
| 数据概览 | 今日对话数、活跃学生数、待处理预警数、平均满意度 |
| 情绪分布图 | 全校学生情绪饼图（开心/平静/低落/焦虑占比） |
| 7 天趋势 | 对话量、预警数折线图 |
| 快捷入口 | 一键跳转预警队列、学生管理 |

### 4.3 预警队列（核心功能）

| 功能 | 说明 |
|------|------|
| 实时推送 | WebSocket 实时接收新预警 + 声音提醒 + 桌面通知 |
| 风险分级 | 红（S3 危机）/ 橙（S2 高危）/ 黄（S1 关注）/ 绿（正常） |
| 预警详情 | 查看触发原因、风险类型、关联会话 |
| 认领处理 | 教师认领预警 → 线下干预 → 标记解决 |
| 处理记录 | 全部预警的处理状态可追溯 |

### 4.4 学生管理

| 功能 | 说明 |
|------|------|
| 学生列表 | 按班级/年级筛选，显示最近对话时间、风险等级 |
| 高危学生 | 一键筛选近 30 天有风险事件的学生 |
| 学生档案 | 查看某学生的对话历史、情绪趋势、会话摘要 |
| 教师备注 | 为学生添加观察备注（如"已与家长沟通"） |
| 会话详情 | 查看某次对话的消息摘要（非原文，保护隐私） |

### 4.5 质量监控

| 功能 | 说明 |
|------|------|
| AI 回复审查 | 查看被安全系统标记的 AI 回复（异常/疑似违规） |
| 质量统计 | 标记率、审查通过率、常见问题类型 |
| 满意度分析 | 学生评价分布（好评/中评/差评） |

### 4.6 通知中心

| 功能 | 说明 |
|------|------|
| 系统通知 | 预警通知、处理提醒、系统公告 |
| 已读/未读 | 未读角标 + 标记已读 |

### 4.7 管理控制台（仅管理员）

| 功能 | 说明 |
|------|------|
| 邀请码管理 | 批量生成/查看/停用试用邀请码 |
| 用户管理 | 查看/创建/停用教师和学生账号 |
| 平台总览 | 全平台数据统计（多学校视角） |

### 4.8 数据大屏

| 功能 | 说明 |
|------|------|
| 全屏展示 | 访问 /bigscreen 进入深色全屏数据看板 |
| 实时数据 | 全校心理健康态势一屏呈现（适合汇报/展示） |

## 五、家长端功能

> 访问方式：教师生成专属链接 → 家长手机打开
> 适用对象：学生家长/监护人

### 5.1 情绪周报（只读）

| 功能 | 说明 |
|------|------|
| 情绪概览 | 孩子近 7 天的主要情绪分布 |
| 对话统计 | 本周对话次数、总时长 |
| 风险等级 | 当前风险状态（绿/黄/橙/红） |
| AI 建议 | 基于孩子近期状态的家长沟通建议 |

### 5.2 访问控制

| 特性 | 说明 |
|------|------|
| 无需注册 | 教师生成链接，家长直接打开 |
| Token 鉴权 | 链接含 7 天有效期 Token，过期需教师重新生成 |
| 只读权限 | 家长只能看统计报告，不能看对话原文 |
| 隐私保护 | 不展示对话内容，只展示情绪趋势和 AI 建议 |

## 六、技术特性（面向学校 IT）

| 特性 | 说明 |
|------|------|
| 多租户隔离 | 每所学校数据 Schema 级隔离，互不可见 |
| JWT 认证 | 无状态 Token 鉴权，支持多端同时在线 |
| 数据加密 | 传输 HTTPS + 敏感字段脱敏存储 |
| 审计日志 | 登录、操作、预警处理全部留痕 |
| 容器化部署 | Docker Compose 一键部署，支持私有化 |
| 自动迁移 | Flyway 数据库版本管理，升级无需手动 SQL |

## 七、合规与安全

| 合规项 | 实现 |
|--------|------|
| 未成年人保护 | 告知同意门控 + 监护人同意 + 非医疗声明 |
| 个人信息保护（PIPL） | 最小化采集 + PII 脱敏 + 不存原始对话于画像 |
| 儿童安全对话 | AI 回复经双重安全审查，禁止不适龄内容 |
| 危机干预 | 高危信号 → 秒级预警 → 危机热线引导 → 教师通知 |
| 数据隔离 | 学校间数据完全隔离，转学不迁移 |

## 八、使用流程速览

### 学生使用流程
```
打开链接 → 阅读告知同意 → 输入邀请码注册 → 选择今天心情 → 进入 AI 对话
→ 文字/语音倾诉 → AI 按 CBT 流程辅导 → 结束评价 → 可选：放松练习/情绪日记
```

### 教师使用流程
```
登录教师端 → 查看工作台概览 → 处理预警队列（认领→干预→解决）
→ 查看学生档案 → 生成家长报告链接 → 质量监控
```

### 家长使用流程
```
收到教师分享的链接 → 手机打开 → 查看孩子情绪周报 → 参考 AI 建议
```
