# 17 前端架构设计

> 状态：新建 | 关联：16 API 接口设计、05 老师后台、08 MVP、12 技术架构
> 核心：定义前端技术栈、项目结构、页面路由、组件体系、状态管理与安全策略，是前端开发的实施蓝图。

> ⚠️ **实现偏差说明（2026-07-28 核对）**：
> - 实际采用 **React 19 + JavaScript**（非 TypeScript 5），Vite 8（非 Vite 5）
> - 项目结构为**扁平 components/ 目录**（非 features/ 按业务模块划分）
> - 状态管理为 **React useState/useEffect + Context**（非 Zustand + React Query）
> - 动画为 **CSS 动画 + SVG 组件**（非 Framer Motion + Lottie）
> - 图表为 **ECharts**（非 Recharts）
> - HTTP 为 **原生 fetch + SSE EventSource**（非 Axios）
> - 代码规范为 **oxlintrc**（非 ESLint + Prettier + Husky）
> - 学生端 24 个组件、教师端 19 个组件、家长端 3 个页面
> - 本文档保留目标设计作为远期重构参考
> - 前端现状四态对照、安全策略偏差与路线定稿见 §10（2026-07-28 深化）

## 1. 技术栈

| 维度 | 选型 | 理由 |
|------|------|------|
| 框架 | React 18 + TypeScript 5（实现现状：已升级 React 19） | 生态成熟、类型安全、团队熟悉 |
| 构建 | Vite 5 | 开发热更新快、构建体积小 |
| 样式 | Tailwind CSS 3 + CSS Modules | 原子化快速开发 + 组件级隔离 |
| 状态管理 | Zustand（全局）+ React Query（服务端） | 轻量、类型推导好、服务端缓存自动同步 |
| 路由 | React Router v6 | 标准方案 |
| HTTP | Axios + SSE EventSource | 支持流式对话 |
| 动画 | Framer Motion + Lottie | 对话气泡动效 + 呼吸引导动画 |
| 图表 | Recharts（M3 报表） | 轻量、React 原生 |
| 测试 | Vitest + Testing Library + Playwright | 单元 + 集成 + E2E |
| 代码规范 | ESLint + Prettier + Husky | 统一风格 |

## 4. 核心组件设计

### 4.1 对话组件（chat feature）

**ChatWindow.tsx**：
- 消息列表（虚拟滚动，支持长对话）
- 输入框（字数限制 200 字）
- 状态指示器（当前 CBT 状态、剩余轮次）
- 安全提示横幅（L4/L5 时显示）

**MessageBubble.tsx**：
- 区分 user/ai/system 三种样式
- AI 消息支持 Markdown 渲染（限制子集）
- 系统消息特殊样式（安全提示、资源推荐）
- 消息状态：sending → sent → delivered

**EmotionPicker.tsx**：
- 5 种情绪卡片（开心/难过/生气/害怕/紧张）
- 儿童友好动画反馈
- 点击后创建新会话

**TypingIndicator.tsx**：
- AI 正在输入动画
- SSE 流式逐字显示

### 4.2 放松练习组件

**BreathingGuide.tsx**：
- Lottie 动画（气球/圆圈缩放）
- 吸气-屏息-呼气阶段指示
- 倒计时 + 轮次显示
- 练习前后情绪评分

### 4.3 预警队列组件

**AlertQueue.tsx**：
- 按风险等级分色（红/橙/黄/绿）
- SLA 倒计时
- 快速操作按钮（认领/转派/建个案）
- 筛选器（等级/年级/状态/负责人）

## 5. 状态管理

## 6. 安全策略

| 策略 | 实现 |
|------|------|
| Token 存储 | httpOnly Cookie（非 localStorage，防 XSS） |
| Token 刷新 | 过期前 5 分钟自动 refresh |
| 跨租户防护 | Axios 拦截器从 authStore 注入 `X-Tenant-Id` |
| XSS 防护 | React 默认转义 + DOMPurify 处理 Markdown |
| CSRF | SameSite Cookie + CSRF Token |
| 会话超时 | 15 分钟无操作自动登出 |
| 内容安全 | CSP Header 限制脚本来源 |
| 敏感数据 | 学生姓名默认脱敏显示 |
| 对话安全 | 单次 ≤20 分钟，每日 ≤2 次，超限弹窗提醒 |

| 设计项 | 状态 | 实态说明 |

### 10.2 安全策略对照与偏差登记

- **Token 存储偏差（§6 第 1 行）**：目标 httpOnly Cookie；实际**学生端 sessionStorage**（共享设备策略：关 tab 即清、下次必须登录，仅设备级 consent 标记进 localStorage）——该实现对共享平板场景优于原目标设计，**定稿采纳**；**教师端 localStorage**（access + refresh）存在 XSS 窗口，依赖 React 转义缓解，迁移 httpOnly Cookie 需后端 CSRF 配套，列 P3。
- **X-Tenant-Id 注入（§6 第 3 行）**：实态为服务端从 JWT 解析租户（见 07 §11），前端不注入租户头——本行按实态**废弃**，防伪造以服务端为准。
- **CSP Header（§6 第 7 行）**：前端与 Nginx 层均未配置 CSP，为教师端 localStorage token 的主要补偿缺口，列 P2。

### 10.3 任务归口

| 任务 | 优先级 | 责任人 |
|------|:---:|------|
