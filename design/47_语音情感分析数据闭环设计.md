# 47_语音情感分析数据闭环设计

> 创建：2026-07-28 | 状态：设计期，待实施 | 不含实现代码
>
> 定位：**语音情感闭环专题**。design/54 定义了语音情感分析方案，voice-service 已完整实现 ASR+SER。本文解决最大断链：**语音情感数据当前只做单轮风险融合，没有回注画像、没有趋势追踪、没有标注回流**——把语音情感从“一次性风险信号”升级为“驱动个性化 + 沉淀趋势 + 自我改进”的闭环数据资产。
>
> 关系：数据源承接 voice-service，风险融合承接 ConversationServiceImpl，情绪驱动策略对接 design/44，回注画像对接 design/46，情感化 TTS 对接 design/37/48，风险规则对接 design/04。

## 一、现状诊断（对照真实代码）

### 1.1 语音情感真实实现度：完整实现（模型侧最成熟）

| 环节 | 现状 | 位置 |
|------|------|------|
| ASR 转写 | ✅ SenseVoiceSmall，16kHz 单声道，清洗特殊标记 | voice-service `app.py` |
| SER 情感识别 | ✅ emotion2vec_plus_large，9 类情绪 + confidence + scores | voice-service |
| 合规 | ✅ 临时文件立即删除，音频不落盘 | voice-service |
| 有效性判定 | ✅ conf>0.6 且非 unknown/other | `VoiceAnalysisService.hasValidEmotion()` |
| 风险映射 | ✅ fearful/sad→2橙,angry/disgusted→1黄 | `emotionRiskLevel()` |
| 多模态融合 | ✅ 文本+语音风险 max 规则 | `ConversationServiceImpl` |

9 类情绪：angry/disgusted/fearful/happy/neutral/other/sad/surprised/unknown。

### 1.2 四个断链（本文要解决的）

| # | 断链 | 严重度 | 本文章节 |
|---|------|--------|---------|
| V1 | **情感不回注画像**：语音情绪只用于当轮风险 max，用完即弃，不进 emotionBaseline/riskTrajectory | 🔴 高 | 五 |
| V2 | **无趋势追踪**：单轮情绪 ≠ 情绪趋势，无法发现"这周越来越低落" | 🔴 高 | 六 |
| V3 | **不驱动对话策略**：语音情绪没接进 44 的 currentEmotion（只做风险，不做共情策略切换） | 🟠 中高 | 四 |
| V4 | **无标注回流**：SER 判得准不准无反馈、无 domain 适配（儿童语音与成人不同），模型无法改进 | 🟠 中 | 七 |

### 1.3 根因

语音情感是"**识别→融合风险→丢弃**"的**终点式管线**。它产出的是系统里质量最高的实时情绪信号之一，却只被用了"风险 max"一个用途，其余价值（个性化/趋势/自改进）全部流失。

## 二、设计目标

1. **多用途化**：一次语音情感识别，同时服务①风险融合（已有）②对话共情策略（44）③画像回注（46）④趋势追踪（本文）。
2. **趋势闭环**：单轮情绪沉淀为会话内曲线 + 跨会话趋势，异常趋势触发关注（非诊断）。
3. **策略驱动**：语音情绪作为 44 的 currentEmotion 权威来源之一，驱动情绪镜映与节奏切换。
4. **自改进**：建标注回流机制，评估 SER 在儿童语音上的准确度，指导阈值调优与 domain 适配。
5. **合规安全**：延续音频不落盘；情感衍生数据去标识、最小化、不诊断、不外泄。

**明确不做**：不存原始音频、不做声纹身份识别、不用情感数据做营销、不因单轮情绪贴心理标签。

## 四、语音情感驱动对话策略（补 V3）

### 4.1 情绪信号统一进 44

语音情绪（有效时）作为 design/44 `currentEmotion` 的权威来源，映射到规范情绪集：

| SER 9 类 | 44 规范情绪集 | 说明 |
|----------|-------------|------|
| happy | happy | 正向扩展 |
| neutral | calm | 平稳 |
| sad | sad | 先接住 |
| fearful | fearful/anxious | 安全感优先 |
| angry / disgusted | angry | 先允许宣泄 |
| surprised | 结合文本判定 | 中性偏关注 |
| other / unknown | 忽略（不驱动） | 仅文本情绪生效 |

### 4.2 文本 × 语音融合策略（升级 max 规则）

现状风险用 max（保守，正确保留）。但**共情策略**不应只用 max，需融合：

| 场景 | 文本情绪 | 语音情绪 | 策略 |
|------|---------|---------|------|
| 一致 | sad | sad | 高置信按 sad 策略（44） |
| 不一致（掩饰） | neutral"没事" | fearful/sad | **温和探询 + 安全感优先**，不拆穿（4.3） |
| 语音无效 | any | conf<0.6 | 回退纯文本情绪 |
| 风险维度 | — | — | **始终 max 保守**（不变，红线） |

### 4.3 多模态不一致检测（高价值信号）

文本正向/中性但语音负向（confidence 高）→ 标记"情绪掩饰倾向"信号，供 44 采用更温柔的探询策略、供 46 画像记录（低调、不贴标签），供教师侧关注（非报警）。**不当面拆穿**（对齐 14 儿童安全）。

## 五、语音情感回注画像（补 V1，最关键）

### 5.1 回注契约（47 → 46）

每次有效语音情感识别，异步回注画像（provenance=voice_ser，confidence=SER confidence）：

| 语音衍生信号 | 回注画像维度（46） | 说明 |
|-------------|------------------|------|
| 情绪分布（会话聚合） | emotionBaseline | 与文本情绪共同构成基线 |
| 负向情绪频次/强度趋势 | riskTrajectory（辅助） | 与文本/量表共同判断，非单独触发 |
| 情绪掩饰倾向（4.3） | communicationPref（表达特征） | 中性描述，不诊断 |
| 情绪波动度 | emotionBaseline.volatility | 稳定性刻画 |

### 5.2 去标识与聚合

回注的是**聚合衍生特征**（分布/趋势/波动），不是逐条原始情绪日志长期留存。原始逐轮情绪仅会话内短期保留用于曲线，会话结束聚合后按保留期清理。

## 六、情绪趋势追踪（补 V2）

### 6.1 两级趋势

| 级别 | 粒度 | 用途 |
|------|------|------|
| **会话内曲线** | 每轮情绪序列 | 会话中情绪走向（越来越稳/越来越激动），驱动 44 动态切换 + 收束判断 |
| **跨会话趋势** | 会话级情绪聚合的时间序列 | 发现周级/月级恶化或改善，接入 MBC（34）与教师预警（05/35） |

### 6.2 情绪趋势数据模型（设计期）

`voice_emotion_trend`（租户隔离，去标识聚合）：

| 字段 | 说明 |
|------|------|
| tenant_id / student_user_id / session_id | 隔离与关联 |
| dominant_emotion / emotion_dist(jsonb) | 会话主导情绪 + 9 类分布 |
| negative_ratio / volatility | 负向占比 + 波动度 |
| avg_confidence | 平均置信（低置信趋势降权） |
| text_voice_consistency | 文本↔语音一致性得分（4.3） |
| created_at | 时间 |

### 6.3 趋势异常处置（非诊断）

跨会话负向趋势持续上升且超阈值 → 生成**关注信号**（不是诊断、不是报警），路由教师工作台（35）建议主动关怀 + 建议量表复测（34）。危机级仍走 04 风险管线（实时，不等趋势）。

## 七、SER 标注回流与自改进（补 V4）

### 7.1 为什么需要：儿童 domain gap

emotion2vec 多在成人语料训练，儿童音高/语速/表达差异大，SER 在儿童语音上的真实准确度**未知**。需建标注回流评估并适配。

### 7.2 回流机制（合规前提下）

- **不回流原始音频**（红线：音频不落盘）。回流的是**去标识特征向量/情绪标签 + 弱监督信号**：
  - 弱标签来源①：文本情绪与语音情绪一致的样本（高可信伪标签）。
  - 弱标签来源②：教师/心理老师对会话情绪的事后标注（少量高质量）。
  - 弱标签来源③：多模态不一致样本（难例，重点分析）。
- **评估**：用弱标签集评估 SER 准确度 / 混淆矩阵（哪些情绪常被混淆，如 fearful↔sad），指导阈值与融合策略调优。
- **domain 适配（远期）**：积累足够去标识特征后，评估儿童 domain 微调或阈值分层的必要性。

### 7.3 阈值自适应

现状固定 conf>0.6。回流评估后，按情绪类别分别设阈值（如 fearful 易误判则提高其阈值），并可按 domain 调整，配置化管理。

## 八、语音情感数据流全景

```
采集：学生语音 → voice-service(ASR+SER，音频不落盘) → text + emotion(label/conf/scores)
   ↓
实时用途（并行）：
   ├─ 风险融合(max，保守) → ConversationServiceImpl → 04 风险管线
   ├─ 对话策略 → 映射 44 currentEmotion → EMO-001 情绪镜映/节奏
   └─ 会话内曲线 → 动态切换 + 收束判断
   ↓
会话结束（异步聚合）：
   ├─ 回注画像(46) emotionBaseline/riskTrajectory/波动/掩饰倾向
   ├─ 写 voice_emotion_trend（跨会话趋势）
   └─ 标注回流(去标识特征+弱标签) → SER 评估与阈值调优(七)
   ↓
回收：趋势异常→教师关注(35)+量表复测(34)；准确度评估→阈值/domain 适配→回到采集
```

## 九、合规与隐私（对齐 14/10/07）

- **音频不落盘**（延续现状红线）：仅内存处理，临时文件立即删除。
- **无声纹身份**：不做说话人识别/声纹建模。
- **衍生数据最小化**：长期留存的是聚合趋势与画像特征，非逐条情绪流水；设保留期与可删除。
- **不诊断不标签**：趋势异常=关注信号，非精神障碍判定；表述中性。
- **危机实时优先**：危机级情绪走 04 实时管线，不因"要看趋势"而延迟。
- **告知同意**：语音采集与情感分析纳入同意条款（22）。

## 十一、EARS 验收标准（摘要）

- WHEN 语音情感识别有效（conf 达标且非 unknown/other），THE 系统 SHALL 将其映射为 44 currentEmotion 并驱动共情策略，同时 SHALL 始终以 max 规则保守融合风险等级。
- WHEN 一次会话结束，THE 系统 SHALL 聚合本次语音情绪并异步回注画像（provenance=voice_ser）与写入趋势表，且不得长期留存逐条原始情绪流水。
- WHEN 文本情绪为中性/正向而语音情绪为高置信负向，THE 系统 SHALL 标记情绪掩饰倾向并采用温和探询策略，SHALL NOT 当面拆穿。
- WHILE 跨会话负向趋势持续超阈值，THE 系统 SHALL 生成教师关注信号并建议量表复测，危机级情绪 SHALL 仍走实时风险管线。
- THE 系统 SHALL NOT 存储原始音频、SHALL NOT 做声纹身份识别、SHALL NOT 用情感数据做营销。
