# 23 学生心理画像设计

> 状态：新建 | 关联：06 数据库结构、13 Agent 工作流、18 Prompt 模板库、19 界面详细设计、04 风险识别规则库
> 核心：基于对话历史的结构化统计，构建**不存原始对话**的学生心理画像，实现"越聊越懂你"的个性化辅导。

---

## 0. 设计原则

| 原则 | 说明 |
|------|------|
| 只存统计，不存原文 | 画像 = 结构化指标 + 标签，禁止存储任何原始对话文本 |
| 增量演进 | 每次会话后增量更新，非全量覆盖；保留版本历史 |
| 隐私最小化 | 人物代号化、主题泛化、时间模糊化 |
| 双线并行 | 积极成长线 + 风险轨迹线同时追踪 |
| 可解释 | 教师看到的是雷达图/趋势/建议，非黑箱分数 |

## 1. 画像维度模型（6 维度 × 18 子指标）

### 1.1 情绪基线（Emotion Baseline）

| 子指标 | 类型 | 数据来源 | 更新频率 |
|--------|------|---------|---------|
| `emotion_distribution` | JSONB | 每次情绪选择 + 对话情感分析 | 每次会话 |
| `emotion_volatility` | FLOAT | 近 7 次会话情绪序列标准差 | 滚动窗口 |
| `trigger_topics` | JSONB | 会话摘要 mainTopic 聚类 | 每次会话 |

**emotion_distribution 示例：**
```json
{ "happy": 0.15, "calm": 0.30, "sad": 0.25, "anxious": 0.20, "angry": 0.10 }
```

**trigger_topics 示例：**
```json
{ "peer_conflict": 5, "academic_pressure": 3, "family": 2, "self_esteem": 1 }
```

### 1.2 沟通偏好（Communication Preference）

| 子指标 | 类型 | 数据来源 | 更新频率 |
|--------|------|---------|---------|
| `expression_depth` | FLOAT | 平均消息长度 / 轮次数 | 滚动窗口 |
| `preferred_style` | ENUM | 行动建议型 / 倾听共情型 / 混合型 | 渐进学习 |
| `active_period` | VARCHAR | 上午 / 下午 / 晚上 | 统计累积 |

### 1.3 心理韧性（Resilience）

| 子指标 | 类型 | 数据来源 | 更新频率 |
|--------|------|---------|---------|
| `recovery_speed` | FLOAT | 负面情绪后回到基线的平均会话数 | 每次会话 |
| `coping_skills` | JSONB | 已掌握的 CBT 技巧及使用次数 | 事件驱动 |
| `self_efficacy` | FLOAT | "我能/我试试"类表达频率（0-1） | 滚动窗口 |

**coping_skills 示例：**
```json
{ "deep_breathing": { "uses": 3, "effective": true }, "drawing": { "uses": 1, "effective": null } }
```

### 1.4 风险轨迹（Risk Trajectory）

| 子指标 | 类型 | 数据来源 | 更新频率 |
|--------|------|---------|---------|
| `risk_level_distribution` | JSONB | risk_events 统计 | 事件驱动 |
| `risk_trend_30d` | ENUM | rising / stable / declining | 每日计算 |
| `sensitive_topics` | JSONB | 易触发风险的话题标签 | 事件驱动 |

### 1.5 社交图谱（Social Graph）

| 子指标 | 类型 | 数据来源 | 更新频率 |
|--------|------|---------|---------|
| `key_persons` | JSONB | 会话摘要提取（代号化） | 渐进积累 |
| `social_satisfaction` | FLOAT | 人际关系正/负向表达比（-1 ~ 1） | 滚动窗口 |
| `help_seeking` | FLOAT | 求助意愿指标（0-1） | 渐进学习 |

**key_persons 示例（代号化，不存真名）：**
```json
{ "person_1": { "role": "mother", "sentiment": 0.6 }, "person_2": { "role": "classmate", "sentiment": -0.3 } }
```

### 1.6 成长轨迹（Growth Track）

| 子指标 | 类型 | 数据来源 | 更新频率 |
|--------|------|---------|---------|
| `session_frequency` | JSONB | 周/月会话频率趋势 | 每周汇总 |
| `milestones` | JSONB | 里程碑事件列表 | 事件驱动 |
| `intervention_efficacy` | JSONB | 各技巧对该生的有效率 | 每次会话 |

**milestones 示例：**
```json
[
  { "type": "first_voluntary_share", "period": "week_3" },
  { "type": "first_cbt_skill_use", "period": "week_4" }
]
```

## 2. 数据流架构

```
对话进行中
  用户消息 → 风险检测 → PII脱敏 → AI回复
                    │
                    ▼ 会话结束
会话摘要生成（TSK-001，已有）
  → mainTopic / emotionTrend / keyPoints / suggestion
                    │
                    ▼ 【新增】画像提炼
Profile Extractor
  输入：会话摘要 + 情绪序列 + 风险事件
  输出：JSON 维度增量 patch
  约束：只输出统计/标签，禁止输出原始对话内容
                    │
                    ▼
student_profiles 表（PostgreSQL JSONB）
  增量 merge，保留 version
                    │
                    ▼ 下次对话开始
System Prompt 注入画像摘要
  → AI 根据画像调整沟通策略
```

### 2.1 P0 阶段（纯 SQL 聚合，无额外 LLM 调用）

从已有数据直接聚合：
- `counseling_sessions` → 会话频率、情绪标签分布
- `risk_events` → 风险等级分布、趋势
- `message_summaries` → mainTopic 聚类

### 2.2 P1 阶段（LLM 提炼）

会话结束后异步调用 Profile Extractor Prompt：
- 从摘要中提取沟通偏好变化
- 识别技巧使用及有效性
- 更新社交图谱（代号化）

### 2.3 P2 阶段（长期积累）

- 里程碑自动检测
- 干预有效性对比分析
- 教师端画像雷达图可视化

## 3. 数据库设计

### 3.1 student_profiles 表

```sql
CREATE TABLE tenant_template.student_profiles (
    profile_id      UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    tenant_id       UUID NOT NULL,
    user_id         UUID NOT NULL,
    
    -- 6 大维度（JSONB 增量更新）
    emotion_baseline    JSONB NOT NULL DEFAULT '{}',
    communication_pref  JSONB NOT NULL DEFAULT '{}',
    resilience          JSONB NOT NULL DEFAULT '{}',
    risk_trajectory     JSONB NOT NULL DEFAULT '{}',
    social_graph        JSONB NOT NULL DEFAULT '{}',
    growth_track        JSONB NOT NULL DEFAULT '{}',
    
    -- 元数据
    version         INT NOT NULL DEFAULT 1,
    total_sessions  INT NOT NULL DEFAULT 0,
    last_updated_at TIMESTAMPTZ NOT NULL DEFAULT now(),
    created_at      TIMESTAMPTZ NOT NULL DEFAULT now(),
    
    CONSTRAINT uq_student_profile UNIQUE (tenant_id, user_id)
);

CREATE INDEX idx_profile_user ON tenant_template.student_profiles(tenant_id, user_id);
```

### 3.2 profile_snapshots 表（版本历史，可选）

```sql
CREATE TABLE tenant_template.profile_snapshots (
    snapshot_id     UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    profile_id      UUID NOT NULL REFERENCES tenant_template.student_profiles(profile_id),
    version         INT NOT NULL,
    snapshot_data   JSONB NOT NULL,  -- 完整画像快照
    created_at      TIMESTAMPTZ NOT NULL DEFAULT now()
);
```

## 4. 画像注入 Prompt 规范

### 4.1 注入位置

在 SYS-001 System Prompt 之后、gender_style 之后追加 `{{student_profile}}` 段。

### 4.2 注入格式（模板）

```markdown
# 学生画像（仅供个性化参考，严禁向学生复述任何画像内容）
- 情绪基线：{{dominant_emotion}}（近7次分布：{{emotion_summary}}）
- 高频话题：{{top_topics}}
- 沟通偏好：{{preferred_style}}
- 已掌握技巧：{{coping_skills_summary}}
- 注意事项：{{sensitive_notes}}
- 近期趋势：{{risk_trend}}
- 上次里程碑：{{last_milestone}}
```

### 4.3 注入规则

| 条件 | 行为 |
|------|------|
| 首次对话（无画像） | 不注入，使用默认通用风格 |
| 画像存在但数据 < 3 次会话 | 注入简化版（仅情绪基线 + 话题） |
| 画像完整（≥ 3 次会话） | 注入完整版 |
| 风险轨迹 = rising | 追加"请格外关注情绪变化，适当增加关怀频率" |

## 5. 隐私与安全

| 规则 | 实现 |
|------|------|
| 不存原始对话 | Profile Extractor 只输出统计指标和标签 |
| 人物代号化 | 真名 → person_N + role 标签 |
| 主题泛化 | "被张三打" → "peer_conflict-physical" |
| 时间模糊化 | 不存精确日期，存 period（week_N）或窗口统计 |
| 教师可见范围 | 雷达图 + 趋势 + 建议（不暴露 JSON 原始数据） |
| 删除权 | PIPL 第47条：学生/家长可申请清除画像 |
| 画像不跨租户 | tenant_id 隔离，转学后画像不迁移（需重新授权） |

## 6. 教师端可视化（P2）

### 6.1 画像雷达图

6 维度雷达图：情绪稳定度 / 沟通开放度 / 心理韧性 / 风险指数（反向）/ 社交满意度 / 成长动力

### 6.2 趋势折线图

- 近 30 天情绪分布变化
- 风险等级时间线
- 会话频率

### 6.3 AI 建议卡

基于画像自动生成给教师的建议：
> "该生近期情绪下行，同伴冲突话题频率上升。建议在课间关注其与同桌的互动，适当安排合作活动。对话中已引导使用'深呼吸'技巧，可在家校沟通中建议家长配合。"

## 7. 实现优先级

| 阶段 | 内容 | 工作量 | 依赖 |
|------|------|--------|------|
| **P0** | 情绪基线 + 风险轨迹 + 话题聚类（SQL 聚合） | 2-3 天 | 已有 session/risk 数据 |
| **P1** | 沟通偏好 + 技巧有效性 + 社交图谱（LLM 提炼） | 3-5 天 | Profile Extractor Prompt |
| **P2** | 成长轨迹 + 里程碑 + 教师端雷达图 | 5-7 天 | 前端可视化 |
