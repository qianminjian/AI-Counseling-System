# 15 心理知识库建设方案

> 来源：`doc/15_心理知识库建设方案.docx`（原文 660 行）
> 状态：已转换 | 关联：02 Prompt 体系、03 CBT 流程树、13 Agent 工作流（RAG）、12 技术架构（pgvector）、49 知识库建设深化
> 核心：为 AI 对话提供**经专家审核的权威心理知识**，通过 RAG 检索注入，是 Knowledge Agent 的数据底座。
> ⚠️ **实现现状（2026-07-28 核对）**：RAG 检索能力（`KnowledgeBaseService`）已完整实现，但 **对话主链路零调用（🟧），且知识内容未生产——当前是「能检索的空库」**；本篇 §2-§6 知识内容体系、§8-§10 审核工作流均未落地，已由 design/49 承接（AI-006/KB 系列）。四态对照见 §12。

## 1. 知识库定位

### 1.1 作用

为 AI 提供权威可靠的心理健康专业知识支撑，确保回复符合心理学原理和临床实践标准，提升信任度，降低生成错误/有害内容的风险。

### 1.2 与通用 LLM 的分工

| 维度 | 通用 LLM | 心理知识库 |
|------|------|------|
| 知识范围 | 广泛但浅层 | 专业且深入 |
| 信息准确性 | 可能存在错误 | 专家审核保证 |
| 时效性 | 依赖训练数据 | 定期更新机制 |
| 适用场景 | 日常对话闲聊 | 专业心理咨询 |
| 风险控制 | 难以精确控制 | 严格安全边界 |

### 1.3 管理边界

- **纳入范围**：CBT 专业知识与技术、儿童青少年发展心理学、情绪识别/表达/调节技术、放松训练与正念冥想、危机识别与干预协议、常见心理问题话术、专业术语科普。
- **排除范围**：未经循证验证的理论/技术、涉及诊断/开药的医疗内容、特定宗教或政治倾向的应用、涉及隐私的个人案例详情。

## 2. 知识库架构

### 2.1 知识分类

| 知识库 | 主要内容 | 优先级 |
|------|------|:---:|
| CBT 知识库 | 认知扭曲、自动化思维、核心信念、矫正技术、苏格拉底提问法 | P0 |
| 儿童发展心理学 | 各年龄段发展特征、常见心理问题、情绪词汇 | P0 |
| 情绪调节知识库 | 情绪识别、表达、调节技术和话术 | P0 |
| 危机干预知识库 | 风险识别、危机对话、资源转介 | P0 |
| 放松训练知识库 | 呼吸引导、正念冥想、渐进式肌肉放松 | P1 |
| 校园场景知识库 | 校园霸凌、学业压力、同伴关系 | P1 |

### 2.2 知识来源

学术文献（PubMed/PsycINFO 期刊、Cochrane 系统综述）、临床指南（APA/WHO/中国心理学会注册系统标准）、专业书籍（CBT 教材、儿童发展心理学、危机干预）、行业标准（咨询师资格、服务规范、数据安全标准）。

### 2.3 知识表示

| 类型 | 形式 | 适用场景 | 优势 |
|------|------|------|------|
| 结构化（图谱） | 三元组（实体-关系-实体） | 认知扭曲分类、情绪与行为关系、信念层级 | 支持复杂推理、关系查询 |
| 半结构化（FAQ） | 问答对 | 常见问题、术语解释、流程说明 | 易更新、检索高效、便于审核 |
| 非结构化（文章） | 长文本段落 | 放松训练脚本、技术详解、案例分析 | 内容完整、支持向量检索 |

## 3. CBT 技术知识库（P0 核心）

### 3.1 认知扭曲类型库

| 类型 | 定义 | 典型表现 |
|------|------|------|
| 非黑即白思维 | 用两个极端评价，忽视中间地带 | 要么完美要么失败 |
| 灾难化思维 | 高估负面结果可能性和严重程度 | 这太可怕了，我承受不了 |
| 读心术 | 主观认为知道别人在想什么 | 他一定觉得我很笨 |
| 心理过滤 | 只关注负面细节忽略正面 | 只记住批评忽略赞扬 |
| 否定正面思维 | 拒绝正面经历，坚持自己不够好 | 那只是运气好 |
| 情绪推理 | 认为情绪反映现实 | 我感觉焦虑，所以一定有危险 |
| 应该陈述 | 用"应该/必须"要求自己和他人 | 我应该总是表现完美 |
| 标签化 | 用负面标签定义自己或他人 | 我是个失败者 |
| 过度概括 | 基于单一事件得出总体结论 | 总是/从不等词汇 |

- **识别话术**：「你说'总是'的时候，能举一个具体例子吗？」「有没有什么时候，事情并没有像你担心的那样发展？」
- **修正技术**：证据法（列支持/反对证据）、重新归因（区分自身与情境避免过度自责）、行为实验（设计小实验验证）、认知重构（更平衡的想法替代极端思维）。

### 3.2 自动化思维库

| 情境 | 常见自动化思维 | 情绪反应 |
|------|------|------|
| 社交场景 | 别人都在评判我 | 焦虑、羞耻 |
| 工作/学习 | 我必须做到完美 | 压力、挫败 |
| 亲密关系 | 表达真实感受他们会离开 | 恐惧、孤独 |
| 自我评价 | 我不够好 | 抑郁、自卑 |

**苏格拉底提问**：澄清类（详细说说这个想法/和实际情况的联系）、证据类（支持/反对的证据）、视角类（如果是好朋友遇到你会怎么说/五年后回看的感受）。

### 3.3 核心信念库（适龄）

| 年龄段 | 常见负面核心信念 | 健康核心信念 |
|------|------|------|
| 6-8 岁 | 我不可爱、我不聪明、没人喜欢我 | 我被爱着、我能学习、我有朋友 |
| 9-12 岁 | 我不够好、我必须完美、我没价值 | 我有价值、尽力就好、我很重要 |
| 青少年 | 我不如别人、我不配成功、我无法改变 | 我独一无二、我能够成长、我值得 |

信念工作表：识别（内心怎么看待自己）→ 检验（何时形成/支持与反对证据）→ 强化（即使有此信念可做什么不同/改变后生活有何不同）。

## 4. 儿童心理知识库（P0）

### 4.1 各年龄段特征与常见问题

| 年龄段 | 发展特征要点 | 常见问题 | 预警信号 |
|------|------|------|------|
| 6-8 岁 | 具体运算思维、理解因果、注意力 15-20 分钟；同伴关系重要、在乎评价 | 分离焦虑、社交退缩、入学适应 | 过度哭闹、拒绝上学、朋友减少 |
| 9-12 岁 | 抽象思维、逻辑推理、批判性思维；自我意识增强、情绪波动、学业压力 | 学业焦虑、自我评价低、人际困难 | 成绩突然下降、回避社交、自我贬低 |

### 4.2 情绪词汇表

- **基本情绪**：开心、难过、生气、害怕、惊讶、厌恶
- **复合情绪**：焦虑、抑郁、羞耻、愧疚、嫉妒、孤独
- **复杂情绪**：失落、绝望、无助、无力、矛盾、纠结
- **强度分层示例**：难过（有点伤心/失落 → 很伤心/悲痛欲绝）、害怕（有点担心/不安 → 非常恐惧/惊恐万分）

### 4.3 家庭情境库

- **常见问题**：父母争吵/离异、亲子沟通困难、手足冲突、学业期望压力、屏幕时间冲突、家庭规则困难。
- **亲子沟通建议**：积极倾听（放下手机、复述确认）、反映情绪（"看起来你很生气"）、开放式提问（"你有什么想法/觉得可以怎么做"）；避免否定情绪、过度提问、急于给建议。

## 5. 放松训练知识库（P1，含引导语）

| 技术 | 适用年龄 | 要点 |
|------|------|------|
| 气球呼吸法 | 6-12 岁 | 吸气 4 秒、呼气 6 秒，想象吹气球，重复 3-5 次 |
| 兔子呼吸法 | 6-10 岁 | 快速嗅气 2-3 次 + 长呼一口气，重复 4-6 次 |
| 4-7-8 呼吸法 | 12 岁以上 | 吸气 4 秒 → 屏息 7 秒 → 呼气 8 秒，重复 3-4 次 |
| 身体扫描 | 10 岁以上 | 注意力从脚趾逐步上移至头部，感受各部位 |
| 五感练习（5-4-3-2-1） | 8 岁以上 | 看到 5/触摸 4/听到 3/闻到 2/尝到 1，回到当下 |
| 情绪天气 | 6-12 岁 | 情绪如天气会来会走，接纳当下天气 |
| 渐进式肌肉放松 | 通用 | 手/前臂/肩/脸/胸/腿/脚各部位「收紧-放松」交替 |

## 6. 危机干预知识库（P0）

- **风险识别关键词**：自杀（不想活了/想死/想解脱/我走了以后）、自伤（想伤害自己/疼痛让我感觉真实）、暴力（想报复/想让他消失）。
- **风险信号**：言语（直接/间接死亡意愿、谈遗书、告别）、行为（突然行为改变、睡眠食欲显著变化、送别礼物）、情绪（极度绝望、突然平静可能已决定）。

## 7. 知识库检索架构（RAG）

### 7.1 向量检索

- **Embedding 模型**：供应商无关（决策 #7）。候选：`text-embedding-3-small`(1536)/`3-large`(3072)/`m3e-base`(768，中文自托管)。维度按所选模型确定。
- **索引**：HNSW（高精度低延迟）/ IVF（大规模成本敏感）；分区策略按知识库类型/数据类型/优先级。
- **检索策略**：相似度阈值（≥0.75 高相关、0.6-0.75 中相关）、Top-K 默认 20、交叉编码器二次重排序。

### 7.2 混合检索

- **向量 + 关键词**：并行执行（向量语义相似度 + 关键词 BM25），RRF 倒数排序融合，权重向量 60% / 关键词 40%。
- **RAG 组件**：Query 理解（意图/实体/关键词）→ 知识检索（混合检索、多路召回、结果融合）→ 上下文构建（切片拼接、窗口管理）→ 生成控制（Prompt 模板、引用标注、敏感词过滤）。

## 8. 知识库更新机制

| 知识类型 | 更新频率 | 审核周期 |
|------|------|------|
| CBT 技术库 | 季度更新 | 每月抽检 |
| 儿童心理知识库 | 半年更新 | 季度抽检 |
| 危机干预知识库 | 年度更新 | 半年抽检 |
| 放松训练库 | 年度更新 | 季度抽检 |

- **更新流程**：收集 → 整理（分类/标注/结构化）→ 审核（专业咨询师）→ 测试（效果验证）→ 上线。
- **版本管理**：主版本号.次版本号.修订号（重大架构/新知识库/小幅优化），记录变更日志。
- **实时更新**：新知识接入（评估 → 快速审核 → 测试 → 灰度 → 全量）；热点问题（咨询量突增/社会热点/季节性高发，快速扩充 + 热点标签优先检索）。

## 9. 质量保证

- **专家审核**：提交 → 初审（准确性/规范性）→ 复审（资深咨询师）→ 终审（专家委员会抽查）。审核标准：准确性、完整性、适切性、安全性、可读性、一致性。周期：常规 5 工作日、加急 2 工作日、每月抽查 5%。
- **效果评估**：回答准确率（≥95%，每周抽 100 条人工评估）、用户满意度（≥4.0 分）、风险事件追踪（24 小时初步响应、72 小时完成调查、每周复盘）。

## 10. 知识库管理系统

- **后台功能**：知识录入（手动/批量 Excel-JSON/自动同步）、知识编辑（版本管理/差异对比/批量/草稿）、知识审核（提交→初审→复审→发布工作流）、知识发布（审批/灰度/回滚）。
- **运营分析**：使用统计（检索次数/无结果率/热门词/引用次数）、效果分析（准确率/满意度/风险事件率/问题解决率/留存）、优化建议（知识缺口识别/质量优化/结构优化/优先级调整）。

## 11. Java / Spring AI 落地适配（补充）

> 原文的 RAG/检索方案与技术无关，本节补充与技术栈（决策 #7/#9、12 文档 pgvector）的映射。

| 知识库要求 | Java / Spring AI 实现方案 |
|------|------|
| 向量存储与检索 | pgvector（与主库同实例，见 12 文档），Spring AI `VectorStore` 抽象接入，HNSW 索引 |
| RAG 注入 | `QuestionAnswerAdvisor` 在 Advisor 链中检索（见 02/13），仅注入经审核知识 |
| Embedding 供应商无关 | Spring AI `EmbeddingModel` 抽象，主备 Provider 可切换，维度随模型配置 |
| 混合检索 | 向量检索 + PostgreSQL 全文/关键词，Service 层 RRF 融合（向量 60%/关键词 40%） |
| 知识审核工作流 | `counseling-service` 知识管理域，状态机（草稿→初审→复审→发布），MyBatis 版本表 |
| 引用标注与防投毒 | 检索结果携带来源 ID 供审计；RAG 内容优先级永远低于系统和安全规则（见 02 §4.4） |

> **知识安全铁律**：只检索**经专家审核、状态为「已发布」**的知识条目；危机资源（热线号码）以固化常量为准，不依赖 RAG 检索结果，防止知识库投毒或过期号码污染高风险回复（呼应 14 文档）。

### 12.2 与 design/49 的分工边界（去重约定）

- **本篇（15）= 知识内容规格层**：知识分类、纳入/排除边界、适龄内容（§3-§6）、质量标准——**内容是什么**；
- **49 = 工程落地层**：内容生产流水线、审核工作流状态机、RAG 接入主链路方案（何时检索/怎么注入/降级策略）、RRF 混合检索、评估闭环——**内容怎么生产、怎么接线**。
本篇不再扩展工程方案；49 不重复定义知识内容体系。

### 12.3 首批入库语料蓝本（本篇存量价值激活）

「空库」的最快闭环不是采购外部语料，而是把本篇 §3-§6 已成型的结构化内容作为首批入库语料：
1. §3.1 九类认知扭曲 + 识别话术/修正技术 → CBT 知识库（FAQ 形式）；
2. §4.1/§4.2 年龄段特征 + 情绪词汇表 → 儿童发展心理库；
3. §5 七项放松技术含引导语 → 放松训练库（长文本）；
4. §6 危机对话话术 → 危机库（**仅供教师侧/内部参考，不进学生对话 RAG**，热线仍走固化常量）。
入库前提：审核状态字段落地（铁律支撑）+ 心理专业背景人员抽审（责任人：钱敏健确认审核人选，列入待确认清单）。
