## 2. 商业模式与采购逻辑（09）

### 2.1 市场背景

- 2024 年中国 K12 教育市场约 5.2 万亿元，校园心理健康服务快速增长
- 政策驱动：2019《儿童青少年心理健康行动方案》→ 2023《全面加强和改进新时代学生心理健康工作专项行动计划》→ 2024《学生心理健康工作体系建设三年行动计划》
- 现状痛点：专职心理教师约 3 万名严重不足、筛查效率低、预警机制缺失、家校协同困难

### 2.2 SaaS 订阅模式

- **计费维度**：按学校或按学生（教育局集采），建议「基础学生数 + 超出按量计费」
- **付费周期**：主推年费制（8-9 折），季度付为辅
- **分层定价**：基础版 99 元/生/年（筛查+报告）、专业版 159 元/生/年（+AI 对话+危机预警+家校互通）、旗舰版 259 元/生/年（+区域看板+API+专属实施）
- ⚠️ **实态对齐**：量表施测未实现（SCALE 门禁），**基础版承诺不成立——销售物料不得先行对外承诺筛查能力**；已实现的反而是专业版能力（AI 对话/预警/家校互通全落地）

### 2.3 采购决策链与触发点

| 角色 | 关注点 | 影响策略 |
|------|--------|---------|
| 决策者（校长/教育局） | 政策合规、舆论风险、投入产出 | 政策解读、案例背书、风险兜底 |
| 影响者（心理老师/班主任） | 功能实用、工作量降低 | 产品培训、操作演示 |
| 使用者（学生） | 体验流畅、隐私保护 | 趣味设计、正向反馈 |
| 评估者（家委会） | 安全性、效果可见 | 透明报告、家长开放日 |

触发点：政策要求达标验收、心理危机事件驱动、指标考核（筛查率/预警准确率）、竞品对比替换。

### 2.4 销售策略

- **标杆学校**：2-3 所试点 → 深度共创 → 效果验证 → 案例包装 → 区域辐射
- **教育局集采**：以「筛查覆盖率」考核切入 → 区县试点 → 现场会触达决策层 → 纳入年度采购
- **渠道合作**：本地代理商（20-30% 利润）、智慧校园集成商、测评机构战略合作
- **试用转化**：14-30 天全功能试用 → 转化锚点 = **学生活跃度 + 预警处置闭环演示**（量表未落地前不使用"完成测评"作锚点）

### 2.5 合同条款要点

- 数据归属：学校/教育局拥有学生数据所有权；约定存储地点/期限/销毁方式；终止支持导出
- SLA：基础 99.5%/专业 99.7%/旗舰 99.9%；响应时间普通 4h、紧急 1h、危机 15min；可用性每降 0.1% 补偿 1 天
- 保密：终止后不少于 3 年；对外案例需脱敏并授权
- 退出：提前 60 天书面通知；终止后 30 天内完成数据交接

### 2.6 客户成功与续费

实施交付六步（启动→数据准备→配置→培训→2 周试运行→上线）；教师培训（新手 2h 视频 + 手册、月度答疑、危机干预专项）；续费激励（60 天前 9 折、连 3 年 8.5 折）。

### 2.7 三年财务预测（简表）

核心假设：客户 50/150/350 所、客单价 120/135/145 元/生、均校 1000 生、续费率 80%/85%、毛利率 65%。

| 项目 | 第 1 年 | 第 2 年 | 第 3 年 |
|------|---:|---:|---:|
| 活跃学生数（万） | 5 | 20 | 55 |
| 年度总收入（万元） | 600 | 2,700 | 7,975 |
| 净利润（万元） | -410 | 155 | 2,384 |

关键指标：CAC < 5,000 元/校、LTV > 30,000 元/校、LTV/CAC > 3、续费率 > 80%、NPS > 50。

### 2.8 计费与成本治理

- entitlement 三层模块开关（基础=筛查+报告 / 专业=+AI+预警+家校 / 旗舰=+区域看板+API）落租户配置，不落代码分支（BIZ 系列 P3）
- 按租户用量计量（活跃学生/LLM 调用量）当前仅 API 级限流，无计量汇总（BIZ 系列 P3）
- LLM 成本（预估 15-20 元/生/年）待上线后用 `model_call_logs` 聚合真实单生成本回补

## 3. 竞品格局与差异化（11）

### 3.1 竞品分类

校园心理平台（心理云平台 10000+ 校、壹点灵 5000+ 校）、AI 心理应用（Wysa/Woebot/察言观色）、心理咨询平台（简单心理/壹心理）、儿童教育类心理模块。

### 3.2 对标要点（截至 2026-07 认知，商用前需实时复核）

- **Woebot**：2025 中停运面向消费者独立 App，转 B2B2C 嵌入医疗机构/保险体系；其「固定话术库 + 状态机」安全可控性仍是儿童场景重要参照
- **Wysa**：持续运营，LLM 混合架构（生成式回应 + 规则安全围栏），获 FDA 突破性设备认定（青少年焦虑）；其 SOS 危机通道 + 本地热线配置与我们同构
- **国内校园 SaaS**：仍以量表 + 档案为核心；头部厂商开始套壳国产大模型做"AI 心理助手"，普遍无儿童安全规范、无风险融合
- **市场空白**：国内外竞品最低年龄 13+，**6-12 岁 AI 心理陪伴是真空带**——已落地的小学段即差异化落点

### 3.3 差异化三支柱（对外口径）

1. **年龄适配深度**：effectiveGrade 分龄话术 / 波波品牌 / 全感官交互
2. **家校闭环**：家长 H5 周报 + 同意管理 + 教师预警工作台（竞品均无完整三方闭环）
3. **儿童安全工程化**：安全规范 + 四级风险融合（文本+语音情绪）+ 硬短路设计——可审计的安全体系而非喷涂层

### 3.4 对外物料纪律（已定稿）

- **竞品对比表仅限内部使用，不对外发放**（含售前物料/答辩材料），避免不正当竞争与虚假宣称风险
- 对外仅使用差异化三支柱正面表述
- 实态能力宣称校准：AI 对话 🟩、危机预警闭环 🟩、情绪识别双通道 🟩（文本+语音，竞品无）、心理测评 ⬜（**对外禁用测评能力宣称**）、大模型应用 = **prompt 工程 + RAG**（非"微调"，表述已修正）
- 真实壁垒 = 合规框架内的儿童安全工程体系（规则库 + 审计 + 门禁流程），非"中文心理对话数据"（受合规约束不留原文，不构成数据壁垒主张）

## 4. 法规与合规框架（10）

### 4.1 核心法规要点

| 法规 | 对本系统的硬要求 |
|------|----------------|
| 《未成年人保护法》（2021.6.1） | 网络保护专章、强制报告制度（发现疑似侵害立即报告）、实名认证、时间限制、内容分级 |
| 《个人信息保护法》 | **14 岁以下信息属敏感个人信息，须监护人单独同意**（非一揽子授权，留痕可追溯）；数据最小化；删除权响应 ≤15 工作日；撤回同意可删 |
| 《数据安全法》 | 分类分级；重要数据出境须安全评估；定期风险评估 |
| 《家庭教育促进法》 | 家长查询渠道、经同意推送使用报告、重大事项及时通知 |
| 《精神卫生法》 | **服务边界：不得涉及精神疾病诊断和治疗、不得开药**；超范围提示转介；危机识别 → 热线（400-161-9995）→ 紧急转介 |

### 4.2 行业监管要求

- **教育 App 备案**：材料含基本信息/ICP/等保证明/隐私政策/未成年人保护方案；周期 30-60 工作日，提前 3-6 个月启动
- **网信办算法备案**：不得大数据杀熟、须提供关闭算法推荐选项、人工干预机制；每年 3.31 前提交安全评估报告
- **等级保护（二级）**：定级 → 备案 → 建设整改 → 等级测评 → 监督检查
- **生成式 AI 服务管理暂行办法（2023.8.15）**：见 §6.2 备案路径定稿

### 4.3 未成年人专项保护

时间管理（禁用时段/每日上限/实名认证/强制下线）、内容过滤（敏感词实时过滤/12 岁以下更严/举报机制）、家长监护（账号绑定/使用报告/异常提醒/远程退出）。

### 4.4 伦理规范

心理辅导伦理：知情同意（性质/范围/局限，未成年需监护人同意，可随时终止）、保密例外（伤害自己/他人、法律要求、事先告知）、避免双重关系。
AI 伦理：透明性（明确告知在与 AI 交互）、可解释性（可申诉纠错）、人类监督（人工渠道畅通、定期人工审核交互记录）。

### 4.5 合规风险清单

| 等级 | 风险项 |
|------|--------|
| 高 | 未成年人信息泄露；未经同意收集敏感信息；内容引发心理伤害；违规开展心理治疗 |
| 中 | 未完成 App/算法备案；等保测评缺失；家长监护功能不完善 |
| 低 | 隐私政策滞后；客服响应不及时 |

## 5. 合规硬约束 → 技术实现映射（落地现状）

> 合规不是文档，是代码里的强制项。合规判断、监管报告签署、生产发布审批属监管责任事项，AI 只提供信息不代替人决策（AGENTS.md §5.7）。

| 合规要求 | 落地实现 | 现状 |
|---------|---------|:---:|
| 14 岁以下单独同意 | `GuardianConsentService`（PIPL §31 短信验证码闭环）+ `ConsentRecord` 版本化独立存表 + 前端 ConsentGate | 🟩 |
| 数据最小化 | 数据模型评审禁采集无关字段；对话不索要真实姓名/地址/精确位置 | 🟩 |
| 删除权 ≤15 工作日 | 账号注销 + 数据删除/匿名化接口；保留期定时清理（普通 180 天/高风险 365 天）——**到期自动清理定时任务与 ≤15 工作日响应链路待验证** | 🟫 |
| 不做诊断/开药 | Prompt 层约束（SAF 模板）已生效；输出侧拦截（Layer2 语义审查）仅留痕不改写 | 🟫 |
| 危机热线固定输出 | 热线硬编码常量（12355/400-161-9995）；RED 硬短路（危机不交 LLM）已实现（SAFE-203/RISK-201） | 🟩 |
| 明确告知在与 AI 交互 | 首次会话 AI 身份说明；儿童化保密边界告知话术（SAFE-201） | 🟩 |
| 强制报告 | RED 事件 → 教师预警推送（WebSocket <3s）；AI 只触发流程不做合规判断 | 🟩 |
| 时间/防沉迷 | 会话时长限制（每日 30 分钟）在 ConversationServiceImpl 生效 | 🟩 |
| 家长监护 | parent-h5 周报/同意管理已实现；时长上限/功能限制/远程退出等完整监护能力 ⬜ | 🟫 |
| 数据加密与等保 | FieldEncryptionService（AES-256-GCM 服务层）覆盖 message_summaries/teacher_notes；student_profiles/long_term_memories 待加密 | 🟫 |

### 6.2 法律审核意见要点

- **🔴 高风险**：非医疗声明须门控页单独突出展示（不可埋长文）；责任限制措辞合规保持；收集敏感信息须单独同意弹窗
- **🟡 中风险**：生成式 AI 备案/安全评估适用性须法务确认（上线硬门槛）；危机预警通知须最小必要；未成年人须专门儿童信息处理规则
- **🟢 低风险**：管辖约定加粗（已✅）；对话界面标注"内容由 AI 生成"（待核对）

### 6.3 条款缺口处理（已定稿）

1. **量表测评同意项**：测评结果属敏感个人信息（PIPL §28），须**单独同意**不能概括覆盖——SCALE-002 上线门禁的一部分，施测接线时同步法务审定
2. **语音数据处理表述（选项 A 如实区分披露，2026-07-28 定稿）**：
   - ① 唤醒词检测在设备本地完成；
   - ② 语音转文字/情感分析加密上传境内服务器，**转写与特征提取完成后立即删除原始音频**（转写即删，COMP-009 已全链路落地：mkstemp 安全 API + finally 必删 + 删除日志留痕 + Java 侧 12MB 阈值 + 日志只记长度不记内容）；
   - ③ TTS 降级场景可能使用境外第三方服务（edge-tts），如实披露（替换境内服务后回调表述）

### 6.4 落地流程

草稿起草（AI，已完成）→ 法务终审（钱敏健+执业律师）→ 补齐主体信息（第十条）→ 确认备案适用性 → 门控页实现（ConsentGate 已完成 🟩）→ 同意留痕（consent_records 版本化 🟩）。
