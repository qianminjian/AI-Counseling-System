## 2. 外部模型依赖清单与降级链路

### 2.1 模型清单（9 个）

| # | 模型 | 用途 | 调用方式 | 部署位置 | 故障影响 |
|---|------|------|---------|---------|----------|
| 1 | DeepSeek V4 Flash | 主 LLM | REST API | 云端 | 自动降级 qwen-plus |
| 2 | 通义千问 qwen-plus | 备用 LLM | REST API（百炼） | 云端 | 对话不可用 |
| 3 | CosyVoice v3 Flash | TTS 主力 | DashScope SDK WebSocket | 云端 | 降级 edge-tts |
| 4 | edge-tts（微软） | TTS 二级降级 | Python edge-tts | 云端（免费） | 降级浏览器合成 |
| 5 | Paraformer-V2 | ASR 主力 | DashScope SDK | 云端 | 降级 FunASR 本地 |
| 6 | SenseVoiceSmall（FunASR） | ASR 本地备用 | FunASR 本地推理 | 服务器容器内 | ASR 不可用 |
| 7 | emotion2vec_plus_large | 语音情感（SER） | FunASR 本地推理（CPU） | 服务器容器内 | 情感降级 neutral，不影响 ASR |
| 8 | Whisper Tiny | 前端语音唤醒 | ONNX WASM 浏览器端 | 自托管 /mindsafe/models/ | 唤醒功能禁用 |
| 9 | WeSpeaker ResNet34 | 前端声纹 | ONNX WASM 浏览器端 | 自托管 /mindsafe/models/ | 声纹登录禁用，PIN 不受影响 |

> 语音情感分析（SER）是辅助信息，不是核心风控依赖——核心风险检测基于纯文本规则，SER 完全不可用也不影响安全功能。

### 2.2 语音服务（ASR/SER 解耦）配置与模型加载

```
ASR_ENGINE = funasr | dashscope    ← 控制语音识别引擎
SER_ENABLED = true | false          ← 独立控制情感分析（与 ASR 无关）
音频输入 → ffmpeg 转 16kHz WAV → ASR + SER 并行执行（ThreadPoolExecutor）→ 合并结果
```

| 条件 | 行为 |
|------|------|
| SER_ENABLED=true | 加载 emotion2vec_plus_large（无论 ASR_ENGINE） |
| SER_ENABLED=false | 不加载，情感始终 neutral |
| SER 模型加载失败 | 降级 neutral，不影响 ASR，日志警告 |
| ASR=dashscope + SER=on | 仅加载 emotion2vec（~1.5GB），不加载 SenseVoice |
| ASR=funasr + SER=on | 加载 SenseVoice + emotion2vec（~4GB） |

emotion2vec 输出 9 类情绪：angry/disgusted/fearful/happy/neutral（默认）/other/sad/surprised/unknown，含置信度（0~1）+ 9 类得分向量。

**部署依赖**：容器 mindsafe-voice（端口 10095）；镜像 ~2GB；模型不打入镜像（volume 挂载 `/root/.cache/modelscope`）；首次部署前运行 `bash deploy/scripts/prepare-funasr.sh`；emotion2vec ~300MB、SenseVoice ~1GB；SER 模型加载 30-60s；转写即删（不保留原始音频）。

**降级链路**：
```
voice-service 正常 → ASR文字 + 情绪标签 + 置信度
voice-service 不可达 → Java 降级 emotion=unknown
Java 也异常 → 前端 Web Speech API 转写 + 无情绪提交
→ 核心风控不受影响（纯文本规则始终工作）
```

### 2.3 模型测试关注点

| 层级 | 关注点 |
|------|--------|
| 云端 API | Key 配额/限流/网络超时；CosyVoice 必须用 v3-flash（**v3.5-flash 不支持系统音色，切勿误用**） |
| 服务器本地 | SER 模型加载时间（首次 30-60s）；内存占用；模型文件是否下载到宿主机 |
| 浏览器端 | 首次下载耗时；设备兼容性（WASM SIMD + SharedArrayBuffer）；iOS Safari 16.4+ |
| 降级链路 | 每级降级是否无感；降级后功能损失是否可接受 |

## 10. 关键测试场景

### 10.1 端到端风险闭环

```
学生输入高危内容 → 风险识别（10 类信号）→ AI 切换危机模式
→ 教师端 WebSocket 实时预警 → 教师认领 → 线下干预
→ 标记解决 → 安排回访 → 完成回访 → 闭环
```

验证要点：预警触发到教师端展示 < 3 秒；等级正确（红/橙/黄）；状态流转正确；审计日志完整。

### 10.2 多租户隔离

学校 A/B 管理员各自只见本校数据；跨租户 API → 403/404。

### 10.3 认证安全

Token 过期自动 refresh 无感续期；登出拉黑后 401；并发 refresh 旧 token 拉黑防重放；PIN 5 次锁定 15 分钟。

### 10.4 AI 对话质量

不同年级/性别差异明显；画像注入（AI 记住偏好/已掌握技巧）；冷场决策（话多偏留白、沉默偏暖场）。

### 10.5 家长端隐私

家长只能看统计（无对话原文）；撤回同意冻结 + 画像删除（不可逆）；Token 7 天过期。
