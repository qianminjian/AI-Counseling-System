## 关键设计决策摘要

### 产品定位
- **一句话定位**：面向小学生与学校心理老师的"低门槛表达 + 早期筛查 + 标准化辅导流程 + 风险预警 + 人工转介闭环"系统
- **AI 角色**：情绪陪伴助手、流程引导助手、风险筛查助手、报告摘要助手、知识检索助手
- **明确不做**：医学诊断、治疗承诺、药物建议、无人工介入的危机处置

### 技术栈（2026-07-23 定案）
- **后端**：Java 21（LTS）+ Spring Boot 3 + Spring AI（模块化单体，Maven 多模块）
- **AI 编排**：Spring AI（ChatClient + Advisor 链 + 状态机）替代原 LangGraph 设计
- **数据库**：PostgreSQL 16 + pgvector（Schema 级多租户隔离 `tenant_{id}`）
- **缓存**：Redis 7
- **前端**：React 18 + TypeScript + Vite + Tailwind CSS
- **部署**：Docker Compose（私有化 All-in-One）/ Helm（集群）
- **明确排除（YAGNI）**：K8s、Kafka、微服务拆分、API 网关、ELK、Milvus、语音/生物识别

### 多租户与隔离
- **Schema 级隔离**：每个学校一个独立 Schema `tenant_{tenant_id}`
- **权限模型**：RBAC + ABAC，心理老师/班主任/管理员权限分离
- **数据原则**：默认最小化采集、摘要优先、敏感内容脱敏展示

### 风险分级与处置
| 等级 | 典型信号 | AI 允许动作 | SLA |
|------|----------|-------------|-----|
| 绿色 | 短期压力、一般情绪 | 共情、轻度 CBT、小行动建议 | 无强制 |
| 黄色 | 持续负面情绪、失眠 | 有限对话、建议寻求老师支持 | 1-3 工作日 |
| 橙色 | 疑似自伤念头、被欺凌 | 停止深挖、安全稳定话术、触发预警 | 当日 2 小时内 |
| 红色 | 明确自杀计划、正在实施 | 安全话术 + 静默通知老师 + 线下危机流程 | 分钟级响应 |

### Agent 协同（7 Agent）
1. **Safety Agent**：底线安全检测（自伤、自杀、暴力、虐待）
2. **Emotion Agent**：情绪识别（类别、强度、趋势）
3. **CBT Agent**：认知行为干预（情境-想法-情绪-证据-替代想法-行动）
4. **Conversation Agent**：儿童友好对话
5. **Escalation Agent**：高风险升级（通知老师、线下处置、转介）
6. **Report Agent**：教师摘要、报告生成
7. **Memory Agent**：长期趋势、上下文摘要

### MVP 范围（M1，1-2 个月）
- **学生端**：登录、情绪选择（5 种）、文本对话、CBT 引导、风险预警触发
- **教师端**：预警通知接收、高风险学生列表、简单档案查看
- **技术边界**：仅 Web 端（H5 适配平板）、仅文本交互、国产 LLM API、数据存国内云
- **性能要求**：AI 首字 <3s、API <500ms、可用性 >99.5%

## 演进路线

| 阶段 | 时间 | 核心目标 | 关键功能 |
|------|------|----------|----------|
| **MVP（M1-M2）** | 1-4 月 | 验证核心闭环 | 文本对话、风险识别、教师工作台、预警通知 |
| **二期（M3）** | 5-6 月 | 能力增强 | 语音/TTS、放松训练、成长档案、测评量表 |
| **三期（M4+）** | 远期 | 生态扩展 | 多模态、机器人、家校协同、私有化部署 |
