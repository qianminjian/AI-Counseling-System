## 关键设计决策摘要

### 产品定位
- **一句话定位**：面向小学生与学校心理老师的"低门槛表达 + 早期筛查 + 标准化辅导流程 + 风险预警 + 人工转介闭环"系统
- **AI 角色**：情绪陪伴助手、流程引导助手、风险筛查助手、报告摘要助手、知识检索助手
- **明确不做**：医学诊断、治疗承诺、药物建议、无人工介入的危机处置

### 技术栈（实现期修正）
- **后端**：Java 21（LTS）+ Spring Boot 3.4 + Spring AI 1.0（模块化单体，Maven 7 模块）
- **AI 编排**：Spring AI（ChatClient + Advisor 链 + 状态机）替代原 LangGraph 设计
- **LLM**：DeepSeek（deepseek-v4-flash/pro，已接入验证）
- **数据库**：PostgreSQL 16（Schema 级多租户隔离 `tenant_template`）
- **前端学生端**：React 19 + JavaScript + Vite 8 + Tailwind CSS + PWA
- **前端教师端**：React 19 + JavaScript + Vite 8 + Ant Design 6
- **部署**：Docker Compose（PostgreSQL + Spring Boot + Nginx 一键启动）
- **语音**：语音输入（Web Audio API）+ TTS 播报（已实现）
- **监控**：Prometheus + Grafana（已配置）

### 多租户与隔离
- **Schema 级隔离**：当前实现为 `tenant_template` 共享 Schema（MVP 简化），生产环境可升级为每校独立 Schema
- **权限模型**：JWT + RBAC，心理老师/班主任/管理员/平台管理员权限分离
- **数据原则**：默认最小化采集、摘要优先、敏感内容脱敏展示

### 风险分级与处置
| 等级 | 典型信号 | AI 允许动作 | SLA |
|------|----------|-------------|-----|
| 绿色 | 短期压力、一般情绪 | 共情、轻度 CBT、小行动建议 | 无强制 |
| 黄色 | 持续负面情绪、失眠 | 有限对话、建议寻求老师支持 | 1-3 工作日 |
| 橙色 | 疑似自伤念头、被欺凌 | 停止深挖、安全稳定话术、触发预警 | 当日 2 小时内 |
| 红色 | 明确自杀计划、正在实施 | 安全话术 + 静默通知老师 + 线下危机流程 | 分钟级响应 |

### Agent 协同（7 Agent）
1. **Safety Agent**：底线安全检测（自伤、自杀、暴力、虐待）
2. **Emotion Agent**：情绪识别（类别、强度、趋势）
3. **CBT Agent**：认知行为干预（情境-想法-情绪-证据-替代想法-行动）
4. **Conversation Agent**：儿童友好对话
5. **Escalation Agent**：高风险升级（通知老师、线下处置、转介）
6. **Report Agent**：教师摘要、报告生成
7. **Memory Agent**：长期趋势、上下文摘要

### MVP 范围（已全部实现）
- **学生端**：登录、情绪选择（5 种）、文本对话、CBT 引导、风险预警触发、语音输入、TTS 播报、放松练习、情绪日记、成就徽章、PWA 离线
- **教师端**：预警通知接收、高风险学生列表、学生档案 + AI 摘要、质量监控、平台总览、数据大屏、暗色模式、新手引导、话术模板
- **商业化**：企微 OAuth、会话导出 PDF、批量导入、满意度分析、家长 H5 报告、周报导出
- **技术边界**：Web 端（H5 适配平板/手机）、文本 + 语音交互、DeepSeek API、Docker Compose 部署
