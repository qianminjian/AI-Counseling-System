## 三、关键设计决策摘要

### 产品定位
- **一句话定位**：面向小学生与学校心理老师的"低门槛表达 + 早期筛查 + 标准化辅导流程 + 风险预警 + 人工转介闭环"系统（详见 01）
- **AI 角色**：情绪陪伴助手、流程引导助手、风险筛查助手、报告摘要助手、知识检索助手
- **明确不做**：医学诊断、治疗承诺、药物建议、无人工介入的危机处置
- **对外物料口径底线**：全线禁用"诊断/治疗/心理咨询"表述，统一"心理辅导/情绪支持"

### 技术栈（实现期定稿，详见 03）
- **后端**：Java 21（LTS）+ Spring Boot 3.5.12 + Spring AI 1.0（模块化单体，Maven 6 模块）
- **AI 编排**：Spring AI（ChatClient + Advisor 链 + 状态机）替代原 LangGraph 设计
- **LLM**：DeepSeek（deepseek-v4-flash/pro，已接入验证）
- **数据库**：PostgreSQL 16 + pgvector（共享表 + 行级 tenant_id 隔离定稿）
- **前端三端**：React 19 + Vite + Tailwind CSS（学生端）/ Ant Design（教师端）/ SCSS（家长端）
- **部署**：Docker Compose（PostgreSQL + Spring Boot + Nginx），阿里云 ECS 经济型 e 实例
- **语音**：语音输入（Web Audio API）+ TTS 播报 + 语音情感分析（SenseVoiceSmall）
- **监控**：Prometheus + Grafana（已配置）

### 风险分级与处置（详见 09 §五）
| 等级 | 典型信号 | AI 允许动作 | SLA |
|------|----------|-------------|-----|
| 绿色 | 短期压力、一般情绪 | 共情、轻度 CBT、小行动建议 | 无强制 |
| 黄色 | 持续负面情绪、失眠 | 有限对话、建议寻求老师支持 | 1-3 工作日 |
| 橙色 | 疑似自伤念头、被欺凌 | 停止深挖、安全稳定话术、触发预警 | 当日 2 小时内 |
| 红色 | 明确自杀计划、正在实施 | 安全话术 + 静默通知老师 + 线下危机流程 | 分钟级响应 |

### Agent 协同（世界 A 单 prompt + CTX-Agent 4 段式简报，详见 03 §4）
原 7-Agent 星型编排（世界 B）已于 2026-07-29 整体删除（DEC-CBT，03 §4 定稿，AUD-038 校正）；线上唯一生效架构：`ConversationServiceImpl` + `PromptOrchestrationService` 单 prompt 主线（SSE 流式）+ CTX-Agent 4 段式上下文简报（身份/情绪/会话/画像，零 LLM 调用，落地于 `ConversationContextAgent.java`）

### 数据原则
- 默认最小化采集、摘要优先、敏感内容脱敏展示（详情见 02 §1/§7）
- 会话默认只保存结构化摘要与风险信号，不保存完整原始对话与语音/生物识别数据
- 高敏表字段级加密 + 行级隔离 + 访问审计 + 到期清理
