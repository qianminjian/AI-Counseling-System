> 产品地址：https://yun.gxjugu.com/mindsafe/（学生端）| https://yun.gxjugu.com/teacher/（教师端）| /parent/（家长端）

## 一、系统概述

MindSafe 是面向小学的 AI 心理辅导 SaaS 系统，包含三端一屏：

| 端 | 技术栈 | 访问方式 |
|---|---|---|
| 学生端 H5 | React 19 + Tailwind + PWA | 手机/平板浏览器 |
| 教师端 Web | React 19 + Ant Design 6 | 电脑浏览器 |
| 家长端 H5 | React + Vite | 手机浏览器（链接访问） |
| 数据大屏 | React（教师端 /bigscreen 路由） | 全屏展示 |

后端：Java 21 + Spring Boot 3.4 + Spring AI + PostgreSQL 16 + Redis + Maven 多模块（7 模块）
AI 引擎：DeepSeek V4 大模型（主，关闭思考模式低延迟）+ 通义/GLM（备）
语音服务：voice-service（ASR 双引擎：DashScope Paraformer-V2 云端 / FunASR 本地可选）+ tts-service（三级降级 TTS）
TTS 架构（v3）：Level 1 阿里云 CosyVoice（DashScope SDK WebSocket 流式，首包 <800ms）→ Level 2 edge-tts（微软）→ Level 3 浏览器 speechSynthesis

### 3.3 AI 心理对话（核心）

| 测试点 | 操作步骤 | 预期结果 |
|---|---|---|
| 创建会话 | 选择情绪（开心/平静/难过/生气/害怕/紧张）→ 开始 | 创建成功，AI 发出开场白（含学生昵称） |
| 流式回复 | 发送文字消息 | SSE 逐字输出，体验流畅 |
| CBT 流程 | 多轮对话 | AI 按"情境→感受→想法→行动"引导，非自由闲聊 |
| 语音输入 | 按住波波说话 → 松开 | 录音 → ASR 转文字 → 自动发送 |
| 语音情感 | 用不同语调说话 | 返回情绪标签 + 置信度，辅助 AI 判断 |
| TTS 朗读 | AI 回复完成后 | 自动/手动朗读，波波头顶冒「水泡」话语气泡（逐句同步，吹泡入场动画） |
| TTS 等待反馈 | AI 回复合成中（首包未到） | 水泡内显示三颗主题色跳动圆点（非空白） |
| TTS 降级 | 后端 TTS 不可用 | 自动降级 edge-tts → 浏览器 speechSynthesis，用户无感 |
| 音色切换 | 设置中选择不同音色 | TTS 使用对应音色（小星星/小太阳等） |
| 性别差异 | 男生/女生分别对话 | 男生：阳光简短；女生：温柔细腻 |
| 年龄适配 | 1 年级 vs 6 年级学生 | 语言复杂度、比喻库、互动模式明显不同 |
| 冷场暖场 | 对话中沉默 30s+ | 决策模型判断：留白（不打扰）或暖场（AI 主动说话） |
| 暖场次数限制 | 连续沉默 | 最多 2 次暖场，之后不再主动打扰 |
| 历史列表已取消 | 进入情绪选择页 | 不再展示历史会话入口（共享 Pad 隐私保护） |
| 结束+评价 | 结束会话 | 弹出满意度评价（😊/😐/😢），底部有「再聊一会儿」可返回聊天 |
| 使用时长限制 | 每日累计 30 分钟 | 达到上限后提示休息 |
| 无操作超时 | 登录后放置 5 分钟不操作 | 弹出"你还在吗？"60 秒倒计时卡片 |
| 超时续期 | 倒计时中点「我还在！」 | 卡片消失，继续使用 |
| 超时退出 | 倒计时结束不操作 | 自动退出回登录页（sessionStorage 清除） |
| 切换同学入口 | 打开设置面板 | 底部"换人使用"区块可见（红色调） |
| 切换同学确认 | 点击"换人使用" | 弹出退出确认，确认后回登录页，取消则留在原页 |
| 注册二次确认 | 填写注册表单 → 提交 | 弹出信息摘要确认卡（昵称/性别/年龄/家长手机），确认才真正注册 |
| 删声纹确认 | 设置中点删除声音钥匙 | 弹出确认弹窗，确认才删除 |
| 情绪适配开场（编排） | 以不同情绪入场（难过/生气/焦虑） | AI 开场与回应策略随情绪适配（共情/中立命名/接地呼吸） |
| 情绪镜映 | 表达强烈情绪 | AI 先镜映共情，激活/危机状态下不立即做认知重构 |
| 情绪状态漂移 | 多轮对话从难过到平复 | 情绪状态机流转（sad→crisis 升级 / anxious→calm 缓解），策略同步切换 |

## 九、关键测试场景

### 9.1 端到端风险闭环

```
学生输入高危内容 → 风险识别（10 类信号）→ AI 切换危机模式
→ 教师端 WebSocket 实时预警 → 教师认领 → 线下干预
→ 标记解决 → 安排回访 → 完成回访 → 闭环
```

验证要点：
- 预警从触发到教师端展示 < 3 秒
- 预警等级正确（红/橙/黄）
- 处理流程状态流转正确
- 审计日志完整记录每一步

### 9.2 多租户隔离

```
学校 A 管理员登录 → 只能看到 A 的学生/预警/数据
学校 B 管理员登录 → 只能看到 B 的数据
跨租户 API 调用 → 返回 403/404
```

### 9.3 认证安全

```
Token 过期 → 自动 refresh → 无感续期
Token 被拉黑（登出后）→ 再使用 → 401
并发 refresh → 旧 token 拉黑防重放
PIN 暴力破解 → 5 次锁定 15 分钟
```

### 9.4 AI 对话质量

```
不同年级 → 语言复杂度差异明显
不同性别 → 沟通风格差异
画像注入 → AI 记住学生偏好/已掌握技巧
冷场决策 → 话多的孩子偏留白、沉默的偏暖场
```

### 9.5 家长端隐私

```
家长只能看统计 → 不能看对话原文
撤回同意 → 学生账号冻结 + 画像删除（不可逆）
Token 7 天过期 → 需重新验证
```

## 十一、已知限制与注意事项

1. 声纹登录已完整实现：本地采集+比对（Phase 1）+ 后端设备凭证换 token（Phase 2，`/auth/voice-credential` 签发 90 天凭证、`/auth/voice-login` 换正式双 token）；登录页为「🎤 声音进入」按钮显式触发，无被动监听
2. 语音唤醒基于浏览器 Web Speech API / Whisper WASM，iOS Safari 需 16.4+，部分安卓浏览器兼容性有限
3. 唤醒词为"哈喽波波"（主）+"你好波波"（兼容变体），通过滑窗转写匹配
4. 企微 OAuth 代码已就绪，需学校配置 corpId/secret 后才可用
5. 阿里云 SMS 签名/模板待申请，当前 SMS_PROVIDER=logging（仅日志）
6. 语音服务（voice-service/tts-service）当前使用 DashScope 云端 API（ASR: Paraformer-V2，TTS: CosyVoice），无需 GPU；FunASR 本地模式为信创/私有化备选（需 6GB 内存 + CPU 推理，延迟 15-30s）
