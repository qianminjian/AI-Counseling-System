## 一、安全通信网络

| 要求项 | 当前状态 | 差距 | 整改建议 | 优先级 |
|--------|---------|------|---------|--------|
| 通信传输加密 | ✅ HTTPS（nginx SSL 证书） | 无 | - | - |
| 可信验证 | ⚠️ 证书存在但无自动续期 | 证书过期风险 | 接入 Let's Encrypt 自动续期或云证书服务 | P1 |
| 网络架构安全 | ❌ 单服务器，无网络分区 | 无 DMZ/内外网分离 | 云安全组限制端口暴露（仅 80/443 对外） | P0 |
| 通信完整性 | ✅ TLS 1.2+ | 无 | - | - |

## 二、安全区域边界

| 要求项 | 当前状态 | 差距 | 整改建议 | 优先级 |
|--------|---------|------|---------|--------|
| 边界防护 | ✅ 云安全组 + nginx 反代 | 无 WAF | 接入云 WAF（阿里云/天翼云） | P1 |
| 访问控制 | ⚠️ 安全组规则未审计 | 可能开放多余端口 | 审计安全组，仅保留 80/443/22（限 IP） | P0 |
| 入侵防范 | ❌ 无 IDS/IPS | 无异常流量检测 | 云主机安全 Agent（天翼云/阿里云安骑士） | P1 |
| 恶意代码防范 | ❌ 无防病毒 | 服务器无 AV | 云安全 Agent 覆盖 | P2 |
| 安全审计 | ✅ nginx access.log | 无集中日志分析 | 接入日志服务（Sprint B OPS-003） | P1 |

| 要求项 | 当前状态 | 差距 | 整改建议 | 优先级 |
|--------|---------|------|---------|--------|
| 身份鉴别 | ✅ JWT + RBAC + 登录锁定 + PIN | 无 | - | - |

| 安全审计（操作） | ❌ 无管理员操作审计日志 | 敏感操作无留痕 | COMP-006：审计日志 AOP 切面 | P0 |

| 可信验证 | ❌ 无 | 等保二级可选 | 暂不实施 | P3 |
