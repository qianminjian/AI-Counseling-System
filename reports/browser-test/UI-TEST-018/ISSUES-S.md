## OBS-S-S02-001 [待账号核验] 体验账号与提供的 active 状态不一致

- 现象：昵称输入“开心”，按数字键 1、2、3、4 后点击进入，页面提示“昵称或 PIN 码错误”。截图 `S-02-pin-filled.png`、`S-02-login-result.png`。
- 影响：无法进入 S-03~S-10 已登录场景；需核验账号是否已被重置、PIN 是否为当前线上版本值，或登录控件是否存在状态同步问题。

## BUG-S-S02-002 [P1] 注册成功后新会话使用同一昵称/PIN 无法登录

- 状态：OPEN
- 证据：同一 Browser Agent 会话内完成体验注册、PIN 设置并进入首页（`S-01-registration-complete.png`、`S-03-home-after-register.png`）；随后新独立会话使用同一体验账号登录，提示“昵称或 PIN 码错误”（`S-04-login-reregistered.png`）。
- 实际：注册成功态未形成可跨会话复用的登录凭据，无法验证会话恢复/退出后重新登录。
- 期望：注册完成后，使用注册昵称和 PIN 可在新会话登录；若试用账号仅设备内有效，应明确提示而非显示注册成功且提供登录入口。
- 影响：S-02 登录、S-10 换人/退出后恢复及家长联动无法可靠验证。

## OBS-S-S01-001 [已澄清] 注册告知同意需先滚动到底

- 状态：CLOSED（测试操作不完整，非产品缺陷）
- 复现：
  1. 学生端首屏点击“新注册”，进入使用前告知页，截图 `S-01-register-entry.png`。
  2. 勾选“我已阅读并理解以上全部内容，同意按照上述条款使用本服务”，按钮由 disabled 变为可用，截图 `S-01-consent-checked.png`。
  3. 点击“同意并继续”，等待 500ms，截图 `S-01-register-form.png`。
- 澄清：页面实现要求先滚动条款区域到底，再勾选同意；此前未完成滚动即点击，因此不构成缺陷。
- 复测：滚动到底后按钮可用，点击进入注册表单，截图 `S-01-scrolled-bottom.png`、`S-01-after-scroll-agree.png`。
