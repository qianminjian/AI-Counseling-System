## 五、共性根因

1. **F6 契约漂移**（学生/教师端 P1）：审计 6bf246d5 移除 `ApiResponse.success` 后，前端 5 文件 + shared refresh 未同步 → 已修复（success→code===0），10 个测试文件 mock 同步。
2. **BACK-008 加固遗漏**（家长端 P1）：家长域强制 PARENT_REPORT token 但登录签发未同步 → 已修复。
3. **CSP style-src 过严**（教师/管理端弹窗类）：生产 nginx CSP 阻止 antd 内联动画样式 → 弹窗无法关闭/toast 残留。
4. **注解 SQL 转义误用**（教师端 stats 500）：`@Select` 注解写 XML 转义 `&gt;=`。
