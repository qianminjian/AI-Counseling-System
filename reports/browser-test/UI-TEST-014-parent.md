## 二、问题清单（本轮）

**0 个功能 BUG**。观察项：

### OBS-P-03-01 [P2] 情绪周报页缺少「近7天日期范围」「风险等级」「AI 建议」区块
- 实际：/report 仅渲染 本周对话/对话轮次/整体状态(轻度波动)/情绪分布（SVG，难过6/开心19）；无日期范围、无独立风险等级标签、无 AI 建议卡
- 期望：design/12 §4.3 原型含日期范围、多情绪百分比分布、风险状态、AI 建议区块
- 截图：P-03-01-情绪周报页.png
- 状态：OPEN（P2，待确认是否设计差异或缺失）

### OBS-P-01-01 [P3] 注册页无「确认密码」字段与「协议勾选」控件
- 实际：注册表单仅家庭码/手机号/密码/关系/注册按钮；与 design/12 §4.2 模式 B 规格一致（密码一次输入）
- 状态：OPEN（P3 观察）

### OBS-P-02-01 [P3] 登录页无「显示密码」「验证码登录入口」
- 实际：登录 tab 仅手机号/密码/登录按钮；design/12 §4.2 模式 C 为兼容通道未提供独立 UI 入口
- 状态：OPEN（P3 观察）

### OBS-P-03-02 [P3] 多孩切换不可验证
- 两个家长账号均只绑定 1 孩（开心）；周报页/同意管理页无孩子切换控件
- 状态：受限（需多孩家庭账号数据）
