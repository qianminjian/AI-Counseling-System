本仓库包含三个独立的前端应用，分别面向学生（student-h5）、教师（teacher-web）和家长（parent-h5），每个应用采用不同的样式方案，形成差异化的视觉风格。

## 技术栈与工具

- **构建工具**：三个应用均基于 Vite + React，使用 oxlint 进行代码检查
- **学生端（student-h5）**：Tailwind CSS v4 + CSS Variables 主题系统 + PWA 支持
- **教师端（teacher-web）**：Ant Design v6 组件库 + 内置主题算法
- **家长端（parent-h5）**：原生 SCSS 手写样式，无 UI 框架依赖

## 主题系统设计

### 学生端情感化主题
`src/theme/ThemeProvider.jsx` 实现了完整的主题切换系统，支持三种预设主题：
- **海洋探险**（默认蓝绿色调）
- **花园精灵**（粉紫色调）
- **彩虹自由**（自定义色调）

主题通过 CSS Variables 驱动，存储在 `:root` 中，包括 `--primary`、`--accent`、`--bg-start`、`--bubble-ai` 等语义化变量，并通过 localStorage 持久化用户选择。

### 情感化排印系统
`src/theme/emotionTypography.js` 基于 CMU Kinetic Typography 研究，实现情绪驱动的文本样式：
- 不同情绪对应不同的字号缩放、字重、强调条颜色和入场动画
- 支持 happy/sad/angry/scared/nervous/neutral 六种情绪状态
- 通过 `--typo-scale` 和 `--typo-weight` CSS 变量动态控制

## 样式组织模式

### 学生端样式结构
- **全局样式**：`src/index.css` 定义字体、CSS 变量、基础动画
- **组件样式**：各组件内联 JSX 样式，配合 Tailwind 原子类
- **动画系统**：预定义情绪相关的关键帧动画（pop-happy、fade-sad、pop-angry 等）
- **响应式策略**：基于 Tailwind 的断点系统，适配手机和平板设备

### 教师端样式结构
- **组件库**：完全依赖 Ant Design 组件，通过 `ConfigProvider` 配置主题
- **暗色模式**：支持明暗主题切换，通过 localStorage 持久化
- **国际化**：中文本地化配置

### 家长端样式结构
- **SCSS 模块化**：单一 `app.scss` 文件，按页面功能组织样式块
- **移动端优先**：最大宽度 480px 限制，适合手机浏览
- **组件样式**：统一的按钮、卡片、输入框等基础样式类

## 设计原则与约束

1. **儿童友好设计**：学生端使用圆体字体（GenSenRounded），柔和色彩，大触控区域
2. **无障碍考虑**：所有应用启用 `-webkit-font-smoothing: antialiased` 提升文字渲染质量
3. **性能优化**：学生端 PWA 缓存静态资源，排除大型语音模型按需加载
4. **安全上下文**：开发环境默认 HTTPS，确保麦克风等敏感 API 可用
5. **品牌一致性**：波波小精灵角色配色随主题变化但保持识别度

## 部署与构建

- 学生端 base path 为 `/mindsafe/`，教师端为 `/teacher/`
- 生产构建时复制 ONNX Runtime WASM 文件到 `dist/ort/` 目录
- 支持通过环境变量控制 HTTPS 行为和代理配置
