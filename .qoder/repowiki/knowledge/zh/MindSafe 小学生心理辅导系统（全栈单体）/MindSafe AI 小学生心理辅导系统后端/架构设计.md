Maven 聚合工程（backend/pom.xml），依赖方向自顶向下严格分层：
- `counseling-app`：Spring Boot 启动入口（MindSafeApplication），通过 @ComponentScan("com.mindsafe") 扫描全部子包，@MapperScan 注册 MyBatis-Plus Mapper，启用异步与定时任务，加载 application.yml 与 Flyway SQL 迁移。
- `counseling-api`：HTTP/WebSocket 暴露层，Controller 仅做参数校验与上下文提取（JwtAuthenticationFilter → TenantContext），SSE 流式回复使用 Flux<StreamMessageEvent>；WebSocket /ws/alerts 用于教师预警推送。
- `counseling-service`：业务编排层，ConversationServiceImpl 串联风险检测、PII 脱敏、画像注入、时长限制、冷场决策模型（NudgeDecisionModel）与异步摘要生成。
- `counseling-ai`：AI Agent 编排层，ConversationOrchestrator 按 Safety→Emotion→CBT/Conversation 顺序调度各 Agent，并通过 CbtStateMachine 管理状态流转；ResilientChatModel 封装 LLM 调用容错。
- `counseling-domain`：领域实体与 MyBatis-Plus Mapper（entity/mapper/typehandler），纯数据访问无业务逻辑。
- `counseling-common`：跨模块共享 DTO、枚举（RiskLevel）、异常（BizException）。
- `counseling-tenant`：多租户隔离基础包。
- 独立 Python 微服务 `tts-service` 与 `voice-service` 通过 Dockerfile 容器化，由前端或后端 HTTP 调用。
- 部署使用 deploy/docker-compose.yml 统一编排 PostgreSQL、Nginx、监控（Prometheus/Grafana）。
