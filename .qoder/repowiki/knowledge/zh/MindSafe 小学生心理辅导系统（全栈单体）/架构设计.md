根目录采用分层模块化架构：后端通过 backend/pom.xml 聚合 counseling-common → counseling-domain → counseling-service → counseling-ai/counseling-api → counseling-app 的单向依赖链，counseling-app 是唯一可执行入口 MindSafeApplication；公共契约集中在 counseling-common（ApiResponse、ErrorCode、RiskLevel 等 DTO），domain 层定义实体与 MyBatis-Plus Mapper，service 层编排对话/通知/审计/家长教师等业务，ai 层封装 Spring AI Agent 与安全过滤，api 层暴露 REST/WebSocket 接口。前端按角色拆分为 student-h5、teacher-web、parent-h5，均通过 api.js 调用后端 /api 前缀接口。部署由 deploy/docker-compose.yml 统一编排 PostgreSQL、Nginx、后端容器、TTS 与 Voice Python 微服务，并附带 Prometheus/Grafana 监控与备份脚本。测试体系在 tests/{unit,integration,e2e} 下组织，Maven 父 POM 统一配置 Surefire 与 Failsafe。
